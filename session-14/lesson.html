الشرح النظري

هدف المشروع

في هذه الجلسة نجمع كل ما تعلمناه في JavaScript لبناء تطبيق قائمة مهام (Todo List) تفاعلي كامل — إضافة مهام، تحديدها كمكتملة، وحذفها. هذا المشروع يُمثّل نموذجاً مصغّراً لأي تطبيق ويب حقيقي.

ملفات المشروع

المشروع موجود في مجلد:

  • projects/todo-app/index.html — هيكل الصفحة
  • projects/todo-app/style.css — التصميم
  • projects/todo-app/app.js — المنطق والتفاعل
ابدأ من هنا: افتح مجلد projects/todo-app/ واتبع الخطوات أدناه لبناء التطبيق خطوة بخطوة.

الميزات المطلوبة

  1. إضافة مهمة: نموذج بإدخال نص وزر «إضافة»
  2. عرض المهام: قائمة ديناميكية تُبنى من مصفوفة
  3. إكمال مهمة: نقرة على المهمة تُعلّمها كمكتملة (خط يتوسطها)
  4. حذف مهمة: زر حذف لكل مهمة
  5. عداد: عرض عدد المهام المتبقية

هيكل البيانات

كل مهمة كائن بهذا الشكل:

  • id — معرّف فريد (رقم أو timestamp)
  • text — نص المهمة
  • completed — هل اكتملت؟ (boolean)

الخطوات المنطقية

  1. تهيئة مصفوفة tasks فارغة
  2. دالة render() ترسم القائمة من المصفوفة
  3. مستمع submit على النموذج يضيف مهمة جديدة
  4. Event delegation على القائمة للنقر (إكمال) والحذف
  5. تحديث العداد بعد كل تغيير

مفاهيم مطبّقة

  • المتغيرات والمصفوفات والكائنات (الجلسة 09-11)
  • الدوال والشروط (الجلسة 10)
  • DOM: createElement, appendChild, textContent (الجلسة 12)
  • الأحداث: addEventListener, submit, click, preventDefault (الجلسة 13)

مثال 3: دالة render — رسم القائمة

projects/todo-app/app.js — Render
function render() {
  list.innerHTML = "";

  tasks.forEach((task) => {
    const li = document.createElement("li");
    li.className = task.completed ? "completed" : "";
    li.dataset.id = task.id;

    const span = document.createElement("span");
    span.textContent = task.text;

    const deleteBtn = document.createElement("button");
    deleteBtn.textContent = "حذف";
    deleteBtn.className = "delete-btn";

    li.appendChild(span);
    li.appendChild(deleteBtn);
    list.appendChild(li);
  });

  const remaining = tasks.filter((t) => !t.completed).length;
  countEl.textContent = remaining;
}

مثال 4: إضافة مهمة عبر النموذج

projects/todo-app/app.js — Add Task
form.addEventListener("submit", (event) => {
  event.preventDefault();

  const text = input.value.trim();
  if (text === "") return;

  tasks.push({
    id: nextId++,
    text: text,
    completed: false
  });

  input.value = "";
  render();
});

مثال 5: Event Delegation — إكمال وحذف

projects/todo-app/app.js — Events
list.addEventListener("click", (event) => {
  const li = event.target.closest("li");
  if (!li) return;

  const taskId = Number(li.dataset.id);

  // Delete button clicked
  if (event.target.classList.contains("delete-btn")) {
    const index = tasks.findIndex((t) => t.id === taskId);
    if (index !== -1) {
      tasks.splice(index, 1);
      render();
    }
    return;
  }

  // Toggle completed on li click
  const task = tasks.find((t) => t.id === taskId);
  if (task) {
    task.completed = !task.completed;
    render();
  }
});

تمارين عملية

1 بناء الهيكل الأساسي

أنشئ الملفات الثلاثة في projects/todo-app/ وانسخ هيكل HTML. تأكد أن الصفحة تفتح بدون أخطاء.

الخطوات:

  1. أنشئ مجلد projects/todo-app/
  2. أنشئ index.html بالهيكل أعلاه
  3. أنشئ style.css و app.js فارغين
  4. افتح index.html في المتصفح

2 إضافة وعرض المهام

نفّذ دالة render() ومستمع submit لإضافة مهام وعرضها في القائمة.

استخدم الأمثلة 2 و 3 و 4 أعلاه — انسخ الكود إلى app.js وجرّب إضافة 3 مهام.

3 إكمال وحذف وعداد

أضف Event delegation لإكمال المهام وحذفها، وحدّث عداد المهام المتبقية.

استخدم المثال 5 أعلاه. تأكد أن:

  • النقر على نص المهمة يُعلّمها مكتملة
  • زر «حذف» يزيل المهمة من المصفوفة والقائمة
  • العداد يعرض فقط المهام غير المكتملة
📌

ملخص الجلسة

  • مشروع Todo List يجمع DOM والأحداث والمصفوفات في تطبيق واحد
  • مصفوفة tasks هي مصدر الحقيقة — DOM يُعاد رسمه منها
  • دالة render() تُحدّث الواجهة بعد كل تغيير في البيانات
  • Event delegation على #todo-list يتعامل مع عناصر ديناميكية
  • preventDefault على النموذج يمنع إعادة تحميل الصفحة

واجب اختياري — تحسينات إضافية

بعد إكمال المشروع الأساسي:

  • أضف زر «مسح المكتملة» يحذف كل المهام المُنجزة
  • أضف فلتر: الكل / نشطة / مكتملة
  • احفظ المهام في localStorage لتبقى بعد إغلاق المتصفح
  • أضف تحققاً: لا تسمح بمهمة فارغة أو مكررة
