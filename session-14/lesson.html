هدف الجلسة

اليوم نربط JavaScript بصفحة HTML — الأزرار تعمل، النص يتغير، والألوان تتحدّث أمامك. DOM هو الجسر بين الكود والصفحة. سنبسّط الموضوع خطوة بخطوة حتى تتمكن من بناء تفاعلات صغيرة بنفسك.

14

الشرح النظري — DOM من الصفر

1) شو هو DOM؟

لما المتصفح يفتح صفحة HTML، يحوّلها لـ شجرة عناصر اسمها DOM (Document Object Model). كل tag في HTML يصير «عقدة» (node) في الشجرة — JavaScript تقدر توصل لأي عقدة وتغيّرها.

تشبيه بسيط — شجرة عائلة:
<html> = الجد الأكبر · <body> = الأب · <h1> و <p> = الأولاد · JavaScript = الشخص اللي يقدر يغيّر أي فرد بالعائلة

2) كيف نوصل للعنصر؟

أهم طريقتين للمبتدئ:

  • document.getElementById("my-id") — يجيب عنصر واحد بـ id محدد (بدون #)
  • document.querySelector(".my-class") — يجيب أول عنصر يطابق محدّد CSS (مثل .class أو #id أو tag)
تذكّر: getElementById يأخذ الاسم فقط — "title" مو "#title". أما querySelector يستخدم صيغة CSS كاملة مع # أو .

3) textContent vs innerHTML

textContent

يغيّر النص فقط — آمن وبسيط. استخدمه دايماً للنصوص العادية.

innerHTML

يغيّر النص مع HTML (مثل <strong>). احذر — ممكن يسبب مشاكل أمنية.

4) تغيير الأنماط — element.style

بعد ما تجيب العنصر، تقدر تغيّر شكله مباشرة: element.style.color = "blue" أو element.style.fontSize = "24px". اسم الخاصية بـ camelCase: backgroundColor مو background-color.

5) الأحداث — addEventListener

عشان الزر «يسمع» النقر: button.addEventListener("click", function() { ... }). لما المستخدم ينقر، الكود داخل الدالة ينفّذ.

مثال 1: getElementById — تغيير نص

HTML + JavaScript
<p id="welcome">Hello!</p>
<script>
  const welcomeEl = document.getElementById("welcome");
  welcomeEl.textContent = "Welcome George!";
</script>

Welcome George!

مثال 2: querySelector — أول زر

JavaScript — querySelector
const btn = document.querySelector(".start-btn");
btn.textContent = "Ready, George!";
📤 النتيجة
نص الزر الأول من class="start-btn" يصير: Ready, George!

مثال 3: textContent vs innerHTML

JavaScript — Content
const box = document.getElementById("info");

box.textContent = "George loves tech";     // نص عادي
// box.innerHTML = "<strong>George</strong> loves tech";  // نص + HTML
📤 الفرق
textContent → George loves tech (نص فقط)
innerHTML   → George (عريض) loves tech (يفسر HTML كوسوم)

مثال 4: element.style — تغيير اللون

JavaScript — Styles
const title = document.getElementById("title");
title.style.color = "#2563eb";
title.style.fontSize = "28px";
📤 النتيجة
العنوان يصير أزرق وحجمه 28px

مثال 5: addEventListener — زر يغيّر الترحيب

JavaScript — Click Event
const greetBtn = document.getElementById("greet-btn");
const greetText = document.getElementById("greet-text");

greetBtn.addEventListener("click", function () {
  greetText.textContent = "Hey George Ziad Shahin! 👋";
  greetText.style.color = "green";
});
📤 النتيجة
عند النقر: النص يتغير واللون يصير أخضر

مثال 6: عدّاد بسيط

JavaScript — Counter
let count = 0;
const countEl = document.getElementById("count");
const addBtn = document.getElementById("add-btn");

addBtn.addEventListener("click", function () {
  count = count + 1;
  countEl.textContent = count;
});

كل نقرة: 0 → 1 → 2 → 3 ...

ملف صغير — انسخه وجربه

ملف جاهز للتجربة: dom-practice.html — افتحه واضغط الأزرار:

dom-practice.html — ملف كامل
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>DOM Practice</title>
  <style>
    body { font-family: sans-serif; padding: 2rem; text-align: center; }
    button { padding: 0.5rem 1rem; margin: 0.5rem; cursor: pointer; }
  </style>
</head>
<body>
  <h1 id="title">DOM Practice</h1>
  <p id="message">Click the buttons!</p>
  <p>Count: <span id="count">0</span></p>
  <button id="greet-btn">Greet</button>
  <button id="color-btn">Random Color</button>
  <button id="add-btn">+1</button>

  <script>
    // Grab elements from the page
    const title = document.getElementById("title");
    const message = document.getElementById("message");
    const countEl = document.getElementById("count");
    const greetBtn = document.getElementById("greet-btn");
    const colorBtn = document.getElementById("color-btn");
    const addBtn = document.getElementById("add-btn");

    let count = 0;
    const colors = ["#e11d48", "#2563eb", "#16a34a", "#ca8a04", "#9333ea"];

    // Change greeting on click
    greetBtn.addEventListener("click", function () {
      message.textContent = "Welcome George Ziad Shahin!";
      title.style.color = "#2563eb";
    });

    // Pick a random text color
    colorBtn.addEventListener("click", function () {
      const randomIndex = Math.floor(Math.random() * colors.length);
      message.style.color = colors[randomIndex];
    });

    // Simple counter
    addBtn.addEventListener("click", function () {
      count = count + 1;
      countEl.textContent = count;
    });
  </script>
</body>
</html>

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: محدّد خاطئ — صلّح الـ selector!

HTML فيه <button id="save-btn">Save</button> لكن الكود ما يلاقي الزر. ليش؟

const saveBtn = document.querySelector("save-btn");

saveBtn.addEventListener("click", function () {
  console.log("Saved!");
});

الخطأ: querySelector يحتاج صيغة CSS — ناقص # للـ id.

الحل:

// Option 1: querySelector with # for id
const saveBtn = document.querySelector("#save-btn");

// Option 2: getElementById (no # needed)
const saveBtn = document.getElementById("save-btn");

saveBtn.addEventListener("click", function () {
  console.log("Saved!");
});

بدون #، المتصفح يدور على tag اسمه save-btn — وما موجود!

🧩 تحدي 2: كود DOM مكسور — صلّحه!

المفروض الزر يغيّر النص، بس ما يشتغل. فيه 3 أخطاء — حاول تكتشفها:

<p id="status">Waiting...</p>
<button id="go-btn">Go</button>

<script>
  const status = document.getElementById("Status");
  const goBtn = document.getElementById("go-btn");

  goBtn.addEventListener("click", function () {
    status.innerText = "Done!";
    status.style.color = blue;
  });
</script>

الأخطاء:

  1. "Status" بحرف S كبير — الـ id بالHTML "status" صغير. JavaScript حساسة لحالة الأحرف!
  2. innerText يشتغل، بس الأفضل textContent للاتساق — أو خليه innerText إذا بدك.
  3. blue بدون علامات تنصيص — JavaScript تظنّه متغير! الصح: "blue"
const status = document.getElementById("status");
const goBtn = document.getElementById("go-btn");

goBtn.addEventListener("click", function () {
  status.textContent = "Done!";
  status.style.color = "blue";
});

تمارين عملية

1 زر ترحيب شخصي

أنشئ صفحة فيها <h1 id="name">Student</h1> وزر. لما ينقر، يصير النص «George Ziad Shahin» واللون أخضر. 

<h1 id="name">Student</h1>
<button id="show-name">Show My Name</button>

<script>
  const nameEl = document.getElementById("name");
  const btn = document.getElementById("show-name");

  btn.addEventListener("click", function () {
    nameEl.textContent = "George Ziad Shahin";
    nameEl.style.color = "green";
  });
</script>

2 عدّاد + و −

عدّاد يبدأ من 0، زر «+» يزيد، زر «−» ينقص. استخدم textContent لتحديث الرقم. 

<p>Score: <span id="score">0</span></p>
<button id="plus">+</button>
<button id="minus">-</button>

<script>
  let score = 0;
  const scoreEl = document.getElementById("score");
  const plusBtn = document.getElementById("plus");
  const minusBtn = document.getElementById("minus");

  plusBtn.addEventListener("click", function () {
    score = score + 1;
    scoreEl.textContent = score;
  });

  minusBtn.addEventListener("click", function () {
    score = score - 1;
    scoreEl.textContent = score;
  });
</script>

3 زر يبدّل بين لونين

فقرة وزر. كل نقرة تبدّل لون النص بين أزرق (#2563eb) وأحمر (#dc2626). تلميح: استخدم متغير boolean isBlue. 

<p id="text">Toggle my color!</p>
<button id="toggle">Toggle</button>

<script>
  const textEl = document.getElementById("text");
  const toggleBtn = document.getElementById("toggle");
  let isBlue = true;

  toggleBtn.addEventListener("click", function () {
    if (isBlue) {
      textEl.style.color = "#dc2626";
    } else {
      textEl.style.color = "#2563eb";
    }
    isBlue = !isBlue;
  });
</script>

ملخص الجلسة

  • DOM = شجرة عناصر HTML — JavaScript تعدّلها حيّاً
  • getElementById("id") و querySelector("#id") لاختيار العناصر
  • textContent للنص العادي · innerHTML فقط لما تحتاج HTML
  • element.style لتغيير الألوان والحجم مباشرة
  • addEventListener("click", ...) يربط الأزرار بالكود
  • الخطوة الجاية: مشروع projects/todo-app/ — تطبيق حقيقي!
