الشرح النظري

تنسيق النصوص

HTML يوفر عناصر لتغيير مظهر ومعنى النص:

  • strong — نص عريض ومهم
  • em — نص مائل للتأكيد
  • mark — تظليل النص
  • small — نص أصغر (ملاحظات)

الروابط (Links)

نستخدم عنصر a لإنشاء روابط. أهم خاصية هي href التي تحدد عنوان الرابط.

  • href="https://..." — رابط لموقع خارجي
  • href="page.html" — رابط لصفحة أخرى
  • target="_blank" — يفتح الرابط في تبويب جديد

الصور

عنصر img يعرض صورة. خصائصه المهمة:

  • src — مسار الصورة
  • alt — وصف نصي للصورة (مهم جداً)
  • width و height — الأبعاد
نصيحة: دائماً أضف alt للصور. يساعد المكفوفين ومحركات البحث على فهم محتوى الصورة.

القوائم

  • ul — قائمة غير مرتبة (نقاط)
  • ol — قائمة مرتبة (أرقام)
  • li — عنصر واحد داخل القائمة

التعليقات

التعليقات لا تظهر في الصفحة: <!-- هذا تعليق --> نستخدمها لتنظيم الكود وشرح أجزاء منه.

💻

أمثلة الكود

مثال 1: تنسيق النصوص

HTML — Text Formatting
<p>هذا نص <strong>عريض ومهم</strong> وهذا <em>مائل</em>.</p>
<p>كلمة <mark>مظللة</mark> و<small>نص صغير</small>.</p>
معاينة حية

هذا نص عريض ومهم وهذا مائل.

كلمة مظللة ونص صغير.

مثال 2: الروابط

HTML — Links
<!-- رابط لموقع خارجي -->
<a href="https://www.google.com" target="_blank">اذهب إلى Google</a>

<!-- رابط لصفحة داخلية -->
<a href="about.html">صفحة من أنا</a>

<!-- رابط بريد إلكتروني -->
<a href="mailto:student@email.com">راسلني</a>

مثال 3: الصور

HTML — Images
<img src="photo.jpg" alt="صورة شخصية" width="200">

<!-- صورة من الإنترنت -->
<img src="https://via.placeholder.com/150" alt="صورة تجريبية">

مثال 4: القوائم

HTML — Lists
<!-- قائمة غير مرتبة -->
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<!-- قائمة مرتبة -->
<ol>
  <li>تعلم HTML</li>
  <li>تعلم CSS</li>
  <li>تعلم JavaScript</li>
</ol>
معاينة حية
  • HTML
  • CSS
  • JavaScript
  1. تعلم HTML
  2. تعلم CSS
  3. تعلم JavaScript

تمارين عملية

1 صفحة "مفضلاتي"

أنشئ صفحة فيها عنوان، قائمة بـ 5 مواقع مفضلة (روابط)، وصورة واحدة.

Solution
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>مفضلاتي</title>
</head>
<body>
  <h1>مواقعي المفضلة</h1>
  <img src="https://via.placeholder.com/100" alt="أيقونة">
  <ul>
    <li><a href="https://www.google.com" target="_blank">Google</a></li>
    <li><a href="https://www.youtube.com" target="_blank">YouTube</a></li>
    <li><a href="https://www.wikipedia.org" target="_blank">Wikipedia</a></li>
    <li><a href="https://github.com" target="_blank">GitHub</a></li>
    <li><a href="https://www.w3schools.com" target="_blank">W3Schools</a></li>
  </ul>
</body>
</html>

2 قائمة مهام يومية

أنشئ قائمة مرتبة بـ 4 مهام يجب إنجازها اليوم، مع تنسيق نصي (عريض للمهم).

Solution
<h2>مهام اليوم</h2>
<ol>
  <li><strong>مراجعة درس HTML</strong></li>
  <li>قراءة 20 صفحة</li>
  <li><strong>إنهاء التمرين العملي</strong></li>
  <li>مشاهدة فيديو تعليمي</li>
</ol>

3 جدول أسعار بسيط (نصي)

استخدم قائمة غير مرتبة لعرض 3 منتجات مع أسعارها بالليرة السورية.

Solution
<h2>أسعار المنتجات</h2>
<ul>
  <li>كتاب برمجة — <strong>25,000 ل.س</strong></li>
  <li>سماعات — <strong>150,000 ل.س</strong></li>
  <li>فأرة حاسوب — <strong>45,000 ل.س</strong></li>
</ul>
📌

ملخص الجلسة

  • strong للنص المهم، em للتأكيد، mark للتظليل
  • الروابط بعنصر a مع خاصية href
  • target="_blank" يفتح الرابط في تبويب جديد
  • الصور بعنصر img مع src و alt إجباري
  • ul للقوائم النقطية، ol للقوائم المرقمة
  • التعليقات <!-- --> لتنظيم الكود

واجب اختياري

  • أنشئ صفحة "دليل المطاعم" فيها 3 مطاعم مع روابط وصور
  • أضف قائمة مرتبة بخطوات تحضير كوب شاي
  • جرّب رابط mailto: لبريدك الإلكتروني
