الشرح النظري

الجداول (Tables)

نستخدم الجداول لعرض بيانات منظمة في صفوف وأعمدة:

  • table — الجدول الكامل
  • tr — صف (Table Row)
  • th — خلية عنوان (Table Header)
  • td — خلية بيانات (Table Data)
  • thead — رأس الجدول
  • tbody — جسم الجدول

النماذج (Forms)

النماذج تجمع بيانات المستخدم. العناصر الأساسية:

  • form — يحتوي كل حقول الإدخال
  • input — حقل إدخال (نص، إيميل، كلمة مرور...)
  • textarea — حقل نص طويل
  • select — قائمة منسدلة
  • button — زر الإرسال
  • label — وصف الحقل

أنواع input الشائعة

  • text — نص عادي
  • email — بريد إلكتروني
  • password — كلمة مرور مخفية
  • number — أرقام فقط
  • checkbox — مربع اختيار
  • radio — اختيار واحد من عدة خيارات

HTML الدلالي (Semantic HTML)

عناصر تصف معنى المحتوى وليس شكله فقط:

  • header — رأس الصفحة
  • nav — قائمة التنقل
  • main — المحتوى الرئيسي
  • section — قسم من الصفحة
  • article — مقال أو محتوى مستقل
  • footer — تذييل الصفحة
لماذا HTML الدلالي؟ يساعد محركات البحث والمكفوفين على فهم هيكل صفحتك بشكل أفضل.

HTML — Form

تمارين عملية

1 جدول جدول دراسي

أنشئ جدولاً بـ 3 مواد دراسية مع أوقاتها وأيامها.

Solution
<table>
  <thead>
    <tr>
      <th>المادة</th>
      <th>اليوم</th>
      <th>الوقت</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>HTML</td>
      <td>الأحد</td>
      <td>10:00</td>
    </tr>
    <tr>
      <td>CSS</td>
      <td>الثلاثاء</td>
      <td>10:00</td>
    </tr>
    <tr>
      <td>JavaScript</td>
      <td>الخميس</td>
      <td>10:00</td>
    </tr>
  </tbody>
</table>

2 نموذج طلب منتج

نموذج يحتوي: اسم، إيميل، اختيار منتج (select)، وزر إرسال.

Solution
<form>
  <label>الاسم: <input type="text"></label><br><br>
  <label>البريد: <input type="email"></label><br><br>
  <label>المنتج:
    <select>
      <option>كتاب — 25,000 ل.س</option>
      <option>قلم — 2,000 ل.س</option>
      <option>دفتر — 8,000 ل.س</option>
    </select>
  </label><br><br>
  <button type="submit">إرسال الطلب</button>
</form>

Solution

    <h2>نبذة عني</h2>

  </section>

ملخص الجلسة

  • الجداول: table, tr, th, td, thead, tbody
  • النماذج تجمع بيانات المستخدم عبر form و input
  • أنواع input: text, email, password, number, checkbox, radio
  • label يربط النص بحقل الإدخال عبر for و id
  • HTML الدلالي: header, nav, main, section, footer
  • الهيكل الدلالي يحسّن SEO وإمكانية الوصول

واجب اختياري

  • أنشئ جدول مقارنة بين 3 هواتف (الاسم، السعر بالليرة، الميزة الأهم)
  • ابنِ نموذج "اتصل بنا" مع textarea لرسالة طويلة
  • حوّل صفحة "مفضلاتي" من الجلسة 2 لهيكل دلالي كامل
