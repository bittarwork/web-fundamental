الشرح النظري

هدف المشروع

في الجلسة 4 بنينا صفحة Portfolio بـ HTML فقط — بدون أي تصميم. الآن حان وقت إضافة CSS لتحويلها إلى صفحة احترافية وجذابة باستخدام كل ما تعلمناه: المحددات، Box Model، Flexbox، والتجاوب.

القاعدة الذهبية: HTML يبقى كما هو — نضيف ملف styles.css فقط ونربطه بالصفحة. لا نغيّر هيكل HTML إلا إذا احتجنا class جديد.

ملف المشروع المرجعي

نسخة جاهزة من المشروع الكامل (HTML + CSS) موجودة في: projects/portfolio-full/

  • index.html — صفحة Portfolio مع HTML الدلالي
  • styles.css — كل أنماط CSS للمشروع
مسار الملفات: من مجلد course-reference، افتح ../projects/portfolio-full/index.html في المتصفح لمعاينة النتيجة النهائية.

خطة التصميم — خطوة بخطوة

  1. Reset & Base: box-sizing، خط افتراضي، ألوان أساسية
  2. Header & Nav: Flexbox navbar، صورة دائرية، روابط أنيقة
  3. الأقسام: padding، max-width للمحتوى، عناوين مميزة
  4. المهارات: قائمة بأيقونات أو badges ملونة
  5. جدول المشاريع: border، hover effect، ألوان الحالة
  6. نموذج التواصل: inputs منسّقة، زر submit جذاب
  7. Footer: خلفية داكنة، روابط بيضاء
  8. Responsive: media query للموبايل

الألوان المقترحة

  • Primary: #2563eb — أزرق للروابط والأزرار
  • Dark: #1e293b — للـ header و footer
  • Text: #334155 — للنصوص
  • Background: #f8fafc — خلفية الصفحة
  • Accent: #059669 — للأسعار والنجاح

ما الذي سنتعلمه من هذا المشروع؟

  • ربط ملف CSS خارجي بمشروع حقيقي
  • تنظيم CSS بأقسام وتعليقات واضحة
  • استخدام Flexbox في navbar وfooter
  • تنسيق الجداول والنماذج بـ Box Model
  • إضافة hover effects و transitions
  • جعل الصفحة متجاوبة بـ media query واحد
تذكير: إذا لم تكمل مشروع HTML من الجلسة 4، استخدم الملف الجاهز في projects/portfolio-full/index.html كقاعدة للبدء.

مثال 1: ربط CSS و Reset أساسي

HTML + CSS — Setup
<!-- In portfolio index.html head -->
<link rel="stylesheet" href="styles.css">
<link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&display=swap" rel="stylesheet">

/* styles.css — Reset and base styles */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: "Cairo", Tahoma, sans-serif;
  line-height: 1.7;
  color: #334155;
  background-color: #f8fafc;
}

/* Limit content width for readability */
main {
  max-width: 900px;
  margin: 0 auto;
  padding: 0 20px;
}

تمارين عملية

1 إعداد الملفات و Reset

افتح مشروع Portfolio من الجلسة 4 (أو من projects/portfolio-full/). أنشئ styles.css، اربطه، وأضف reset + خط Cairo + ألوان أساسية.

Solution — index.html head
<link rel="stylesheet" href="styles.css">
<link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&display=swap" rel="stylesheet">
Solution — styles.css start
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: "Cairo", sans-serif;
  line-height: 1.7;
  color: #334155;
  background: #f8fafc;
}

2 تصميم Header و Navigation

صمّم header بخلفية داكنة، صورة دائرية، وnavbar بـ Flexbox. أضف hover effect على الروابط. استخدم الألوان المقترحة أعلاه.

راجع مثال 2 في قسم أمثلة الكود — أو افتح projects/portfolio-full/styles.css وابحث عن قسم /* Header */.

3 تنسيق الأقسام والجدول والنموذج

أضف padding لكل section، صمّم جدول المشاريع بظل و hover، ونسّق نموذج التواصل (inputs + زر submit). أضف footer داكن.

راجع أمثلة 3-6 أعلاه. الملف الكامل في projects/portfolio-full/styles.css يحتوي كل الأقسام منظّمة بتعليقات.

4 التجاوب — Media Query

أضف media query عند 768px: navbar عمودي، خط أصغر للعناوين، جدول بخط أصغر. اختبر بتصغير نافذة المتصفح أو DevTools → Toggle Device.

Solution
@media (max-width: 768px) {
  .site-header nav {
    flex-direction: column;
    gap: 8px;
  }

  .site-header h1 {
    font-size: 1.5rem;
  }

  main {
    padding: 0 12px;
  }

  table {
    font-size: 0.85rem;
  }
}

ملخص الجلسة

  • حوّلنا Portfolio من HTML خام إلى صفحة مصمّمة بملف CSS واحد
  • نظّمنا CSS بأقسام: reset → header → sections → table → form → footer
  • استخدمنا Flexbox في navbar وقائمة المهارات
  • Box Model + box-shadow للبطاقات والجداول والنماذج
  • hover effects و transitions تضيف حيوية للصفحة
  • media query واحد يجعل الصفحة متجاوبة على الموبايل
  • الملف المرجعي الكامل: projects/portfolio-full/

واجب اختياري

  • خصّص الألوان بأسلوبك الشخصي — جرّب palette مختلف
  • أضف قسم "شهادات" أو "خبرات" بتصميم CSS جديد
  • حسّن hover effects: ظل أقوى على البطاقات، تغيير لون الزر
  • شارك رابط GitHub أو screenshot للصفحة النهائية
  • قارن عملك مع projects/portfolio-full/ وحدّد الفروقات
