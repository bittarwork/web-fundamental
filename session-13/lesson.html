الشرح النظري

ما هي الأحداث (Events)؟

الحدث هو إشارة يُرسلها المتصفح عندما يفعل المستخدم شيئاً: نقرة، كتابة، إرسال نموذج، تحريك الماوس، الضغط على مفتاح... JavaScript «تستمع» لهذه الإشارات وتستجيب لها.

addEventListener — الطريقة الصحيحة

بدلاً من كتابة onclick داخل HTML، نربط المستمعين (listeners) من JavaScript:

  • أنظف وأكثر قابلية للصيانة
  • يسمح بإضافة أكثر من مستمع لنفس الحدث
  • يفصل بين HTML (هيكل) و JS (سلوك)
الصيغة: element.addEventListener("event", callback)

أحداث شائعة

  • click — نقرة على عنصر (أزرار، روابط)
  • submit — إرسال نموذج form
  • input — تغيّر قيمة حقل أثناء الكتابة
  • change — تغيّر القيمة عند فقدان التركيز (select, checkbox)
  • keydown — الضغط على مفتاح في لوحة المفاتيح

كائن الحدث (event object)

الدالة المستجيبة تستقبل كائناً يحمل معلومات عن الحدث: العنصر المستهدف (event.target)، نوع الحدث، وطرق للتحكم بالسلوك الافتراضي.

preventDefault — إيقاف السلوك الافتراضي

بعض العناصر لها سلوك افتراضي: النموذج يُعيد تحميل الصفحة، الرابط ينتقل لعنوان. event.preventDefault() يُوقف هذا السلوك لنتحكم نحن بالنتيجة عبر JavaScript.

مثال شائع: نموذج تسجيل — نمنع إعادة التحميل، نقرأ المدخلات، نتحقق منها، ثم نعرض رسالة نجاح.

Event Delegation — تفويض الأحداث

عند إضافة عناصر ديناميكياً (مثل قائمة مهام)، بدلاً من ربط مستمع لكل عنصر، نربط مستمعاً واحداً على العنصر الأب ونتحقق من event.target. سنطبّق هذا في مشروع الجلسة 14.

أمثلة الكود

مثال 1: حدث click على زر

HTML + JavaScript — Click Event
<button id="greet-btn">اضغطني</button>
<p id="message"></p>

<script>
  const btn = document.getElementById("greet-btn");
  const msg = document.getElementById("message");

  btn.addEventListener("click", () => {
    msg.textContent = "مرحباً! لقد ضغطت الزر.";
  });
</script>

مثال 2: حدث input — عداد الأحرف

JavaScript — Input Event
<input type="text" id="username" placeholder="اسمك">
<span id="char-count">0</span> حرف

<script>
  const input = document.getElementById("username");
  const counter = document.getElementById("char-count");

  input.addEventListener("input", (event) => {
    const value = event.target.value;
    counter.textContent = value.length;
  });
</script>

مثال 3: submit مع preventDefault

JavaScript — Form Submit
<form id="contact-form">
  <input type="email" id="email" required>
  <button type="submit">إرسال</button>
</form>
<p id="form-result"></p>

<script>
  const form = document.getElementById("contact-form");
  const result = document.getElementById("form-result");

  form.addEventListener("submit", (event) => {
    event.preventDefault(); // منع إعادة تحميل الصفحة

    const email = document.getElementById("email").value;
    result.textContent = `تم استلام: ${email}`;
  });
</script>

مثال 4: تبديل حالة (Toggle)

JavaScript — Toggle Class
<button id="theme-btn">تبديل الوضع</button>

<script>
  const themeBtn = document.getElementById("theme-btn");

  themeBtn.addEventListener("click", () => {
    document.body.classList.toggle("dark-mode");
  });
</script>

مثال 5: حاسبة سعر بسيطة

JavaScript — Price Calculator
<input type="number" id="qty" value="1" min="1">
<span id="unit-price" data-price="45000">45,000 ل.س</span>
<p>المجموع: <strong id="total">45,000 ل.س</strong></p>

<script>
  const qtyInput = document.getElementById("qty");
  const priceEl = document.getElementById("unit-price");
  const totalEl = document.getElementById("total");
  const unitPrice = Number(priceEl.dataset.price);

  qtyInput.addEventListener("input", () => {
    const qty = Number(qtyInput.value) || 0;
    const total = unitPrice * qty;
    totalEl.textContent = total.toLocaleString("ar-SY") + " ل.س";
  });
</script>

تمارين عملية

1 زر إظهار/إخفاء

أنشئ فقرة وزراً. عند النقر، أخفِ الفقرة أو أظهرها بتبديل display.

Solution
<p id="secret">نص سري!</p>
<button id="toggle-btn">إظهار/إخفاء</button>

<script>
  const secret = document.getElementById("secret");
  const toggleBtn = document.getElementById("toggle-btn");

  toggleBtn.addEventListener("click", () => {
    const isHidden = secret.style.display === "none";
    secret.style.display = isHidden ? "block" : "none";
  });
</script>

2 نموذج تسجيل بدون إعادة تحميل

نموذج باسم ورقم هاتف. عند الإرسال، امنع التحميل واعرض «تم التسجيل: [الاسم]».

Solution
<form id="register-form">
  <input type="text" id="name" placeholder="الاسم" required>
  <input type="tel" id="phone" placeholder="الهاتف" required>
  <button type="submit">تسجيل</button>
</form>
<p id="status"></p>

<script>
  document.getElementById("register-form").addEventListener("submit", (e) => {
    e.preventDefault();
    const name = document.getElementById("name").value;
    document.getElementById("status").textContent = `تم التسجيل: ${name}`;
  });
</script>

3 عدّاد تنازلي

زر «انقُص» يُنقص رقماً معروضاً من 10 إلى 0. عند الوصول لـ 0، عطّل الزر.

Solution
<span id="count">10</span>
<button id="decrease-btn">انقُص</button>

<script>
  let count = 10;
  const countEl = document.getElementById("count");
  const btn = document.getElementById("decrease-btn");

  btn.addEventListener("click", () => {
    if (count > 0) {
      count--;
      countEl.textContent = count;
    }
    if (count === 0) {
      btn.disabled = true;
    }
  });
</script>

ملخص الجلسة

  • الأحداث تربط تفاعل المستخدم بكود JavaScript
  • addEventListener الطريقة المفضّلة لربط المستمعين
  • click للنقر · input للكتابة المباشرة · submit للنماذج
  • preventDefault() يمنع السلوك الافتراضي (مثل إعادة تحميل الصفحة)
  • event.target يشير للعنصر الذي أطلق الحدث

واجب اختياري

قبل الجلسة القادمة:

  • ابنِ نموذج «إضافة منتج» (اسم + سعر بالليرة السورية) يعرض المنتج في قائمة دون إعادة تحميل
  • أضف زر «مسح الكل» يُفرّغ القائمة عند النقر
  • جرّب حدث keydown لإرسال النموذج عند الضغط على Enter
