الشرح النظري — من الصفر

1) شو هي الدالة (Function)؟

الدالة = كتلة كود لها اسم، بتقدر تستدعيها متى ما بدك. مثل «وصفة» جاهزة: بدل ما تكتب نفس الخطوات كل مرة، بتقول «نفّذ الوصفة».

2) التوابع السهمية — Arrow Functions

طريقة أقصر وأحدث لكتابة الدوال. بدل كلمة function منستخدم السهم =>.

دالة عادية (Regular)

function add(a, b) { return a + b; }

أطول، الطريقة الكلاسيكية

دالة سهمية (Arrow)

const add = (a, b) => a + b;

أقصر، مثالية مع filter و map

تشبيه بسيط: الدالة العادية = رسالة طويلة · الدالة السهمية = اختصار واتساب — نفس المعنى، أسرع بالكتابة

قواعد Arrow Function البسيطة

  • معامل واحد: ممكن بدون أقواس — x => x * 2
  • أكثر من معامل: أقواس لازمة — (a, b) => a + b
  • سطر واحد + return: ما تحتاج {} ولا return
  • أكثر من سطر: أقواس معقوفة + return

3) filter() — احتفظ باللي بيطابق الشرط

filter() بمر على كل عنصر بالمصفوفة، وبيرجع مصفوفة جديدة فيها بس العناصر اللي الشرط طلع true عليها. المصفوفة الأصلية ما بتتغير!

Syntax
const result = array.filter((item) => condition);

مثال من الحياة: عندك 10 ألعاب، بدك بس اللي تقييمها فوق 4 — filter بيعمل هالشي.

4) map() — حوّل كل عنصر

map() بمر على كل عنصر، بيحوّله لشي جديد، وبيرجع مصفوفة جديدة بنفس الطول. برضه المصفوفة الأصلية ما بتتغير.

Syntax
const result = array.map((item) => newValue);

مثال من الحياة: عندك أسعار 5 منتجات بالليرة، بدك تطبق خصم 10% على كل واحد — map بيعمل هالشي.

filter — تصفية

10 عناصر → 4 عناصر (بس اللي بيطابقوا)

«أريني بس اللي...»

map — تحويل

10 عناصر → 10 عناصر (كل واحد متحوّل)

«غيّر كل واحد لـ...»

قاعدة ذهبية: filter = أقل عناصر (تصفية) · map = نفس العدد (تحويل) · الاتنين بيرجعوا مصفوفة جديدة وما بيعدّلوا الأصل!

مثال 1: Arrow Function — أول دالة سهمية

JavaScript — Arrow Functions
// regular function
function greet(name) {
  return "Hello " + name;
}

// arrow function — same result, shorter syntax
const greetArrow = (name) => "Hello " + name;

console.log(greet("George"));
console.log(greetArrow("George"));

// arrow with math
const double = (n) => n * 2;
console.log(double(5));

مثال 3: map — خصم 10% على أسعار المنتجات

JavaScript — map()
const products = [
  { name: "Mouse", price: 28000 },
  { name: "Keyboard", price: 95000 },
  { name: "Headphones", price: 85000 }
];

// transform each product — apply 10% discount
const discounted = products.map((product) => {
  const newPrice = product.price * 0.9;  // 10% off
  return {
    name: product.name,
    price: newPrice
  };
});

discounted.forEach((p) => {
  console.log(p.name + ": " + Math.round(p.price) + " ل.س");
});

مثال 5: filter + map معاً — منتجات رخيصة بأسعار جديدة

JavaScript — Chaining filter & map
const shop = [
  { name: "Cable", price: 15000 },
  { name: "Laptop", price: 3200000 },
  { name: "Case", price: 25000 },
  { name: "Monitor", price: 450000 }
];

// step 1: filter — only items under 100,000 ل.س
const cheap = shop.filter((item) => item.price < 100000);

// step 2: map — add 5000 ل.س shipping to each
const withShipping = cheap.map((item) => ({
  name: item.name,
  total: item.price + 5000
}));

withShipping.forEach((p) => {
  console.log(p.name + " total: " + p.total + " ل.س");
});

مثال 6: before / after — شوف الفرق

قبل — for loop تقليدي

const nums = [1, 2, 3, 4, 5];
const evens = [];
for (let i = 0; i < nums.length; i++) {
  if (nums[i] % 2 === 0) {
    evens.push(nums[i]);
  }
}
console.log(evens); // [2, 4]

بعد — filter + arrow

const nums = [1, 2, 3, 4, 5];
const evens = nums.filter((n) => n % 2 === 0);
console.log(evens); // [2, 4]

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: filter ولا map؟

عندك مصفوفة ألعاب. بدك بس أسماء الألعاب اللي تقييمها 5. أي أداة تستخدم؟

const games = [
  { name: "Minecraft", rating: 5 },
  { name: "FIFA", rating: 4 },
  { name: "GTA", rating: 5 }
];
// ??? — what goes here?

الجواب: filter ثم map — أو filter + map مع بعض!

  1. filter — نحتفظ بس rating === 5
  2. map — نستخرج الاسم فقط من كل غرض
const perfect = games
  .filter((g) => g.rating === 5)
  .map((g) => g.name);

console.log(perfect);
// ["Minecraft", "GTA"]

🧩 تحدي 2: بدون تشغيل — توقع النتيجة!

اقرأ الكود واكتب النتيجة:

const items = [5, 12, 8, 20, 3];
const result = items
  .filter((n) => n > 5)
  .map((n) => n + 10);
console.log(result);

الحل خطوة بخطوة:

  1. filter (> 5): من [5, 12, 8, 20, 3] → [12, 8, 20]
  2. map (+ 10): 12→22, 8→18, 20→30
[22, 18, 30]

3 arrow function + filter + map

مصفوفة أرقام: [3, 7, 12, 4, 9, 15]. 1) filter: بس الأرقام الأكبر من 5. 2) map: اضرب كل رقم × 2. 3) اطبع النتيجة النهائية. 

const numbers = [3, 7, 12, 4, 9, 15];

const result = numbers
  .filter((n) => n > 5)
  .map((n) => n * 2);

console.log(result);
[14, 24, 18, 30]

ملخص الجلسة

  • Arrow function: (x) => x * 2 — أقصر من function العادية
  • filter() — يرجع عناصر بس اللي الشرط true عليها (تصفية)
  • map() — يحوّل كل عنصر ويرجع مصفوفة بنفس الطول (تحويل)
  • filter و map ما بيعدّلوا المصفوفة الأصلية — بيرجعوا مصفوفة جديدة
  • ممكن تربطهم: arr.filter(...).map(...)
