الشرح النظري

لماذا نحتاج هياكل بيانات؟

المتغيرات البسيطة تكفي لقيمة واحدة. لكن التطبيقات الحقيقية تتعامل مع قوائم منتجات، مستخدمين، طلبات... لذلك نستخدم هياكل بيانات تجمع قيماً مرتبطة معاً.

المصفوفات (Arrays)

المصفوفة قائمة مرتبة من القيم، تبدأ الفهرس (index) من 0. يمكن أن تحتوي أي نوع: أرقام، نصوص، كائنات، أو حتى مصفوفات أخرى.

  • length — عدد العناصر
  • push() — إضافة في النهاية
  • pop() — حذف من النهاية
  • [index] — الوصول لعنصر بالفهرس

الكائنات (Objects)

الكائن يخزّن بيانات على شكل أزواج مفتاح : قيمة (key-value). مثالي لتمثيل كيان واحد له خصائص متعددة — مثل منتج له اسم وسعر وفئة.

  • object.key أو object["key"] — قراءة خاصية
  • يمكن إضافة وتعديل الخصائص ديناميكياً

forEach — التكرار على المصفوفات

الدالة array.forEach(callback) تنفّذ دالة على كل عنصر دون الحاجة لحلقة for يدوياً. مفيدة لعرض قوائم أو حساب مجموعات.

JSON — تبادل البيانات

JSON اختصار لـ JavaScript Object Notation — صيغة نصية موحّدة لتبادل البيانات بين المتصفح والسيرفر. تبدو مثل كائن JavaScript لكنها نص وليست كوداً.

  • JSON.stringify(obj) — تحويل كائن إلى نص JSON
  • JSON.parse(text) — تحويل نص JSON إلى كائن
تطبيق عملي: عندما تطلب منتجات من API، تستلم JSON تحوّله بـ JSON.parse ثم تعرضه في الصفحة.

أمثلة الكود

مثال 1: المصفوفات الأساسية

JavaScript — Arrays
const colors = ["أحمر", "أخضر", "أزرق"];

console.log(colors[0]);       // "أحمر"
console.log(colors.length);   // 3

colors.push("أصفر");
console.log(colors);          // 4 عناصر

const prices = [25000, 45000, 120000]; // ل.س
const total = prices[0] + prices[1] + prices[2];
console.log("مجموع الأسعار:", total, "ل.س");

مثال 2: كائن منتج

JavaScript — Objects
const product = {
  id: 1,
  name: "هاتف ذكي",
  price: 1850000,        // ل.س
  category: "إلكترونيات",
  inStock: true
};

console.log(product.name);
console.log(product["price"]);
console.log(`${product.name}: ${product.price} ل.س`);

product.discount = 10;    // إضافة خاصية جديدة
console.log(product);

مثال 3: مصفوفة من كائنات — كتالوج منتجات

JavaScript — Product Catalog
const products = [
  { name: "سماعات بلوتوث", price: 95000, inStock: true },
  { name: "ماوس لاسلكي", price: 35000, inStock: true },
  { name: "لوحة مفاتيح", price: 78000, inStock: false },
  { name: "شاحن سريع", price: 42000, inStock: true }
];

products.forEach((item, index) => {
  const status = item.inStock ? "متوفر" : "نفد";
  console.log(`${index + 1}. ${item.name} — ${item.price} ل.س (${status})`);
});

مثال 4: forEach مع حسابات

JavaScript — forEach Calculations
const cart = [
  { name: "قهوة", price: 15000, qty: 2 },
  { name: "كعك", price: 8000, qty: 3 }
];

let cartTotal = 0;

cart.forEach((item) => {
  const lineTotal = item.price * item.qty;
  cartTotal += lineTotal;
  console.log(`${item.name}: ${lineTotal} ل.س`);
});

console.log("إجمالي السلة:", cartTotal, "ل.س");

مثال 5: JSON — stringify و parse

JavaScript — JSON
const store = {
  name: "متجر النور",
  city: "دمشق",
  products: [
    { name: "حليب", price: 12000 },
    { name: "خبز", price: 3500 }
  ]
};

// Object → JSON string
const jsonText = JSON.stringify(store);
console.log(jsonText);

// JSON string → Object
const parsed = JSON.parse(jsonText);
console.log(parsed.name);
console.log(parsed.products[0].price, "ل.س");

تمارين عملية

1 قائمة مهام بسيطة

أنشئ مصفوفة بثلاث مهام نصية، واطبعها باستخدام forEach مع ترقيم.

Solution
const tasks = ["تعلّم HTML", "تعلّم CSS", "تعلّم JavaScript"];

tasks.forEach((task, index) => {
  console.log(`${index + 1}. ${task}`);
});

2 كائن طالب

عرّف كائن student يحتوي: name, age, course, grade — واطبع تقريراً منسقاً.

Solution
const student = {
  name: "ليلى حسن",
  age: 20,
  course: "أساسيات الويب",
  grade: 88
};

console.log(`الطالبة: ${student.name}`);
console.log(`العمر: ${student.age}`);
console.log(`الكورس: ${student.course}`);
console.log(`الدرجة: ${student.grade}`);

3 فلترة المنتجات المتوفرة

من مصفوفة منتجات، اطبع فقط المنتجات المتوفرة (inStock: true) مع أسعارها بالليرة السورية.

Solution
const items = [
  { name: "ساعة ذكية", price: 320000, inStock: true },
  { name: "تابلت", price: 890000, inStock: false },
  { name: "سماعة", price: 65000, inStock: true }
];

items.forEach((item) => {
  if (item.inStock) {
    console.log(`${item.name}: ${item.price} ل.س`);
  }
});

ملخص الجلسة

  • المصفوفات قوائم مرتبة تبدأ فهرستها من 0
  • الكائنات تخزّن بيانات كأزواج مفتاح-قيمة لتمثيل كيانات حقيقية
  • forEach يمرّ على كل عنصر وينفّذ دالة عليه
  • JSON صيغة نصية لتبادل البيانات — stringify و parse
  • مصفوفة من كائنات = النمط الأكثر شيوعاً لعرض قوائم في التطبيقات
