هدف الجلسة

اليوم نتعلم شيئين مهمين: الحلقات — لتكرار العمل بدون كتابة نفس الكود مراراً، والتوابع — كتل جاهزة تستدعيها عند الحاجة. مثل عدّ تنازلي قبل بدء لعبة، أو دالة تحسب النقاط تلقائياً.

11

الشرح النظري — من الصفر

1) شو هي الحلقة (Loop)؟

بدل ما تكتب console.log(1) مئة مرة، الحلقة بتكرّر كود معيّن لعدد مرات أو لحد ما يتحقق شرط.

تشبيه بسيط: الحلقة مثل «كرّر 10 تمرينات» — ما بتعدّهم يدوي، بتكرّر نفس الحركة!

2) حلقة for — الأكثر استخداماً

بنية حلقة for فيها 3 أجزاء مفصولة بـ ;:

  1. البداية (start): let i = 0 — من وين نبدأ العد
  2. الشرط (condition): i < 5 — لحد متى نكمل
  3. الخطوة (step): i++ — كيف نزيد العداد (i++ يعني i = i + 1)
for (let i = 0; i < 5; i++) {
  console.log("الرقم:", i);
}
// يطبع: 0, 1, 2, 3, 4

3) حلقة while — «طالما الشرط صح»

while تكرّر الكود طالما الشرط true. مفيدة لما ما نعرف بالضبط كم مرة بدنا نكرّر.

for

لما تعرف عدد التكرارات مسبقاً
مثل: جدول ضرب، عد تنازلي 10→1

while

لما التكرار يعتمد على شرط
مثل: «طالما اللعبة شغالة»

تحذير — الحلقة اللانهائية! إذا الشرط في while دايماً true، البرنامج ما بيوقف وبيعلق المتصفح!
مثال خطير: while (true) { ... } بدون break.
تأكد إنو في شي يغيّر الشرط أو يوقف الحلقة.

4) شو هي الدالة (Function)؟

الدالة (تابع) هي كتلة كود مسماة تقدر تستدعيها متى ما بدك — مثل وصفة طبخ: اكتبها مرة، استخدمها 100 مرة.

تشبيه: الدالة = وصفة «تحضير قهوة» — ما بتكتب الخطوات كل مرة، بتقول «حضّر قهوة»!

5) تعريف دالة — function

  1. نكتب function ثم اسم الدالة
  2. أقواس () — فيها معاملات (parameters) اختيارية
  3. أقواس { } — جسم الدالة (الكود)
  4. نستدعيها: greet("George")

6) return — إرجاع نتيجة

return يرجّع قيمة من الدالة بدل ما يطبعها بس. مثلاً: دالة تحسب نقاط اللعبة وترجع الرقم. 

function add(a, b) {
  return a + b;
}

const result = add(5, 3);
console.log(result); // 8

مثال 5: دالة تحسب نقاط اللعبة

JavaScript — Function with return
function calculateScore(wins, bonus) {
  const pointsPerWin = 10;
  const total = (wins * pointsPerWin) + bonus;
  return total;
}

const georgeScore = calculateScore(7, 5);
console.log("النقاط:", georgeScore);

if (georgeScore >= 60) {
  console.log("مبروك! نجحت");
} else {
  console.log("حاول مرة تانية");
}

for (let count = 5; count >= 1; count--) {

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: صلّح الحلقة اللانهائية!

هالكود المفروض يطبع 1، 2، 3 — بس بيعلّق! ليش؟

let i = 1;
while (i <= 3) {
  console.log(i);
  // ناقص شي هون!
}

المشكلة: i ما عم يزيد — الشرط i <= 3 دايماً true!

الحل: أضف i++; داخل الحلقة:

let i = 1;
while (i <= 3) {
  console.log(i);
  i++; // ← هاد السطر الناقص!
}
// 1, 2, 3

🧩 تحدي 2: تتبّع مخرجات الحلقة

بدون تشغيل — شو رح يطبع؟

let total = 0;
for (let i = 1; i <= 4; i++) {
  total = total + i;
}
console.log(total);

الحل خطوة بخطوة:

  1. i=1: total = 0+1 = 1
  2. i=2: total = 1+2 = 3
  3. i=3: total = 3+3 = 6
  4. i=4: total = 6+4 = 10
10

function greet(name) {

3 دالة calculateScore

دالة تأخذ wins و bonus، ترجع (wins × 10) + bonus. جرب wins=5, bonus=10.

function calculateScore(wins, bonus) {
  return (wins * 10) + bonus;
}

const score = calculateScore(5, 10);
console.log(score);
60

ملخص الجلسة

  • for: start; condition; step — للتكرار بعدد معروف
  • while: طالما الشرط true — انتبه من الحلقات اللانهائية!
  • i++ يعني زيادة العداد بـ 1 · count-- يعني نقصان بـ 1
  • function = وصفة قابلة لإعادة الاستخدام
  • parameters = مدخلات الدالة · return = النتيجة المرجعة
  • الحلقات + التوابع = أساس أي برنامج حقيقي
