اليوم نتعلم شيئين مهمين: الحلقات — لتكرار العمل بدون كتابة نفس الكود مراراً، والتوابع — كتل جاهزة تستدعيها عند الحاجة. رح نغطّي while و break و continue، ونفهم الفرق بين return و console.log. مثل عدّ تنازلي قبل بدء لعبة، أو دالة تحسب السعر باليورو تلقائياً.

الشرح النظري — من الصفر

1) شو هي الحلقة (Loop)؟

بدل ما تكتب console.log(1) مئة مرة، الحلقة بتكرّر كود معيّن لعدد مرات أو لحد ما يتحقق شرط.

تشبيه بسيط: الحلقة مثل «كرّر 10 تمرينات» — ما بتعدّهم يدوي، بتكرّر نفس الحركة!

2) حلقة for — الأكثر استخداماً

بنية حلقة for فيها 3 أجزاء مفصولة بـ ;:

  1. البداية (start): let i = 0 — من وين نبدأ العد
  2. الشرط (condition): i < 5 — لحد متى نكمل
  3. الخطوة (step): i++ — كيف نزيد العداد (i++ يعني i = i + 1)
for (let i = 0; i < 5; i++) {
  console.log("الرقم:", i);
}
// يطبع: 0, 1, 2, 3, 4

3) حلقة while — «طالما الشرط صح»

while تكرّر الكود طالما الشرط true. مفيدة لما ما نعرف بالضبط كم مرة بدنا نكرّر — أو لما التكرار يعتمد على حالة تتغيّر أثناء التشغيل (مثل أرواح اللاعب، أو انتظار إدخال صحيح).

for

لما تعرف عدد التكرارات مسبقاً
مثل: جدول ضرب، عد تنازلي 10→1

while

لما التكرار يعتمد على شرط
مثل: «طالما اللعبة شغالة» أو «طالما في أرواح»

بنية while أبسط من for — فيها جزئين فقط:

  1. قبل الحلقة: نجهّز المتغيرات (مثل let lives = 3)
  2. الشرط: while (lives > 0) — يُفحص قبل كل دورة
  3. داخل الحلقة: الكود + تحديث المتغير (مثل lives--) — وإلا بتعلق!
let lives = 3;

while (lives > 0) {
  console.log("أرواح متبقية:", lives);
  lives--; // decrease by 1 each round
}
console.log("انتهت اللعبة!");
كيف تشتغل؟ المتصفح يسأل: «هل الشرط true؟» → نعم: ينفّذ الكود ويرجع يسأل من جديد → لا: يطلع من الحلقة ويكمل الكود اللي بعدها.
مثل سؤال «في أرواح؟» قبل كل جولة — لما تصير 0، بتوقف.
تحذير — الحلقة اللانهائية! إذا الشرط في while دايماً true، البرنامج ما بيوقف وبيعلق المتصفح!
مثال خطير: while (true) { ... } بدون break.
تأكد إنو في شي داخل الحلقة يغيّر الشرط (مثل i++ أو lives--) أو يستخدم break لإيقافها.

4) break و continue — التحكم داخل الحلقة

أحياناً بدنا نوقف الحلقة مبكراً أو نتخطّى دورة واحدة بدون ما نوقف كل شي. هون بيجي دور break و continue. (تذكّر: break استخدمناها بـ switch بالجلسة 10 — نفس الفكرة: «وقف واطلع»!)

break — «وقف الحلقة»

يوقف الحلقة فوراً ويكمل الكود اللي بعدها.
مثل: وصلت للرقم اللي بتدور عليه — ما داعي تكمل العد.

continue — «تخطّى هالدورة»

يوقف الدورة الحالية ويروح للدورة الجاية.
مثل: تخطّي الأرقام الزوجية واطبع الفردية بس.

// break — stop when we reach the target number
const target = 5;

for (let i = 1; i <= 10; i++) {
  console.log("جاري العد:", i);
  if (i === target) {
    console.log("وصلنا للهدف!");
    break; // no need to keep counting
  }
}

// continue — skip multiples of 3
for (let n = 1; n <= 7; n++) {
  if (n % 3 === 0) {
    continue; // skip 3, 6...
  }
  console.log(n);
}
// prints: 1, 2, 4, 5, 7
قاعدة سريعة: break = اخرج من الحلقة كلها · continue = روح للتكرار الجاي بدون ما تنفّذ باقي الكود بهالدورة.

5) شو هي الدالة (Function)؟

الدالة (تابع) هي كتلة كود مسماة تقدر تستدعيها متى ما بدك — مثل وصفة طبخ: اكتبها مرة، استخدمها 100 مرة.

تشبيه: الدالة = وصفة «تحضير قهوة» — ما بتكتب الخطوات كل مرة، بتقول «حضّر قهوة»!

6) تعريف دالة — function

تعريف الدالة = «نكتب الوصفة». استدعاء الدالة = «نطبّق الوصفة».

  1. نكتب function ثم اسم الدالة (يفضّل يبدأ بفعل: greet, calculateScore, add)
  2. أقواس () — فيها معاملات (parameters) اختيارية: مدخلات الوصفة
  3. أقواس { } — جسم الدالة: الخطوات اللي تنفّذ
  4. نستدعيها باسمها + القيم: greet("George")
// definition — write the recipe once
function greet(name) {
  console.log("مرحباً " + name + "!");
}

// calls — use it many times with different values
greet("George");
greet("Sara");
greet("Ali");

7) Parameters و Arguments — مدخلات الدالة

Parameters = الأسماء اللي نكتبها وقت تعريف الدالة (مثل name, wins). Arguments = القيم الفعلية اللي نمرّرها وقت الاستدعاء (مثل "George", 7). 

function showPrice(item, price) {
  // item and price are parameters
  console.log(item + " — " + price + " €");
}

showPrice("Coffee", 3);   // arguments: "Coffee", 3
showPrice("Cake", 5);     // arguments: "Cake", 5

الدالة ما بتشتغل لحالها — لازم نستدعيها. ممكن نستدعيها أكثر من مرة بقيم مختلفة، وكل استدعاء ينفّذ الكود من جديد.

8) return — إرجاع نتيجة

return يرجّع قيمة من الدالة ويوقف تنفيذها. الفرق عن console.log: الطباعة بتعرض بالكونسول بس؛ return بترجع قيمة تقدر تخزّنها أو تستخدمها بحسابات لاحقة.

console.log داخل الدالة

يطبع وخلص — ما ترجع قيمة للاستخدام
النتيجة: undefined

return

يرجّع قيمة — تقدر تحفظها بمتغير
مثل: const total = calculateScore(5, 10)

function add(a, b) {
  return a + b; // send result back to caller
}

const result = add(5, 3);
console.log(result); // 8

// use return value in another calculation
const doubled = add(5, 3) * 2;
console.log(doubled); // 16
متى أستخدم return؟ لما الدالة «تحسب» شي وتريده ترجع — مثل السعر النهائي، مجموع النقاط، أو تحويل درجة حرارة. استخدم console.log بس للعرض والتجربة أثناء التعلّم.

مثال 6: while + break — تخمين الرقم السري

حلقة while لا نهائية (while (true)) — نوقفها بـ break أول ما نصيب الرقم.

    break; // stop the loop — we found it!

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: صلّح الحلقة اللانهائية!

هالكود المفروض يطبع 1، 2، 3 — بس بيعلّق! ليش؟

let i = 1;
while (i <= 3) {
  console.log(i);
  // ناقص شي هون!
}

المشكلة: i ما عم يزيد — الشرط i <= 3 دايماً true!

الحل: أضف i++; داخل الحلقة:

let i = 1;
while (i <= 3) {
  console.log(i);
  i++; // ← هاد السطر الناقص!
}
// 1, 2, 3

🧩 تحدي 2: تتبّع مخرجات الحلقة

بدون تشغيل — شو رح يطبع؟

let total = 0;
for (let i = 1; i <= 4; i++) {
  total = total + i;
}
console.log(total);

الحل خطوة بخطوة:

  1. i=1: total = 0+1 = 1
  2. i=2: total = 1+2 = 3
  3. i=3: total = 3+3 = 6
  4. i=4: total = 6+4 = 10
10

🧩 تحدي 3: break vs continue — شو الفرق؟

بدون تشغيل — أي كود يطبع أقل أرقام؟

الكود A

for (let i = 1; i <= 5; i++) {
  if (i === 3) break;
  console.log(i);
}

الكود B

for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);
}

الكود A (break): يطبع 1، 2 — عند i=3 يوقف الحلقة كلها.

الكود B (continue): يطبع 1، 2، 4، 5 — عند i=3 يتخطّى بس ويكمل.

A → 1, 2
B → 1, 2, 4, 5

5 break — أوقف عند 100

حلقة while تجمع أرقام (1+2+3...) — أوقفها بـ break لما المجموع يوصل 100 أو أكثر.

let sum = 0;
let n = 1;

while (true) {
  sum = sum + n;
  if (sum >= 100) {
    break; // stop when we reach 100
  }
  n++;
}

console.log("المجموع:", sum, "— توقف عند n =", n);
المجموع: 105 — توقف عند n = 14

ملخص الجلسة

  • for: start; condition; step — للتكرار بعدد معروف
  • while: طالما الشرط true — جهّز المتغير قبلها، حدّثه داخلها، وانتبه من الحلقات اللانهائية!
  • break: أوقف الحلقة فوراً · continue: تخطّى الدورة الحالية وروح للجاية
  • i++ يعني زيادة العداد بـ 1 · count-- يعني نقصان بـ 1
  • function = وصفة قابلة لإعادة الاستخدام — عرّف مرة، استدعِ كم مرة بدك
  • parameters = أسماء المدخلات وقت التعريف · arguments = القيم وقت الاستدعاء
  • return يرجّع قيمة ويوقف الدالة · console.log للعرض بس
  • الحلقات + التوابع + break/continue = أساس أي برنامج حقيقي
