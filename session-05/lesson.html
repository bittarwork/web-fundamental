الشرح النظري

ما هو CSS؟

CSS اختصار لـ Cascading Style Sheets — أي «أوراق الأنماط المتتالية». إذا كان HTML هو هيكل الصفحة (العظام)، فـ CSS هو المظهر: الألوان، الخطوط، المسافات، والتخطيط.

قاعدة ذهبية: HTML يصف ماذا يوجد في الصفحة، و CSS يصف كيف يبدو ذلك المحتوى.

ثلاث طرق لربط CSS

يمكنك تطبيق CSS بثلاث طرق — كل واحدة لها استخدام مناسب:

  1. ملف خارجي (External): الأفضل للمشاريع الحقيقية. تربط ملف .css من داخل <head>.
  2. داخل <head> (Internal): تكتب CSS داخل <style> في نفس ملف HTML. مفيد للصفحات الصغيرة أو التجارب السريعة.
  3. مباشر على العنصر (Inline): باستخدام style="..." على العنصر نفسه. استخدمه نادراً — يصعب صيانته.

بنية قاعدة CSS

كل قاعدة CSS تتكون من ثلاثة أجزاء:

  • المحدد (Selector): يحدد أي عنصر HTML نستهدف
  • الخاصية (Property): ما نريد تغييره (مثل اللون)
  • القيمة (Value): القيمة الجديدة (مثل أحمر أو #ff0000)

المحددات الأساسية

  • * — يستهدف كل العناصر (Universal)
  • p — يستهدف كل عناصر الفقرات (Element)
  • .card — يستهدف العناصر ذات class="card" (Class)
  • #header — يستهدف العنصر ذو id="header" (ID)
  • a:hover — يستهدف الرابط عند مرور الماوس (Pseudo-class)
تذكير: الـ id فريد لكل صفحة (عنصر واحد فقط)، بينما class يمكن استخدامه لعدة عناصر. في المشاريع الكبيرة نفضّل class.

الألوان في CSS

يمكنك كتابة الألوان بعدة طرق:

  • بالاسم: red, blue
  • HEX: #1a73e8 — الأكثر شيوعاً
  • RGB: rgb(26, 115, 232)
  • RGBA: مثل RGB مع شفافية — rgba(0,0,0,0.5)

الخطوط (Fonts)

أهم خصائص النص:

  • font-family — نوع الخط (مثل Arial أو Tahoma)
  • font-size — حجم الخط (px, rem, em)
  • font-weight — سُمك الخط (400 عادي، 700 عريض)
  • line-height — المسافة بين الأسطر — مهم للقراءة
  • text-align — محاذاة النص (right, center, left)

Google Fonts

يمكنك استيراد خطوط مجانية من Google Fonts. تضيف رابطاً في <head> ثم تستخدم اسم الخط في font-family. للعربية جرّب: Cairo, Tajawal, Noto Sans Arabic.

أمثلة الكود

مثال 1: ربط CSS — الطرق الثلاث

HTML + CSS — Linking Methods
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>طرق ربط CSS</title>

  <!-- Method 1: External CSS file (recommended) -->
  <link rel="stylesheet" href="styles.css">

  <!-- Method 2: Internal CSS inside head -->
  <style>
    body {
      font-family: Tahoma, sans-serif;
    }
  </style>
</head>
<body>
  <h1>مرحباً</h1>

  <!-- Method 3: Inline style (use sparingly) -->
  <p style="color: #2563eb;">فقرة بلون أزرق</p>
</body>
</html>

مثال 2: المحددات الأساسية

CSS — Selectors
/* Element selector — all paragraphs */
p {
  color: #333;
  line-height: 1.6;
}

/* Class selector — reusable style */
.price-tag {
  color: #059669;
  font-weight: bold;
}

/* ID selector — unique element */
#main-title {
  font-size: 2rem;
  text-align: center;
}

/* Pseudo-class — link on hover */
a:hover {
  color: #dc2626;
  text-decoration: underline;
}

تمارين عملية

1 أول ملف CSS خارجي

أنشئ ملف styles.css واربطه بصفحة HTML. اجعل خلفية الصفحة رمادية فاتحة (#f3f4f6) والنص بلون داكن (#111827).

Solution — styles.css
/* Page background and default text color */
body {
  background-color: #f3f4f6;
  color: #111827;
  font-family: Tahoma, sans-serif;
  margin: 0;
  padding: 20px;
}
Solution — index.html (head)
<link rel="stylesheet" href="styles.css">

2 بطاقة منتج بـ class

أنشئ div بـ class="product-card" يحتوي عنوان منتج وسعره. استخدم CSS لتنسيق البطاقة: خلفية بيضاء، padding، ولون أخضر للسعر. مثال السعر: 45,000 ل.س.

Solution
<!-- HTML -->
<div class="product-card">
  <h2>سماعات لاسلكية</h2>
  <p class="price">45,000 ل.س</p>
</div>

/* CSS */
.product-card {
  background-color: #ffffff;
  padding: 20px;
  border-radius: 8px;
  max-width: 300px;
}

.product-card .price {
  color: #059669;
  font-weight: bold;
  font-size: 1.2rem;
}

3 تنسيق روابط التنقل

أنشئ nav بـ 3 روابط. اجعل لون الروابط أزرق، وعند hover يصبح أحمر مع خط تحته. استخدم pseudo-class :hover.

Solution
<nav class="main-nav">
  <a href="#">الرئيسية</a>
  <a href="#">المنتجات</a>
  <a href="#">تواصل</a>
</nav>

/* Nav link default and hover states */
.main-nav a {
  color: #2563eb;
  text-decoration: none;
  margin-left: 16px;
}

.main-nav a:hover {
  color: #dc2626;
  text-decoration: underline;
}

ملخص الجلسة

  • CSS يتحكم بمظهر HTML: ألوان، خطوط، مسافات، وتخطيط
  • أفضل طريقة لربط CSS: ملف خارجي عبر <link rel="stylesheet">
  • المحددات: عنصر (p)، class (.name)، id (#name)، pseudo-class (:hover)
  • الألوان: اسم، HEX، RGB، RGBA — HEX الأكثر استخداماً
  • font-family, font-size, font-weight, line-height, text-align للنصوص
  • Google Fonts يوفّر خطوطاً مجانية جاهزة للاستخدام

واجب اختياري

قبل الجلسة القادمة:

  • أنشئ صفحة "قائمة أسعار" فيها 5 منتجات بأسعار بالليرة السورية (ل.س)
  • استخدم class مختلف لكل فئة (إلكترونيات، ملابس، إلخ)
  • جرّب خط Cairo من Google Fonts على الصفحة كاملة
  • افتح DevTools (F12) وعدّل الألوان مباشرة لترى التأثير فوراً
