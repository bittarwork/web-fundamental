الشرح النظري — من الصفر

ملاحظة: في أمثلة هذا الكورس نستخدم اسم George كقيمة تجريبية في الكود.

1) شو هو JavaScript أصلاً؟

تخيل موقع إلكتروني مثل لعبة أو متجر: HTML هو الهيكل (الجدران والغرف)، CSS هو التصميم (الألوان والديكور)، وJavaScript هو الكهرباء — اللي يخلي الأزرار تشتغل، والعداد يزيد، والصفحة تتفاعل معك.

تشبيه بسيط: HTML = جسم الإنسان · CSS = الملابس · JavaScript = الحركة والتفكير

2) وين منكتب الكود؟

  1. افتح VS Code وأنشئ ملف اسمه app.js
  2. اربطه بصفحة HTML: <script src="app.js"></script>
  3. افتح المتصفح واضغط F12 → تبويب Console
  4. اكتب كودك وشوف النتيجة مباشرة!

3) console.log — أهم أداة للمبتدئ

console.log() يعني: «يا كمبيوتر، اطبعلي هالشي على الشاشة» حتى نشوف النتيجة ونتأكد إنو الكود شغال.

4) المتغيرات — الصندوق اللي بحفظ المعلومات

المتغير (Variable) مثل صندوق عليه اسم، وبداخله قيمة. مثلاً: صندوق اسمه age وبداخله الرقم 17.

let — قيمة بتتغير

مثل عداد اللعبة: كل ما تفوز، الرقم بيزيد.

const — قيمة ثابتة

مثل اسم ثابت — لا يتغير بعد تعريفه.

5) أنواع البيانات الأساسية

  • String (نص): "George" — بين علامات تنصيص
  • Number (رقم): 17 — بدون علامات تنصيص
  • Boolean (صح/غلط): true أو false
قاعدة ذهبية: استخدم const دائماً، وغيّر لـ let بس لما تحتاج تغيّر القيمة.

6) العمليات الحسابية البسيطة

JavaScript يقدر يجمع ويطرح ويضرب:

  • + جمع · - طرح
  • * ضرب · / قسمة

JavaScript — let
let score = 0;       // نقاط اللعبة بالبداية

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: صلّح الكود!

هالكود فيه 3 أخطاء. حاول تكتشفها قبل ما تشوف الحل:

let Name = "george";
const age = "17";
let score = 0
score = score + 10
console.log(name, age, score);

الأخطاء:

  1. Name كبيرة لكن استخدمنا name صغيرة — JavaScript حساسة لحالة الأحرف!
  2. age نص ("17") مو رقم — الأفضل: const age = 17;
  3. ناقص ; في نهاية السطرين (اختياري بس الأفضل نضيفها)
let name = "George";
const age = 17;
let score = 0;
score = score + 10;
console.log(name, age, score);
// George 17 10

🧩 تحدي 2: بدون تشغيل — توقع النتيجة!

اقرأ الكود بعناية واكتب النتيجة على ورقة:

const a = 10;
const b = 3;
let result = a * b + 1;
result = result - 5;
console.log(result);

الحل خطوة بخطوة:

  1. a * b + 1 = 10 × 3 + 1 = 31
  2. 31 - 5 = 26
26

3 حساب سعر سماعات

السعر 120,000 ل.س، خصم 20,000 ل.س. احسب واطبع السعر النهائي.

const price = 120000;
const discount = 20000;
const total = price - discount;
console.log("المجموع:", total, "ل.س");
// المجموع: 100000 ل.س

ملخص الجلسة

  • JavaScript تخلي الصفحة تتفاعل — HTML هيكل، CSS تصميم، JS حركة
  • console.log() لطباعة النتائج في Console (F12)
  • const للقيم الثابتة، let للقيم المتغيرة
  • أنواع البيانات: String, Number, Boolean
  • JavaScript حساسة لحالة الأحرف: name ≠ Name
  • جرّب كل مثال بنفسك — القراءة بدون تجربة ما بتكفي!
