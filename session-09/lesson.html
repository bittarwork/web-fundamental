الشرح النظري

ما هو JavaScript؟

JavaScript هي لغة برمجة تعمل داخل المتصفح وتضيف السلوك والتفاعل للصفحة. بينما HTML يبني الهيكل و CSS يضيف التصميم، JavaScript تجعل الصفحة «حية»: أزرار تستجيب، نماذج تتحقق من المدخلات، وقوائم تتحدّث دون إعادة تحميل.

أين نكتب JavaScript؟

هناك طريقتان شائعتان:

  • داخل HTML: باستخدام وسم <script> في نهاية body
  • ملف خارجي: <script src="app.js"></script> — الأفضل للمشاريع
نصيحة: ضع وسم script قبل إغلاق </body> حتى تُحمّل عناصر الصفحة أولاً قبل تشغيل الكود.

console.log — نافذتك للتعلّم

الدالة console.log() تطبع قيماً في Console داخل DevTools (F12). هي أداةك الأساسية لفحص النتائج وتتبّع الأخطاء أثناء التعلّم.

المتغيرات: let و const

المتغير هو «صندوق» يخزّن قيمة يمكن استخدامها لاحقاً:

  • let — لقيمة قابلة للتغيير (مثل عداد أو اسم مستخدم مؤقت)
  • const — لقيمة ثابتة لا تُعاد تعيينها (مثل رابط API أو نسبة ضريبة)
قاعدة عملية: استخدم const افتراضياً، وانتقل إلى let فقط عندما تحتاج تغيير القيمة.

أنواع البيانات الأساسية

  • String — نص: "مرحباً"
  • Number — رقم: 42 أو 3.14
  • Boolean — منطقي: true أو false
  • undefined — متغير مُعرَّف لكن بلا قيمة
  • null — قيمة فارغة مقصودة

العوامل (Operators)

العوامل تُنفّذ عمليات على القيم:

  • حسابية: + - * / %
  • مقارنة: === !== > <
  • منطقية: && (و) · || (أو) · ! (نفي)
مهم: استخدم === للمقارنة الدقيقة (القيمة والنوع معاً)، وليس == الذي قد يسبب نتائج غير متوقعة.

أمثلة الكود

مثال 1: أول سطر JavaScript

JavaScript — Hello Console
console.log("مرحباً من JavaScript!");
console.log(2026);

مثال 2: المتغيرات let و const

JavaScript — Variables
const courseName = "أساسيات الويب";
let studentCount = 25;

console.log(courseName);
console.log(studentCount);

studentCount = 26; // مسموح مع let
console.log("عدد الطلاب الآن:", studentCount);

// courseName = "كورس آخر"; // خطأ! const لا يُعاد تعيينه

مثال 3: أنواع البيانات

JavaScript — Data Types
const productName = "سماعات لاسلكية";   // String
const price = 85000;                      // Number (ل.س)
const inStock = true;                     // Boolean
let discount;                             // undefined

console.log(typeof productName);  // "string"
console.log(typeof price);        // "number"
console.log(typeof inStock);      // "boolean"
console.log(typeof discount);     // "undefined"

مثال 4: العوامل الحسابية والمقارنة

JavaScript — Operators
const itemPrice = 120000;  // ل.س
const quantity = 2;
const total = itemPrice * quantity;

console.log("المجموع:", total, "ل.س");

const isExpensive = total > 200000;
console.log("هل السعر مرتفع؟", isExpensive);

const hasDiscount = true;
const isMember = false;
console.log("يستحق خصماً؟", hasDiscount && isMember); // false

مثال 5: دمج النصوص (Concatenation)

JavaScript — Strings
const firstName = "محمد";
const lastName = "بيطار";
const fullName = firstName + " " + lastName;

console.log("الاسم الكامل:", fullName);

// Template literals — الطريقة الحديثة
const greeting = `أهلاً ${firstName}!`;
console.log(greeting);

تمارين عملية

1 متغيرات الملف الشخصي

أنشئ ملف profile.js يحتوي على const للاسم والعمر والمدينة، واطبعها في Console.

Solution
const name = "سارة أحمد";
const age = 22;
const city = "دمشق";

console.log("الاسم:", name);
console.log("العمر:", age);
console.log("المدينة:", city);

2 حساب سعر منتج

عرّف سعر منتج بـ 45,000 ل.س وكمية 3، واحسب المجموع واطبعه مع وحدة العملة.

Solution
const unitPrice = 45000;
const quantity = 3;
const total = unitPrice * quantity;

console.log(`المجموع: ${total} ل.س`);

3 فحص الأنواع والمقارنة

قارن بين الرقمين 10 و "10" باستخدام === و ==، واطبع typeof لكل منهما.

Solution
const num = 10;
const str = "10";

console.log(typeof num);       // "number"
console.log(typeof str);       // "string"
console.log(num === str);      // false
console.log(num == str);       // true (تحويل تلقائي — تجنّبه)
