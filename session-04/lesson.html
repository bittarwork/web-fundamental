الشرح النظري

هدف المشروع

في هذه الجلسة نجمع كل ما تعلمناه في HTML لبناء صفحة Portfolio شخصية كاملة — بدون أي CSS. الهدف هو إتقان هيكل HTML قبل الانتقال للتصميم.

متطلبات المشروع

الصفحة يجب أن تحتوي على الأقسام التالية:

  1. Header: اسمك وصورة شخصية
  2. قسم "عني": فقرة تعريفية عنك
  3. قسم المهارات: قائمة بمهاراتك
  4. قسم المشاريع: جدول بمشاريعك
  5. نموذج تواصل: اسم، إيميل، رسالة
  6. Footer: حقوق النشر وروابط
تذكير: لا تستخدم CSS في هذا المشروع! سنصممه بالكامل في الجلسة 8. ركّز على الهيكل الصحيح والعناصر الدلالية.

خطوات العمل

  1. أنشئ ملف portfolio.html
  2. ابدأ بالهيكل الدلالي: header → main → footer
  3. أضف كل قسم داخل section
  4. استخدم nav للتنقل بين الأقسام
  5. اختبر الصفحة في المتصفح
💻

تمارين المشروع

1 بناء الهيكل الأساسي

أنشئ الملف مع header (اسمك + nav) و main و footer. تأكد من استخدام العناصر الدلالية.

راجع الكود المرجعي أعلاه — ابدأ بـ header, main, footer ثم أضف الأقسام تدريجياً.

2 إضافة المحتوى

أضف قسم "عني" بفقرتين، قائمة مهارات بـ 5 عناصر، وجدول بـ 3 مشاريع.

استخدم section لكل قسم، ul للمهارات، table للمشاريع. خصّص المحتوى بمعلوماتك الشخصية.

3 نموذج التواصل والمراجعة

أضف نموذج تواصل، ثم راجع الصفحة كاملة وتأكد أن كل عنصر في مكانه الصحيح.

تحقق من: هل كل section له id؟ هل الروابط في nav تشير للأقسام؟ هل alt موجود للصورة؟

📌

ملخص الجلسة

  • المشروع يجمع كل عناصر HTML التي تعلمناها
  • استخدمنا HTML الدلالي: header, nav, main, section, footer
  • الصفحة تحتوي: نصوص، روابط، صور، قوائم، جداول، نماذج
  • لا CSS في هذه المرحلة — الهيكل فقط
  • سنعود لهذا المشروع في الجلسة 8 لإضافة التصميم

واجب اختياري

  • خصّص المحتوى بمعلوماتك الحقيقية
  • أضف قسم "خبراتي" بقائمة مرتبة
  • أرسل رابط GitHub أو صفحة إضافية في الـ footer
