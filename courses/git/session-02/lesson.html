هدف الجلسة

نقرأ الفروقات، نتجاهل الملفات غير المطلوبة، نعمل على فروع، ندمجها في main، ونتراجع بحذر دون تدمير التاريخ.

02

الشرح النظري

1) git diff

يعرض ما تغيّر ولم يُضف بعد إلى الانتظار. git diff --staged يعرض ما ينتظر الـ commit. السطور الخضراء إضافة، والحمراء حذف.

2) git restore

لإلغاء تعديل في ملف لم يُحفظ بعد: git restore notes.txt يعيده لآخر commit.

لإخراج ملف من الانتظار دون حذف التعديل من القرص: git restore --staged notes.txt.

في إصدارات أقدم قد ترى git checkout -- file لنفس فكرة restore. فضّل restore لأنه أوضح.

3) ملف .gitignore

بعض الملفات لا تُرفع أبداً: مجلدات البناء، node_modules، .env، ملفات نظام التشغيل. ضع أسماءها في .gitignore في جذر المشروع ثم اعمل commit لهذا الملف نفسه.

الأسرار: كلمات المرور ومفاتيح API لا تدخل Git. إذا أضفتها بالخطأ لا يكفي حذف السطر لاحقاً — تبقى في التاريخ. اسأل المدرب قبل أي «تنظيف» متقدم.

4) الفروع

الفرع خط عمل مستقل. main هو الخط المستقر. ميزة جديدة تُبنى على فرع مثل feature/contact-page حتى لا تُكسر النسخة الجاهزة.

تشبيه: main = الشارع الرئيسي. الفرع = ورشة جانبية. بعد نجاح التجربة تُفتح الورشة على الشارع (merge). 
git branch
git switch -c feature/about
git switch main

git switch -c name ينشئ الفرع وينقلك إليه. git branch يعرض الفروع والنجمة على الحالي.

5) git merge

وأنت على main: git merge feature/about يدخل عمل الفرع. إن كان main لم يتقدّم قد يكون الدمج Fast-forward (تحريك المؤشر فقط). إن عمل الاثنان على تواريخ مختلفة يُنشأ commit دمج.

التعارضات عندما يعدّل الطرفان نفس الأسطر — نحلّها في الجلسة 05.

6) قراءة السجل كشجرة

git log --oneline --graph --all

ترى تفرّع الخطوط ثم التقاءها بعد الدمج.

7) التراجع الآمن

  • restore: تراجع عن ملفات غير committed.
  • commit --amend: تصحيح آخر commit إن لم يُرفع بعد (تعديل الرسالة أو نسيان ملف صغير).
  • reset --soft HEAD~1: يلغي آخر commit ويبقي التغييرات في الانتظار.
  • reset --mixed HEAD~1: يلغي الـ commit ويبقي التعديلات في المجلد دون staging.
تجنّب git reset --hard في هذه الدورة إلا بطلب صريح وبعد فهم أن الملفات غير المحفوظة قد تُفقد. لا تستخدمه على عمل مشترك مرفوع.

أمثلة عملية

مثال 1: مشاهدة الفرق ثم الاستعادة

echo "draft line" >> notes.txt
git diff
git restore notes.txt
git status

مثال 2: تجاهل ملفات النظام

echo ".env" > .gitignore
echo "node_modules/" >> .gitignore
echo ".DS_Store" >> .gitignore
git add .gitignore
git commit -m "Ignore env files and dependencies"

مثال 3: فرع لصفحة عن المدرب

git switch -c feature/about
echo "<h1>About Osama Bittar</h1>" > about.html
git add about.html
git commit -m "Add about page for the trainer"
git switch main
git merge feature/about
git log --oneline --graph --all

مثال 4: تعديل رسالة آخر commit (محلياً فقط)

git commit --amend -m "Add about page for Osama Bittar"

لا تعدّل commits رُفعت إلى GitHub وشاركها الآخرون.

تمارين عملية

1 إخراج من الانتظار

أضف ملفاً بـ add ثم أخرجه بـ restore --staged دون حذف الملف.

git add draft.txt
git restore --staged draft.txt

2 فرع الأسعار

أنشئ فرعاً feature/pricing فيه سطر «Price: 29 €» ثم ادمجه في main.

git switch -c feature/pricing
echo "Price: 29 €" > pricing.txt
git add pricing.txt
git commit -m "Add course price in EUR"
git switch main
git merge feature/pricing

3 شجرة السجل

اعرض كل الفروع بشكل رسم بعد الدمج.

git log --oneline --graph --all

ملخص الجلسة

  • diff يوضح التغيير قبل الحفظ
  • .gitignore يحمي الأسرار والمجلدات الثقيلة
  • اعمل على فرع ثم ادمج إلى main
  • restore آمن · reset --hard خطير

واجب الجلسة

  • أضف .gitignore لمشروع academy-notes
  • ابنِ فرعين صغيرين (مثلاً about و pricing) وادمجهما
  • التقط صورة لخرج git log --oneline --graph --all في الواجب
