عن

عن هذه الدورة

Git أداة على جهازك تحفظ تاريخ الملفات كلقطة بعد لقطة. GitHub موقع يستضيف تلك المستودعات على الشبكة ويعطي فريقاً واحداً مكاناً للتعاون. الدورة تغطي الاثنين معاً: الأوامر الأساسية كاملة، ثم تفاصيل GitHub التي يحتاجها مطوّر ويب في العمل اليومي.

الأمثلة تستخدم اسم المدرب Osama Bittar كمرجع موحّد. الأوامر والتعليقات داخل الأمثلة بالإنجليزية.

يشمل

ماذا يتضمن المحتوى؟

  • شرح المفاهيم النظرية بتشبيهات واضحة
  • أوامر Git خطوة بخطوة مع أمثلة قابلة للنسخ
  • تمارين واختبارات وواجبات لكل جلسة
  • استخدام واجهة GitHub: المستودع، Issues، Pull Requests
  • مشروع ختامي: رفع موقع صغير ونشره عبر GitHub Pages
