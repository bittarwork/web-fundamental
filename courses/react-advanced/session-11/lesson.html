هدف الجلسة

نحدّث القائمة فوراً عند الإضافة أو الحذف، ونرجع للحالة السابقة إن فشلت الشبكة.

11

الشرح النظري

1) الشعور بالسرعة

انتظار round-trip لكل نقرة يجعل اللوحة ثقيلة. التفاؤل يعرض النتيجة المتوقعة ثم يؤكدها السيرفر.

2) Rollback

احفظ لقطة الحالة قبل التحديث. في catch أعدها واعرض خطأ.

3) علامات الانتظار

يمكنك تعطيل الزر أو إظهار نقطة صغيرة دون تجميد الصفحة كلها.

4) التطابق مع المعرّفات

عنصر مؤقت يحتاج id مؤقت (temp-...) يُستبدل برد السيرفر حتى لا يتكرر الصف.

لا تتفاءل بعمليات مالية حقيقية دون تأكيد. في الدورة الحجز رمزي باليورو.
💻

أمثلة عملية

مثال 1: إضافة متفائلة

async function addCourse(title) {
  const snapshot = items;
  const temp = { id: "temp-" + Date.now(), title, price: 29, trainer: "Osama Bittar" };
  setItems((current) => [...current, temp]);
  try {
    const saved = await apiCreate(temp);
    setItems((current) => current.map((row) => (row.id === temp.id ? saved : row)));
  } catch (error) {
    setItems(snapshot);
    setError(error.message);
  }
}

مثال 2: حذف متفائل

const snapshot = items;
setItems((current) => current.filter((row) => row.id !== id));
try {
  await apiDelete(id);
} catch (error) {
  setItems(snapshot);
}

ملخص الجلسة

  • لقطة قبل التغيير
  • rollback عند الفشل
  • لا تفاؤل أعمى بالمدفوعات

واجب الجلسة

  • طبّق إضافة وحذف على قائمة كورسات
  • اعرض السعر € واسم المدرب
  • رسالة خطأ واضحة عند الرجوع
