هدف الجلسة

نبني واجهة تُركَّب كقطع واضحة (Tabs، Card) بدل تمرير عشرات الـ props.

02

الشرح النظري

1) Composition قبل الإعدادات

كلما زاد عدد الـ props المنطقية (showHeader, headerExtra, footerSlot...) فكّر في children وقطع مسماة.

2) Compound Components

عائلة مكوّنات تتشارك حالة عبر Context داخلي: Tabs.List و Tabs.Panel يقرآن القيمة من Tabs الجذر.

تشبيه: HTML الأصلي <select> و <option> — القطع تعرف عائلتها.

3) Context ضيق النطاق

هذا السياق ليس Global State للتطبيق. هو سلك داخلي للمجموعة فقط.

4) Slots عبر children

مرّر رأس البطاقة وتذييلها كأبناء بدل خصائص نصية فقط — أحرار في وضع زر أو سعر €

لا تصدّر عشر قطع لا تعمل وحدها دون جذر يوفّر السياق.
💻

أمثلة عملية

مثال 1: بطاقة مركّبة

function Card({ children }) {
  return <article className="card">{children}</article>;
}
Card.Title = function Title({ children }) {
  return <h2>{children}</h2>;
};
Card.Price = function Price({ amount }) {
  return <p>{amount} €</p>;
};

<Card>
  <Card.Title>React Advanced</Card.Title>
  <Card.Price amount={49} />
</Card>

مثال 2: Tabs مع سياق

const TabsContext = createContext(null);

function Tabs({ children, defaultValue }) {
  const [value, setValue] = useState(defaultValue);
  return (
    <TabsContext.Provider value={{ value, setValue }}>
      {children}
    </TabsContext.Provider>
  );
}

مثال 3: زر التبويب

function Tab({ id, children }) {
  const { value, setValue } = useContext(TabsContext);
  const selected = value === id;
  return (
    <button type="button" aria-selected={selected} onClick={() => setValue(id)}>
      {children}
    </button>
  );
}

ملخص الجلسة

  • التركيب أوضح من قائمة flags
  • سياق المجموعة ≠ حالة التطبيق كله
  • القطع المسماة توثّق الواجهة

واجب الجلسة

  • ابنِ Accordion مركّب (Item, Header, Panel)
  • بطاقة كورس بالسعر € واسم المدرب
  • لا تستخدم prop اسمه renderHeader إن أمكن بالأبناء
