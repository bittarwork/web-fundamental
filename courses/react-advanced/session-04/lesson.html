هدف الجلسة

نمرّر مراجع للمدخلات، نعرض النوافذ فوق الشجرة، ونولّد معرّفات وصول مستقرة.

04

الشرح النظري

1) forwardRef

المكوّن الدالة لا يستقبل ref كـ prop عادي. forwardRef يمرّر المرجع إلى عنصر DOM داخلي — أساس حقل Accordion أو Input في مكتبة.

2) useImperativeHandle

تعرّض واجهة محدودة للأب (focus, clear) بدل العنصر الخام. استخدمه نادراً.

3) Portals

createPortal يرسم الأبناء في عقدة DOM خارج الأب — ضروري للـ Modal حتى لا يقصّه overflow.

تشبيه: المحتوى يعيش في React تحت App، لكن النافذة تُعلَّق على document.body.

4) useId

معرّف مستقر يربط label بالحقل ويتوافق مع التصيير على السيرفر لاحقاً. لا تستخدمه كمفتاح قائمة.

💻

أمثلة عملية

مثال 1: Input مع ref

const TextField = forwardRef(function TextField({ label, ...props }, ref) {
  const id = useId();
  return (
    <div>
      <label htmlFor={id}>{label}</label>
      <input id={id} ref={ref} {...props} />
    </div>
  );
});

مثال 2: تركيز من الأب

const inputRef = useRef(null);
<button type="button" onClick={() => inputRef.current.focus()}>Focus</button>
<TextField ref={inputRef} label="Trainer" defaultValue="Osama Bittar" />

مثال 3: Modal عبر Portal

function Modal({ children }) {
  return createPortal(
    <div className="modal-root">{children}</div>,
    document.getElementById("modal-root")
  );
}

تمارين عملية

1 حقل مع label

ابنِ TextField بـ forwardRef وuseId.

انظر مثال 1 ثم صدّر المكوّن.

2 نافذة سعر

Modal يعرض «React Advanced — 49 €».

<Modal><p>React Advanced — 49 €</p></Modal>

3 واجهة محدودة

عرّض clear() عبر useImperativeHandle.

useImperativeHandle(ref, () => ({
  clear() { inputRef.current.value = ""; }
}));
📌

ملخص الجلسة

  • forwardRef للمكتبات والحقول
  • Portal يفك الارتباط البصري بالأب
  • useId للوصولية لا للقوائم

واجب الجلسة

  • أضف div#modal-root في index.html
  • ابنِ Dialog يُغلق بزر ويُركّز الحقل عند الفتح
  • لا تستخدم id ثابت مكرر في القائمة
