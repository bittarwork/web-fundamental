هدف الجلسة

نستخدم memo وuseMemo وuseCallback بعد أن نرى مشكلة حقيقية في Profiler، لا كزينة على كل ملف.

03

الشرح النظري

1) القياس أولاً

React Developer Tools → Profiler يسجّل أي مكوّن أعيد رسمه ولماذا. حسّن الأغلى لا كل شيء.

2) React.memo

يتخطى رسم الابن إن كانت props بنفس المرجع/القيمة. مفيد لابن ثقيل تحت أب كثير الرسم.

3) useCallback

يثبّت مرجع الدالة حتى لا يكسر memo في الابن. بلا ابن مُمَوَّه غالباً لا فائدة.

4) useMemo

يحفظ نتيجة حساب مكلف (فلترة 2000 كورس) أو مرجعاً يمرَّر لطفل مُمَوَّه. الحساب الرخيص أسرع بدونه.

تحسين مبكر يزيد التعقيد ويخلق اعتماداً ناقصاً في المصفوفات.

5) تكلفة الذاكرة

كل memo يخزّن نتيجة سابقة. لا تغلف أيقونة صغيرة. ابدأ بتقسيم المكوّنات ومفاتيح صحيحة.

💻

أمثلة عملية

مثال 1: ابن ثقيل

const CourseTable = memo(function CourseTable({ rows }) {
  console.log("table render");
  return rows.map((row) => <tr key={row.id}><td>{row.title}</td></tr>);
});

مثال 2: تثبيت المعالج

const onSelect = useCallback((id) => {
  setSelectedId(id);
}, []);

مثال 3: فلترة مكلفة

const visible = useMemo(() => {
  return courses.filter((item) => item.trainer === "Osama Bittar");
}, [courses]);

تمارين عملية

1 Profiler

سجّل نقرة زر بحث وحدد أغلى مكوّن.

افتح Profiler → Record → تفاعل → أوقف. ابحث عن الأشرطة الطويلة.

2 memo لبطاقة

غلّف CourseCard بـ memo ومرّر كائناً سعراً ثابتاً.

const CourseCard = memo(function CourseCard({ title, price }) {
  return <p>{title}: {price} €</p>;
});

3 متى لا؟

اذكر حالة useMemo غير مفيدة.

تجميع جملة ترحيب Hello Osama — أرخص من تكلفة الخطاف نفسه.

ملخص الجلسة

  • قِس ثم حسّن
  • memo يحمي ابناً ثقيلاً
  • المراجع الجديدة في props تكسر الحماية

واجب الجلسة

  • أضف Profiler لمشروع Vite السابق
  • حسّن قائمة واحدة فقط بعد القياس
  • اكتب تعليقاً إنجليزياً يشرح لماذا أضفت memo
