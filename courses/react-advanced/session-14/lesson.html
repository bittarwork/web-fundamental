هدف الجلسة

ننظّم المشروع حسب الميزات لا حسب نوع الملف فقط، ونجهّز نمط جلسة بسيط وProfiler للمشروعين.

14

الشرح النظري

1) Feature folders

features/courses فيها الصفحات والمكوّنات وhooks الخاصة بالكورسات. shared للأشياء العامة.

2) نمط الجلسة

SessionProvider يقرأ user من memory أو localStorage للتدريب. RequireSession يستهلكه. لا تخزّن توكنات حقيقية في هذا الكورس.

3) Profiler قبل المشروع

اعرف خط الأساس: أي صفحة بطيئة قبل أن تضيف memo عشوائي.

4) البيئة

VITE_API_URL كما في الكورس الأساسي. ف bulk import للمسارات.

تشبيه: كل ميزة شقة في المبنى · المشتركة الممر والكهرباء.

مثال 2: جلسة تدريبية

const SessionContext = createContext(null);

export function SessionProvider({ children }) {
  const [user, setUser] = useState(null);
  function signIn() {
    setUser({ name: "Osama Bittar" });
  }
  function signOut() {
    setUser(null);
  }
  return (
    <SessionContext.Provider value={{ user, signIn, signOut }}>
      {children}
    </SessionContext.Provider>
  );
}
