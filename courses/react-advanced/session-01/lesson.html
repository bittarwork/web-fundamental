هدف الجلسة

نفهم متى يعيد React تشغيل المكوّن، كيف يطابق العناصر بالمفاتيح، ولماذا Strict Mode يضاعف الآثار في التطوير.

01

الشرح النظري

1) Render مقابل Commit

استدعاء الدالة (render) يحسب JSX الجديد. ثم مرحلة Commit تلمس الـ DOM. ليس كل render يغيّر الشاشة إن كانت النتيجة نفسها.

تشبيه: الرسم = إعداد قائمة الطعام · الـ Commit = تقديم الصحون على الطاولة.

2) متى يُعاد التشغيل؟

  • تغيّر state أو context يستهلكه المكوّن.
  • إعادة رسم الأب تعيد رسم الأبناء بشكل افتراضي.
  • تغيير key يفكّ المكوّن ويعيد إنشاءه من صفر.

3) Reconciliation والمفاتيح

React يقارن نوع العنصر والـ key ليعرف: تحديث أم استبدال. مفتاح غير مستقر (index في قائمة تُرتَّب) يسبب أخطاء حالة مثل حقل إدخال يقفز.

لا تستخدم Math.random() كمفتاح. يتغيّر كل رسم فيُدمَّر المكوّن دائماً.

4) تجميع التحديثات (Batching)

عدة setState في نفس الحدث تُجمع في رسم واحد. في React 18 يُجمع أيضاً داخل الوعود والمهلات في كثير من الحالات.

5) Strict Mode

في التطوير قد يُركَّب المكوّن مرتين لاكتشاف آثار بلا cleanup. الإنتاج مرة واحدة. جهّز useEffect دائماً بدالة تنظيف.

أمثلة عملية

مثال 1: الأب يعيد رسم الابن

function AcademyBoard() {
  const [tick, setTick] = useState(0);
  return (
    <div>
      <button onClick={() => setTick((n) => n + 1)}>Refresh {tick}</button>
      <TrainerName />
    </div>
  );
}

function TrainerName() {
  console.log("TrainerName render");
  return <p>Osama Bittar</p>;
}

مثال 2: key يعيد إنشاء الحقل

<input key={selectedCourseId} defaultValue="" />

عند تغيّر الكورس يُفرَّغ الحقل لأن المكوّن جديد — مفيد أو مؤذٍ حسب النية.

مثال 3: قائمة بأسعار €

{courses.map((course) => (
  <li key={course.id}>{course.title} — {course.price} €</li>
))}

تمارين عملية

1 مفتاح ثابت

اعرض ثلاث بطاقات كورس بمفتاح id لا index.

{items.map((item) => (
  <CourseCard key={item.id} title={item.title} />
))}

2 إعادة ضبط بنقل key

عند تبديل المدرب اجعل نموذج الاسم يُعاد بمفتاح اسم المدرب.

<NameForm key={trainerId} />

3 لاحظ الرسم

ضع console.log في ابن واضغط زر في الأب. اشرح لماذا طُبع السطر.

لأن إعادة رسم الأب تعيد تشغيل دالة الابن ما لم تمنعه لاحقاً بـ memo.
