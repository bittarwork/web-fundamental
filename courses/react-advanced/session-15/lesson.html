15

الشرح النظري

1) المنتج

لوحة باسم Osama Bittar تعرض كورسات بأسعار €. الدخول وهمي. القائمة، التفاصيل، والإعدادات داخل تخطيط جانبي.

2) Architecture

  • RequireSession حول /desk
  • search params للبحث والحد الأدنى للسعر
  • useCachedCourses للقائمة
  • SectionBoundary حول التفاصيل
  • lazy لصفحات اللوحة

3) ترتيب التنفيذ

مسارات وهيكل → جلسة → قائمة → فلاتر URL → تفاصيل مع abort → ثم تجميل.

لا تبدأ بالثيم. التدفق أولاً: دخول → قائمة → تفاصيل → رجوع مع بقاء الفلتر.
