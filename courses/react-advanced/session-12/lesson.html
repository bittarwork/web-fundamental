هدف الجلسة

نبني معالج تسجيل/حجز من ثلاث خطوات مع تحقق لكل خطوة ومسودة في state واحد.

12

الشرح النظري

1) State واحد للمعالج

غرض draft: الخطوة الحالية، الحقول، الأخطاء. أو useReducer إن تشعّب المنطق.

2) تحقق لكل خطوة

لا تنتقل من الهوية إلى الدفع إن كان الاسم فارغاً. تحقق الخطوة الأخيرة قبل الإرسال.

3) مصفوفة حقول

قائمة مقاعد أو مشاركين: أضف/احذف صفوفاً في المصفوفة بنسخ جديدة.

4) ملخص قبل التأكيد

اعرض الاسم، التاريخ، والسعر الإجمالي باليورو.

💻

أمثلة عملية

مثال 1: خطوات

const [step, setStep] = useState(1);
const [draft, setDraft] = useState({
  name: "Osama Bittar",
  seats: 1,
  email: ""
});

مثال 2: منع التقدم

function next() {
  if (step === 1 && !draft.name.trim()) {
    setError("Name is required");
    return;
  }
  setError("");
  setStep((n) => n + 1);
}

مثال 3: الإجمالي

const price = 29;
const total = price * draft.seats;
