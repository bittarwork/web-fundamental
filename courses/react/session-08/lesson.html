هدف الجلسة

ننفّذ Side Effects بعد الرسم: تغيير عنوان الصفحة، الاشتراك بمؤقت، أو التحضير لجلب بيانات. نفهم مصفوفة الاعتماد ودالة التنظيف.

08

الشرح النظري

1) Side Effects

رسم JSX عمل نقي قدر الإمكان. أي تواصل مع الخارج أثر جانبي: document.title، setInterval، fetch، مستمع على النافذة.

هذه الأعمال لا تُكتب مباشرة في جسم المكوّن بلا ضوابط — نضعها في useEffect.

2) useEffect

import { useEffect } from "react";

useEffect(() => {
  // runs after render
}, [dependencies]);

3) Dependency Array

  • [] — مرة بعد أول رسم (يشبه «عند التحميل»).
  • [query] — بعد أول رسم وكلما تغيّر query.
  • بدون مصفوفة — بعد كل رسم (نادراً ما تريده).
ضع في المصفوفة كل قيمة من المكوّن تستخدمها داخل الأثر. إغفالها يسبب قيماً قديمة أو حلقات لا نهائية.

4) مفهوم دورة الحياة

المكوّن يُركَّب (mount) ثم يتحدّث (update) ثم يُزال (unmount). useEffect يغطي هذه اللحظات: التشغيل بعد الرسم، وإعادة التشغيل عند تغيّر الاعتماد، والتنظيف قبل الإزالة أو قبل إعادة التشغيل.

Mount

أول رسم ثم أثر بمصفوفة [] — مناسب لعنوان الصفحة أو بدء الجلب.

Update

تغيّر قيمة في المصفوفة يعيد تشغيل الأثر — مناسب للبحث أو id الصفحة.

React Strict Mode (Vite): في وضع التطوير قد يُركَّب المكوّن مرتين لاكتشاف الآثار غير النظيفة. لذلك cleanup ضروري حتى لا يتكرر المؤقت. في الإنتاج يعمل مرة واحدة.

5) Cleanup Functions

إذا بدأت مؤقتاً أو أضفت مستمعاً، أرجع دالة تلغيه. وإلا يتكرر العداد بعد كل رسم أو بعد مغادرة الصفحة.

حلقة لا نهائية: استدعاء setState داخل الأثر بدون اعتماد صحيح يعيد الرسم فيعيد الأثر فيعيد setState. راجع المصفوفة فوراً.
💻

أمثلة عملية

مثال 1: عنوان الصفحة مرة واحدة

useEffect(() => {
  document.title = "React — Osama Bittar";
}, []);

مثال 2: العنوان يتبع الحالة

const [session, setSession] = useState(1);

useEffect(() => {
  document.title = "Session " + session;
}, [session]);

مثال 3: مؤقت مع تنظيف

useEffect(() => {
  const id = setInterval(() => {
    console.log("tick");
  }, 1000);

  return () => {
    clearInterval(id);
  };
}, []);

مثال 4: محاكاة تحميل بيانات عند فتح المكوّن

useEffect(() => {
  console.log("Load courses for Osama");
  // fetch will come in the next session
}, []);

مثال 5: مستمع نافذة مع تنظيف

useEffect(() => {
  function onResize() {
    console.log(window.innerWidth);
  }

  window.addEventListener("resize", onResize);
  return () => {
    window.removeEventListener("resize", onResize);
  };
}, []);

✏️

تمارين عملية

1 عنوان ترحيبي

عند التحميل اجعل عنوان التبويب «Welcome Osama».

useEffect(() => {
  document.title = "Welcome Osama";
}, []);

2 عدّاد ثوانٍ

زد رقماً كل ثانية ونظّف المؤقت عند المغادرة.

useEffect(() => {
  const id = setInterval(() => setSeconds((s) => s + 1), 1000);
  return () => clearInterval(id);
}, []);

3 أثر يتبع البحث

كلما تغيّر query اطبع في Console «Search: ...».

useEffect(() => {
  console.log("Search:", query);
}, [query]);

ملخص الجلسة

  • الآثار الجانبية بعد الرسم عبر useEffect
  • المصفوفة تتحكم بمتى يُعاد التشغيل
  • [] ≈ عند التحميل · [x] عند تغيّر x
  • أرجع cleanup للمؤقتات والمستمعات

واجب الجلسة

  • غيّر عنوان الصفحة حسب رقم الجلسة في state
  • أضف مؤقتاً مع clearInterval
  • اكتب في تعليق متى ستستخدم [] ومتى ستضع قيمة داخل المصفوفة
