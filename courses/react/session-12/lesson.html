هدف الجلسة

نشارك بيانات بين أجزاء بعيدة من الشجرة دون Prop Drilling: createContext و Provider و useContext.

12

الشرح النظري

1) مفهوم Global State

بعض البيانات تخص التطبيق كله: اسم المستخدم الحالي، اللغة، الوضع الليلي، سلة التسجيل. تمريرها عبر خمسة آباء متعبة وعرضة للأخطاء.

Props

مناسبة للأب المباشر والابن. واضحة ومحدودة.

Context

مناسبة لقيم مشتركة بعيدة. لا تستخدمها لكل حقل صغير.

2) createContext

ننشئ حاوية: const TrainerContext = createContext(null). القيمة الابتدائية تظهر إذا قرأ مكوّن السياق بلا Provider.

3) Provider

<TrainerContext.Provider value={...}> يغلّف الشجرة ويمرّر القيمة لكل الأبناء. غالباً القيمة غرض: البيانات + دوال التحديث.

أين نضع Provider؟ أقرب مستوى يغطي كل من يحتاج البيانات — غالباً حول التخطيط أو App، لا حول زر واحد.

4) useContext

الابن البعيد يستدعي useContext(TrainerContext) ويحصل على القيمة دون props وسيطة.

5) مشاركة البيانات بين Components

الهيدر يعرض اسم المدرب، والفوتر يعرضه، وصفحة الكورسات تستخدمه في البطاقة — مصدر واحد في Provider.

لا تضع كل التطبيق في Context واحد ضخم. اقسم السياقات حسب الموضوع: مستخدم، سلة، إعدادات. أي تغيير في value يعيد رسم المستهلكين.
تشبيه: الراديو في المبنى (Context) يصل لكل الغرف. الهاتف الداخلي (Props) يكفي لغرفتين متجاورتين.

أمثلة عملية

مثال 1: إنشاء السياق والملف

import { createContext, useContext, useState } from "react";

const TrainerContext = createContext(null);

export function TrainerProvider({ children }) {
  const [trainer] = useState({
    name: "Osama Bittar",
    city: "Damascus"
  });

  return (
    <TrainerContext.Provider value={trainer}>
      {children}
    </TrainerContext.Provider>
  );
}

export function useTrainer() {
  const value = useContext(TrainerContext);
  if (!value) {
    throw new Error("useTrainer must be used inside TrainerProvider");
  }
  return value;
}

مثال 2: تغليف التطبيق

<TrainerProvider>
  <BrowserRouter>
    <App />
  </BrowserRouter>
</TrainerProvider>

مثال 3: القراءة في الهيدر والبطاقة

function Header() {
  const trainer = useTrainer();
  return <p>Academy · {trainer.name}</p>;
}

function CourseCard() {
  const trainer = useTrainer();
  return <p>Taught by {trainer.name}</p>;
}

مثال 4: سياق مع دالة تحديث (سمة)

function ThemeProvider({ children }) {
  const [theme, setTheme] = useState("light");

  function toggleTheme() {
    setTheme((current) => (current === "light" ? "dark" : "light"));
  }

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}

تمارين عملية

1 سياق مدرب

Provider يمرّر name: Osama Bittar. الهيدر يقرأه بـ useContext.

const trainer = useContext(TrainerContext);
return <span>{trainer.name}</span>;

2 تبديل سمة

زر في الإعدادات يغيّر theme عبر دالة من السياق، والتخطيط يقرأ القيمة.

const { theme, toggleTheme } = useContext(ThemeContext);
<body className={theme}>
  <button onClick={toggleTheme}>Toggle</button>
</body>

3 حماية الخطاف

إن استُدعي useTrainer خارج Provider ارمِ خطأ واضحاً.

if (!value) {
  throw new Error("useTrainer must be used inside TrainerProvider");
}

ملخص الجلسة

  • Context للحالة المشتركة البعيدة لا لكل prop
  • createContext ثم Provider ثم useContext
  • مرّر البيانات ودوال التحديث في value
  • اقسم السياقات حسب الموضوع
