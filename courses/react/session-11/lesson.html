هدف الجلسة

نبني صفحات تفاصيل تعتمد على معاملات الرابط: Dynamic Routes و useParams و useNavigate وقراءة الـ URL.

11

الشرح النظري

1) Dynamic Routes

مسار واحد يغطي عناصر كثيرة: /courses/:courseId بدل مسار منفصل لكل كورس. الجزء بعد النقطتين اسم المعامل.

تشبيه: قالب بطاقة تفاصيل واحد، والرقم على الرابط يخبرنا أي كورس نعرض.

2) useParams

const { courseId } = useParams() يقرأ القيمة من الرابط. النوع نص دائماً: حوّله لرقم عند المقارنة إن لزم Number(courseId).

3) صفحات التفاصيل

القائمة تعرض روابط /courses/1، /courses/2. صفحة التفاصيل تأخذ المعامل ثم تجلب العنصر أو تبحث عنه في مصفوفة. إن لم يوجد العنصر اعرض «غير موجود» أو 404.

4) التعامل مع Parameters في URL

المعامل جزء من المسار. يمكن دمجه مع fetch: عندما يتغيّر courseId أعد الجلب في useEffect مع الاعتماد [courseId].

لا تخلط: query مثل ?q=react يختلف عن param المسار. هذه الجلسة تركز على :id.

5) useNavigate

تنقّل برمجي بعد حدث: حفظ نموذج، زر رجوع، أو بعد حذف عنصر. navigate("/courses") أو navigate(-1) للرجوع خطوة.

أمثلة عملية

مثال 1: مسار ديناميكي

<Route path="courses" element={<CoursesPage />} />
<Route path="courses/:courseId" element={<CourseDetailsPage />} />

مثال 2: قراءة المعامل وعرض التفاصيل

import { useParams, Link } from "react-router-dom";

function CourseDetailsPage() {
  const { courseId } = useParams();

  return (
    <article>
      <h1>Course #{courseId}</h1>
      <p>Trainer: Osama Bittar</p>
      <p>Price: 49 €</p>
      <Link to="/courses">Back to list</Link>
    </article>
  );
}

مثال 3: روابط من القائمة

{courses.map((course) => (
  <li key={course.id}>
    <Link to={"/courses/" + course.id}>{course.title}</Link>
  </li>
))}

مثال 4: تنقّل بعد إرسال نموذج

import { useNavigate } from "react-router-dom";

function EnrollForm() {
  const navigate = useNavigate();

  function handleSubmit(event) {
    event.preventDefault();
    navigate("/courses");
  }

  return (
    <form onSubmit={handleSubmit}>
      <button type="submit">Save and go to courses</button>
    </form>
  );
}

مثال 5: جلب التفاصيل حسب الـ id

const { courseId } = useParams();

useEffect(() => {
  async function load() {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/posts/" + courseId
    );
    if (!response.ok) {
      setError("Course not found");
      return;
    }
    const data = await response.json();
    setCourse(data);
  }

  load();
}, [courseId]);

تمارين عملية

1 تفاصيل منشور

مسار /posts/:postId يعرض رقم المنشور من useParams.

const { postId } = useParams();
return <h1>Post {postId}</h1>;

2 زر رجوع

زر يستدعي navigate(-1).

const navigate = useNavigate();
<button type="button" onClick={() => navigate(-1)}>Back</button>

3 عنصر مفقود

إن لم يوجد الكورس في المصفوفة اعرض نصاً ورابطاً للقائمة.

const course = list.find((item) => String(item.id) === courseId);
if (!course) {
  return (
    <p>
      Not found. <Link to="/courses">All courses</Link>
    </p>
  );
}

ملخص الجلسة

  • مسار :id يغطي تفاصيل كثيرة بقالب واحد
  • useParams يقرأ المعامل من الرابط
  • useNavigate للتنقّل بعد حدث
  • أعد الجلب عندما يتغيّر المعامل

واجب الجلسة

  • قائمة كورسات مع رابط لكل عنصر إلى /courses/:id
  • صفحة تفاصيل: العنوان، Osama Bittar، السعر باليورو، زر رجوع
  • بعد «تسجيل اهتمام» انتقل إلى /courses بـ useNavigate
