هدف الجلسة

ننتقل من صفحات HTML/CSS/JS التقليدية إلى React: نفهم المكتبة، مفهوم SPA، ننشئ أول مشروع بـ Vite، ونكتب أول JSX.

01

الشرح النظري

ملاحظة: أمثلة الكورس تستخدم اسم Osama Bittar كمرجع موحّد لجميع الطلاب.

1) ما هي React؟

React مكتبة JavaScript لبناء واجهات المستخدم من قطع صغيرة اسمها Components. بدل ما تكتب صفحة طويلة في ملف واحد، تقسّم الواجهة إلى أجزاء: رأس، بطاقة، زر، نموذج — وكل جزء له ملف وكود واضح.

تشبيه: HTML التقليدي = بناء البيت حجراً حجراً في مكانه. React = تصنيع غرف جاهزة (مكوّنات) ثم تركيبها في الصفحة.

2) لماذا نستخدم React؟

  • إعادة الاستخدام: الزر أو البطاقة يُكتبان مرة ويُستخدمان في أكثر من مكان.
  • تحديث الواجهة: لما تتغير البيانات، React تعيد رسم الجزء المطلوب.
  • تنظيم المشروع: كل مكوّن مسؤول عن جزء واحد — أسهل للقراءة والتعديل.
  • منظومة واسعة: Routing، نماذج، جلب بيانات — كلها تُبنى فوق نفس الفكرة.

3) مفهوم SPA — Single Page Application

في الموقع التقليدي كل رابط يحمّل صفحة HTML جديدة من السيرفر. في SPA المتصفح يحمّل التطبيق مرة، وبعدها التنقّل يبدّل المحتوى بدون إعادة تحميل كاملة للصفحة.

موقع متعدد الصفحات

كل رابط = طلب جديد + وميض أبيض + إعادة تحميل CSS وJS.

SPA

رابط يتغير، والمحتوى يتبدّل داخل نفس الصفحة — أسرع وأسلس.

مهم: SPA لا تعني أن التطبيق صفحة واحدة بالمعنى البصري. تعني أن المتصفح يدير عدة «شاشات» داخل تطبيق واحد.

4) إنشاء المشروع باستخدام Vite

Vite أداة حديثة لتشغيل مشروع React بسرعة أثناء التطوير. نستخدمها بدل الإعداد اليدوي المعقّد.

  1. افتح Terminal داخل مجلد مشاريعك.
  2. نفّذ: npm create vite@latest osama-react -- --template react
  3. ادخل للمجلد: cd osama-react
  4. ثبّت الحزم: npm install
  5. شغّل المشروع: npm run dev وافتح الرابط في المتصفح.
تذكير: تحتاج Node.js مثبتاً على الجهاز قبل Vite. تأكد بكتابة node -v في Terminal.

5) Project Structure — هيكل الملفات

  • index.html — الصفحة الوحيدة التي يفتحها المتصفح.
  • src/main.jsx — نقطة الدخول: تربط React بعنصر في الصفحة.
  • src/App.jsx — المكوّن الرئيسي للتطبيق.
  • src/index.css — تنسيقات عامة.
  • package.json — اسم المشروع والحزم والأوامر.
  • public/ — ملفات ثابتة مثل الأيقونات.

6) JSX — JavaScript + XML

JSX يسمح بكتابة شكل الواجهة داخل JavaScript، فيبدو مثل HTML لكنه ليس HTML. المتصفح لا يفهم JSX مباشرة؛ Vite يحوّله إلى استدعاءات JavaScript قبل التشغيل.

  • يجب إرجاع عنصر واحد جذر (أو Fragment <>...</>).
  • استخدم className بدل class.
  • التعابير تُكتب بين أقواس: {name}.
  • معظم الوسوم تُغلق: <img />.

أمثلة عملية

مثال 1: ربط React بالصفحة

src/main.jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);

العنصر #root موجود في index.html — React ترسم داخله كل التطبيق.

مثال 2: أول مكوّن

src/App.jsx
function App() {
  return (
    <main>
      <h1>Welcome Osama Bittar</h1>
      <p>This is my first React app.</p>
    </main>
  );
}

export default App;
📤 النتيجة على الشاشة
Welcome Osama Bittar
This is my first React app.

مثال 3: تعابير داخل JSX

JSX expressions
const trainer = "Osama Bittar";
const hours = 32;

function App() {
  return (
    <p>
      Trainer: {trainer} — Course hours: {hours + 8}
    </p>
  );
}
📤 النتيجة
Trainer: Osama Bittar — Course hours: 40

مثال 4: className وليس class

JSX attribute
function Badge() {
  return <span className="chip">React Course</span>;
}
خطأ شائع: class كلمة محجوزة في JavaScript. لذلك JSX يستخدم className.

تمارين عملية

1 إنشاء المشروع

أنشئ مشروع Vite بالقالب react وشغّله محلياً حتى تظهر الصفحة الافتراضية.

npm create vite@latest osama-react -- --template react
cd osama-react
npm install
npm run dev

2 تخصيص App

عدّل App.jsx ليعرض عنواناً باسم المدرب وفقرة عن كورس React.

function App() {
  const name = "Osama Bittar";
  return (
    <section>
      <h1>{name}</h1>
      <p>Modern Front-End with React.</p>
    </section>
  );
}

export default App;

3 تعبير حسابي في JSX

اعرض عدد الجلسات 16 ومدة كل جلسة 120، واطبع إجمالي الدقائق بين أقواس JSX.

const sessions = 16;
const minutes = 120;

<p>Total minutes: {sessions * minutes}</p>
// Total minutes: 1920

ملخص الجلسة

  • React تبني الواجهة من Components قابلة لإعادة الاستخدام
  • SPA تبدّل المحتوى دون إعادة تحميل كاملة للصفحة
  • Vite هو أداة التطوير الحديثة لإنشاء وتشغيل مشروع React
  • المهم في الهيكل: main.jsx و App.jsx
  • JSX يشبه HTML لكن يستخدم className و { }

واجب الجلسة

  • ثبّت Node.js وتأكد من node -v
  • أنشئ مشروع Vite واحفظ رابطه وهو يعمل على جهازك
  • احذف المحتوى الافتراضي من App.jsx واكتب ترحيباً باسم Osama Bittar
  • اقرأ ملفات index.html و main.jsx وحدّد أين يظهر root
