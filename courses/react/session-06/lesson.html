هدف الجلسة

نبني نماذج Controlled Components: قيمة الحقل من State، والتحديث من onChange، مع تحقق أساسي قبل الإرسال.

06

الشرح النظري

1) Forms في React

النموذج يجمع بيانات المستخدم: اسم، بريد، رسالة. في React نربط كل حقل بـ state حتى تبقى الواجهة والكود على نفس القيمة.

2) Inputs و onChange

event.target.value يعطي النص الحالي. نحدّث state في onChange فيظهر فوراً في الحقل.

3) Controlled Components

الحقل مُتحكَّم به عندما تكون value={state} وonChange يحدّث ذلك الـ state. React هي مصدر الحقيقة، لا المتصفح وحده.

Controlled

value من React · سهل التحقق والعرض والمعاينة الحية.

Uncontrolled

المتصفح يمسك القيمة · نقرأه أحياناً بـ ref (جلسة لاحقة).

4) التعامل مع بيانات المستخدم

امنع السلوك الافتراضي للإرسال بـ event.preventDefault() حتى لا تُحدَّث الصفحة وتضيع الحالة.

5) Form Validation أساسي

  • حقل فارغ بعد القصّ: trim()
  • البريد يحتوي @
  • عرض رسالة خطأ تحت الحقل من state مثل error

أمثلة عملية

مثال 1: حقل اسم متحكم به

function NameField() {
  const [name, setName] = useState("Osama");

  return (
    <label>
      Name
      <input
        value={name}
        onChange={(event) => setName(event.target.value)}
      />
    </label>
  );
}

مثال 2: إرسال نموذج تواصل

function ContactForm() {
  const [email, setEmail] = useState("");
  const [message, setMessage] = useState("");

  function handleSubmit(event) {
    event.preventDefault();
    console.log({ email, message, trainer: "Osama Bittar" });
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="email"
      />
      <textarea
        value={message}
        onChange={(e) => setMessage(e.target.value)}
      />
      <button type="submit">Send</button>
    </form>
  );
}

مثال 3: تحقق أساسي

function handleSubmit(event) {
  event.preventDefault();
  if (!name.trim()) {
    setError("Name is required");
    return;
  }
  if (!email.includes("@")) {
    setError("Enter a valid email");
    return;
  }
  setError("");
  console.log("Saved", name);
}

اعرض {error} تحت النموذج بلون واضح.

تمارين عملية

1 معاينة حية

حقل اسم قيمته الابتدائية Osama، وتحت الحقل فقرة تعرض نفس النص مباشرة.

<input value={name} onChange={(e) => setName(e.target.value)} />
<p>Hello {name}</p>

2 تسجيل كورس

نموذج: الاسم + اختيار المستوى (select) + زر إرسال يطبع البيانات.

<select value={level} onChange={(e) => setLevel(e.target.value)}>
  <option value="beginner">Beginner</option>
  <option value="intermediate">Intermediate</option>
</select>

3 رسالة خطأ

إذا كان الاسم أقصر من 3 أحرف امنع الإرسال وأظهر خطأ.

if (name.trim().length < 3) {
  setError("Name must be at least 3 characters");
  return;
}

ملخص الجلسة
