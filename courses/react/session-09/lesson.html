هدف الجلسة

نجلب بيانات خارجية عبر Fetch داخل useEffect، ونعرض ثلاث حالات واضحة: التحميل، الخطأ، والنتائج داخل المكوّن.

09

الشرح النظري

1) التعامل مع APIs

API مصدر بيانات على الشبكة: قائمة كورسات، تفاصيل جلسة، أسعار باليورو. الواجهة تطلب البيانات، والسيرفر يردّ غالباً بصيغة JSON.

تشبيه: المكوّن يطلب قائمة من مكتب الاستقبال (الـ API)، ثم يعرض البطاقات بعد وصول الرد — لا يخترع القائمة داخل JSX.

2) Fetch API

fetch(url) يعيد Promise. نستخدم async/await داخل دالة، ثم response.json() لتحويل الجسم إلى كائن JavaScript.

مهم: نجاح الشبكة لا يعني نجاح الطلب. افحص response.ok قبل قراءة JSON.

3) GET Requests

GET للقراءة فقط: قائمة أو عنصر واحد. لا جسم في الطلب عادة. نضعه في useEffect لأن الجلب أثر جانبي بعد الرسم.

أين نكتب fetch؟ داخل useEffect (غالباً بمصفوفة [] أو بقيمة مثل id)، لا في جسم المكوّن مباشرة وإلا يتكرر الطلب مع كل رسم.

4) Loading

قبل وصول البيانات نعرض رسالة أو هيكل فارغ. state شائع: loading يبدأ true ثم يصبح false بعد انتهاء الطلب.

5) Errors

الشبكة قد تفشل، أو السيرفر يرد 404/500. خزّن نص الخطأ في state واعرضه بدل القائمة. لا تترك الشاشة بيضاء.

6) عرض البيانات داخل Components

بعد النجاح ضع المصفوفة في state ثم map إلى بطاقات. إن كانت القائمة فارغة أظهر رسالة «لا نتائج» — ليست خطأ شبكة.

ثلاث حالات واجهة

Loading · Error · Data (وقد تكون فارغة).

تنظيف الطلب

إن غادر المستخدم الصفحة بسرعة، تجاهل النتيجة المتأخرة (flag أو AbortController لاحقاً).

أمثلة عملية

مثال 1: GET بسيط وطباعة JSON

useEffect(() => {
  async function loadPosts() {
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/posts?_limit=5"
    );
    const data = await response.json();
    console.log(data);
  }

  loadPosts();
}, []);

مثال 2: Loading + Error + قائمة

function CourseFeed() {
  const [courses, setCourses] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function load() {
      try {
        setLoading(true);
        setError("");
        const response = await fetch(
          "https://jsonplaceholder.typicode.com/posts?_limit=4"
        );
        if (!response.ok) {
          throw new Error("Could not load courses");
        }
        const data = await response.json();
        setCourses(data);
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }

    load();
  }, []);

  if (loading) return <p>Loading courses...</p>;
  if (error) return <p>Error: {error}</p>;

  return (
    <ul>
      {courses.map((item) => (
        <li key={item.id}>{item.title}</li>
      ))}
    </ul>
  );
}

مثال 4: إعادة المحاولة بزر

const [reload, setReload] = useState(0);

useEffect(() => {
  // fetch lives here
}, [reload]);

<button type="button" onClick={() => setReload((n) => n + 1)}>
  Retry
</button>

تمارين عملية

1 قائمة مستخدمين

اجلب 5 مستخدمين من jsonplaceholder واعرض الاسم والبريد. أظهر Loading أثناء الجلب.

const response = await fetch(
  "https://jsonplaceholder.typicode.com/users?_limit=5"
);
if (!response.ok) throw new Error("Failed");
const users = await response.json();
setUsers(users);

2 بطاقة مدرب

بعد الجلب أضف حقلاً ثابتاً trainer: "Osama Bittar" لكل عنصر قبل العرض.

setItems(
  data.map((row) => ({ ...row, trainer: "Osama Bittar" }))
);

3 رسالة خطأ واضحة

إن فشل الطلب اعرض نصاً وزر Retry يعيد تشغيل الأثر.

if (error) {
  return (
    <div>
      <p>{error}</p>
      <button onClick={() => setReload((n) => n + 1)}>Retry</button>
    </div>
  );
}
