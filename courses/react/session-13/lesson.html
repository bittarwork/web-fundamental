الشرح النظري

1) مفهوم Reducer

الـ Reducer دالة نقية: تأخذ الحالة الحالية وفعلاً (action)، وترجع حالة جديدة. لا تعدّل الغرض القديم ولا تستدعي fetch داخلها. 

function reducer(state, action) {
  // return next state
}
تشبيه: الصندوق (state) والتعليمات المكتوبة (action). الموظف (reducer) يقرأ التعليمات ويعيد صندوقاً جديداً مرتباً.

2) متى useReducer بدل useState؟

  • عدة حقول تتغيّر معاً (سلة: عناصر، المجموع، الحالة).
  • تحديثات مترابطة يصعب تتبعها عبر عدة setState.
  • منطق واضح يمكن اختباره كدالة مستقلة.

للعداد البسيط أو حقل نموذج واحد ابقَ على useState.

3) useReducer

const [state, dispatch] = useReducer(reducer, initialState);

state القيمة الحالية. dispatch يرسل فعلاً إلى الـ reducer.

4) Actions و Dispatch

الفعل غرض فيه type غالباً نص ثابت، وقد يحمل payload (id، كمية، سعر). 

dispatch({ type: "add_item", payload: { id: 1, title: "React" } });

داخل الـ reducer استخدم switch (action.type) وأرجع نسخة جديدة. أضف default يرجع الحالة كما هي أو يرمي خطأ واضحاً.

ممنوع: state.items.push(...). انسخ المصفوفة: [...state.items, item].

5) دمج useReducer مع Context API

Provider يحتفظ بـ [state, dispatch] ويمرّرهما عبر Context. أي صفحة تضيف للسلة تستدعي dispatch دون رفع الحالة يدوياً عبر كل شجرة المسارات.

خطوة تالية للدورة: هذا النمط أساس المشروع الكبير الثاني (جلسة 16).

أمثلة عملية

مثال 1: عداد بـ reducer

function counterReducer(state, action) {
  switch (action.type) {
    case "inc":
      return { count: state.count + 1 };
    case "dec":
      return { count: state.count - 1 };
    case "reset":
      return { count: 0 };
    default:
      return state;
  }
}

function SeatsBoard() {
  const [state, dispatch] = useReducer(counterReducer, { count: 12 });

  return (
    <div>
      <p>Seats: {state.count}</p>
      <button onClick={() => dispatch({ type: "inc" })}>+</button>
      <button onClick={() => dispatch({ type: "dec" })}>-</button>
    </div>
  );
}

مثال 2: سلة تسجيل كورسات

const initialCart = { items: [] };

function cartReducer(state, action) {
  switch (action.type) {
    case "add": {
      const exists = state.items.some((item) => item.id === action.payload.id);
      if (exists) return state;
      return { items: [...state.items, action.payload] };
    }
    case "remove":
      return {
        items: state.items.filter((item) => item.id !== action.payload)
      };
    case "clear":
      return initialCart;
    default:
      return state;
  }
}

مثال 3: الاستخدام في المكوّن

const [cart, dispatch] = useReducer(cartReducer, initialCart);

dispatch({
  type: "add",
  payload: { id: 1, title: "React", price: 49, trainer: "Osama Bittar" }
});

الأسعار باليورو (€). المجموع: cart.items.reduce((sum, item) => sum + item.price, 0)

مثال 4: CartContext

const CartContext = createContext(null);

export function CartProvider({ children }) {
  const [state, dispatch] = useReducer(cartReducer, initialCart);
  return (
    <CartContext.Provider value={{ state, dispatch }}>
      {children}
    </CartContext.Provider>
  );
}

export function useCart() {
  const value = useContext(CartContext);
  if (!value) throw new Error("useCart must be inside CartProvider");
  return value;
}

ملخص الجلسة

  • Reducer: (state, action) ⇒ state جديد
  • Actions بأنواع واضحة وpayload عند الحاجة
  • useReducer للحالة المترابطة
  • Provider يمرّر state و dispatch معاً
