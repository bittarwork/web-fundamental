هدف الجلسة

نفهم State: بيانات تتغير مع الوقت وتُعيد رسم المكوّن. نتعلّم useState مع قيم بسيطة، أكثر من حالة، ومع Objects وArrays.

05

الشرح النظري

1) مفهوم State

Props تأتي من الخارج ولا تُغيَّر في الابن. State ملك المكوّن: عداد، قائمة مهام، رسالة خطأ — أي قيمة تتبدل بعد تفاعل المستخدم.

تشبيه: Props = اسم الطالب على البطاقة (يأتي من الخارج). State = درجته الحالية في التمرين (تتغير أثناء الجلسة).

2) useState Hook

import { useState } from "react";

const [count, setCount] = useState(0);
  • count القيمة الحالية.
  • setCount الدالة الوحيدة لتغييرها.
  • القيمة الابتدائية تُمرَّر لـ useState(0).
Hooks: تُستدعى في أعلى المكوّن فقط، ليس داخل if أو loops.

3) تحديث State وإعادة الرسم

استدعاء setCount يطلب من React إعادة تشغيل المكوّن بالقيمة الجديدة ثم إعادة رسم JSX. لا تكتب count = count + 1.

إذا اعتمد التحديث على القيمة السابقة استخدم دالة: setCount((current) => current + 1).

4) أكثر من State

يمكنك استدعاء useState أكثر من مرة: اسم، عمر، هل القائمة مفتوحة...

5) Objects و Arrays

State يجب أن يُستبدل بنسخة جديدة لا أن يُعدَّل مباشرة. للأغراض: انسخ بـ spread ثم غيّر الحقل. للمصفوفات: map / filter / spread.

ممنوع: user.name = "Osama" ثم setUser(user) — المرجع نفسه وReact قد لا ترسم.

أمثلة عملية

مثال 1: عداد

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Clicks: {count}</p>
      <button onClick={() => setCount((c) => c + 1)}>+1</button>
    </div>
  );
}

مثال 2: إظهار اسم المدرب

function NameToggle() {
  const [visible, setVisible] = useState(false);

  return (
    <div>
      <button onClick={() => setVisible((v) => !v)}>
        Toggle name
      </button>
      {visible && <p>Osama Bittar</p>}
    </div>
  );
}

مثال 3: أكثر من حالة

function Profile() {
  const [name, setName] = useState("Osama");
  const [city, setCity] = useState("Damascus");

  return (
    <p>{name} · {city}</p>
  );
}

مثال 4: تحديث غرض

function TrainerCard() {
  const [trainer, setTrainer] = useState({
    name: "Osama Bittar",
    hours: 32
  });

  function addHours() {
    setTrainer((current) => ({
      ...current,
      hours: current.hours + 8
    }));
  }

  return (
    <div>
      <p>{trainer.name}: {trainer.hours} h</p>
      <button onClick={addHours}>Add web course hours</button>
    </div>
  );
}

مثال 5: إضافة عنصر لمصفوفة

const [topics, setTopics] = useState(["JSX", "Components"]);

function addTopic() {
  setTopics((current) => [...current, "Props"]);
}

setItems((current) => current.filter((item) => item.id !== id));

ملخص الجلسة

  • State بيانات داخلية تُعيد رسم المكوّن عند التغيير
  • غيّر دائماً عبر setState لا بالتعيين المباشر
  • استخدم الدالة إذا التحديث يعتمد على القيمة السابقة
  • الأغراض والمصفوفات تُستبدل بنسخ جديدة

واجب الجلسة

  • ابنِ عداداً + و − مع عدم النزول تحت 0
  • قائمة مواضيع تُضاف بزر إلى المصفوفة
  • بطاقة مدرب state كغرض مع زر لتحديث حقل واحد
