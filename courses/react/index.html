عن

عن هذه الدورة

دورة عملية متخصصة في تطوير واجهات الويب الحديثة باستخدام React، تبدأ من المفاهيم الأساسية للمكتبة وتنتقل تدريجياً إلى Components وProps وإدارة الحالة باستخدام Hooks، والتعامل مع Routing وAPIs وContext API وuseReducer، وصولاً إلى بناء تطبيقات React متكاملة من خلال مشاريع عملية كبيرة.

المحتوى العلمي مكتمل لكل الجلسات الست عشرة: شرح نظري، أمثلة، اختبارات، تمارين مع حلول، وواجبات. الأمثلة تستخدم اسم المدرب Osama Bittar كمرجع موحّد، والأسعار باليورو (€).
