هدف الجلسة

ندمج الحالة المتقدمة في تطبيق واحد: سلة تسجيل بـ useReducer و Context، مع API و Routing ومكوّنات قابلة لإعادة الاستخدام، ثم نحسّن المشروع ونراجع الكود النهائي.

16

الشرح النظري

1) فكرة المنتج الثاني

Enrollment Desk — مكتب تسجيل: الكتالوج يجلب الكورسات، والطالب يضيف إلى السلة، يراجع العناصر، يحذف، ويُفرغ السلة. الحالة المشتركة عبر Context + Reducer حتى الهيدر يعرض العدد والمجموع باليورو.

2) State Management في هذا المشروع

  • قائمة الكورسات: useState / useEffect (أو خطاف الجلب).
  • نص البحث: محلي في صفحة القائمة.
  • السلة: useReducer داخل CartProvider.

أبقِ محلياً

query، فتح قائمة الجوال، رسالة خطأ نموذج.

ارفع للسلة

العناصر المختارة — الهيدر و /cart وصفحة التفاصيل يحتاجونها.

3) useReducer و Context API معاً

أفعال مقترحة: add، remove، clear. لا تضف نفس الـ id مرتين. Payload العنصر يحتوي id و title و price و trainer: "Osama Bittar".

4) API Integration و Routing

أعد استخدام services من المشروع الأول. صفحات إضافية: /cart تعرض العناصر وأزرار الحذف والمجموع. من التفاصيل: زر «Add to desk» يستدعي dispatch ثم يمكن navigate إلى السلة.

5) Reusable Components

CourseCard، CartItem، PriceLabel (تعرض المبلغ و €)، ErrorBanner، LoadingText. الصفحة لا تعيد كتابة نفس الـ JSX ثلاث مرات.

6) Loading و Errors

القائمة والتفاصيل تبقيان الحالات الثلاث. السلة نفسها لا تحتاج fetch إن كانت الذاكرة المحلية كافية — لكن إن فشل الكتالوج لا تسمح بالإضافة من بيانات ناقصة.

7) تنظيم الكود و Debugging

  • Reducer في ملف مستقل قابل للقراءة.
  • أسماء type واضحة كنصوص ثابتة.
  • React Developer Tools: راقب CartProvider والقيم بعد كل زر.
  • إن لم يتحدّث الهيدر تأكد أن المكوّن داخل Provider.

8) تحسين المشروع ومراجعة الكود النهائي

قبل التسليم اعمل جولة مراجعة:

  • هل المفاتيح في القوائم ids حقيقية؟
  • هل النماذج preventDefault وتتحقق؟
  • هل الأسعار € واسم المدرب موحّد؟
  • هل المسار المجهول يعرض 404؟
  • هل المجلدات تطابق components / pages / services / hooks / context؟
  • هل توجد دوال مكررة يمكن نقلها لخطاف؟
معيار الاكتمال: مستخدم يفتح القائمة، يفتح تفاصيل، يضيف كورسين، يرى المجموع في الهيدر وفي /cart، يحذف واحداً، يُفرغ السلة — بلا أخطاء في Console.

أمثلة عملية

مثال 1: أفعال السلة

function cartReducer(state, action) {
  switch (action.type) {
    case "add": {
      const exists = state.items.some((item) => item.id === action.payload.id);
      if (exists) return state;
      return { items: [...state.items, action.payload] };
    }
    case "remove":
      return {
        items: state.items.filter((item) => item.id !== action.payload)
      };
    case "clear":
      return { items: [] };
    default:
      return state;
  }
}

مثال 2: زر الإضافة من التفاصيل

function AddToDeskButton({ course }) {
  const { dispatch } = useCart();

  function handleAdd() {
    dispatch({
      type: "add",
      payload: {
        id: course.id,
        title: course.title,
        price: course.price,
        trainer: "Osama Bittar"
      }
    });
  }

  return (
    <button type="button" onClick={handleAdd}>
      Add to desk
    </button>
  );
}

مثال 3: شارة الهيدر والمجموع

function CartBadge() {
  const { state } = useCart();
  const total = state.items.reduce((sum, item) => sum + item.price, 0);

  return (
    <Link to="/cart">
      {state.items.length} items · {total} €
    </Link>
  );
}

مثال 4: صفحة السلة

function CartPage() {
  const { state, dispatch } = useCart();

  if (state.items.length === 0) {
    return <p>Your desk is empty.</p>;
  }

  return (
    <section>
      {state.items.map((item) => (
        <CartItem
          key={item.id}
          item={item}
          onRemove={() => dispatch({ type: "remove", payload: item.id })}
        />
      ))}
      <button type="button" onClick={() => dispatch({ type: "clear" })}>
        Clear desk
      </button>
    </section>
  );
}

تمارين عملية

1 ربط السلة

CartProvider حول التطبيق، شارة في الهيدر، مسار /cart.

<CartProvider>
  <BrowserRouter>
    <App />
  </BrowserRouter>
</CartProvider>
<Route path="cart" element={<CartPage />} />

2 منع التكرار

إن أُضيف الكورس مسبقاً لا يتكرر السطر. يمكن تعطيل الزر إن وُجد id.

const already = state.items.some((item) => item.id === course.id);
<button disabled={already} onClick={handleAdd}>
  {already ? "Added" : "Add to desk"}
</button>

3 قائمة مراجعة

طبّق بنود المراجعة في الشرح واكتب ثلاث ملاحظات تحسين وجدتها في كودك.

أمثلة: نقل fetch إلى service، توحيد PriceLabel، إصلاح key={index}، إضافة 404، إزالة console.log قبل التسليم.
