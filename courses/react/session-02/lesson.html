هدف الجلسة

نتعلّم Functional Components: كيف نكتب مكوّناً، كيف نقسم الواجهة، وكيف نصدّر ونستورد المكوّنات لإعادة استخدامها.

02

الشرح النظري

1) Functional Components

المكوّن في React الحديثة هو دالة اسمها يبدأ بحرف كبير، وترجع JSX. كل مرة نستدعيها كأننا نضع قطعة واجهة في الصفحة.

Component rule
function Welcome() {
  return <h1>Hello Osama</h1>;
}
قاعدة: Welcome صح · welcome خطأ — React تعتبر الاسم الصغير عنصر HTML عادي.

2) Component Structure

هيكل المكوّن الواضح:

  1. الاستيرادات في أعلى الملف إن لزم.
  2. الدالة بالمكوّن (اسم كبير).
  3. منطق بسيط قبل الـ return إذا احتجت متغيرات.
  4. return (...JSX...)
  5. export default أو تصدير مسمّى.

3) تقسيم واجهة الموقع

لا تضع الموقع كله في App.jsx. قسّم حسب المعنى: Header، Hero، CourseCard، Footer.

تشبيه: App = غلاف الكتاب · كل Component = فصل مستقل.

4) Reusable Components

المكوّن الجيد يفعل شيئاً واحداً ويمكن وضعه أكثر من مرة. بطاقة كورس واحدة تُعاد لعرض «أساسيات الويب» و«React».

5) Import / Export

export default

تصدير واحد لكل ملف. الاستيراد بأي اسم: import Header from "./Header"

Named export

أكثر من تصدير: export function Logo() ثم import { Logo }

أمثلة عملية

مثال 1: مكوّن ترحيب

src/components/Welcome.jsx
function Welcome() {
  return <h1>Trainer: Osama Bittar</h1>;
}

export default Welcome;

مثال 2: استخدامه داخل App

src/App.jsx
import Welcome from "./components/Welcome";
import Footer from "./components/Footer";

function App() {
  return (
    <>
      <Welcome />
      <Footer />
    </>
  );
}

export default App;

مثال 3: مكوّن يُستخدم مرتين

CourseCard reused
function CourseCard() {
  return (
    <article className="card">
      <h2>Web Course</h2>
      <p>40 hours · 20 sessions</p>
    </article>
  );
}

function App() {
  return (
    <section>
      <CourseCard />
      <CourseCard />
    </section>
  );
}

حالياً البطاقتان متطابقتان. في الجلسة التالية نمرّر بيانات مختلفة عبر Props.

مثال 4: Named export

src/components/Logo.jsx
export function Logo() {
  return <span className="brand-mark">وب</span>;
}
import named
import { Logo } from "./components/Logo";

تمارين عملية

1 Header و Footer

أنشئ مجلداً src/components فيه Header و Footer واستوردهما في App.

// Header.jsx
function Header() {
  return <header><h1>Osama Bittar Academy</h1></header>;
}
export default Header;

// App.jsx
import Header from "./components/Header";
import Footer from "./components/Footer";

2 مكوّن Instructor

مكوّن يعرض اسم المدرب ووظيفته في بطاقة بسيطة.

function Instructor() {
  return (
    <article>
      <h2>Osama Bittar</h2>
      <p>Informatics Engineer · Web Instructor</p>
    </article>
  );
}

3 تقسيم الصفحة

App لا يحتوي إلا على تجميع المكوّنات: Header، Instructor، Footer — بدون نصوص طويلة داخله.

function App() {
  return (
    <>
      <Header />
      <Instructor />
      <Footer />
    </>
  );
}

ملخص الجلسة

  • المكوّن = دالة بحرف كبير ترجع JSX
  • قسّم الواجهة حسب المعنى لا حسب الحجم فقط
  • ملفات المكوّنات في src/components
  • default export لملف بمكوّن واحد · named export لأكثر من تصدير

واجب الجلسة

  • أنشئ 4 مكوّنات: Header، Hero، CourseList، Footer
  • اجمعها في App بدون تكرار HTML طويل
  • سمّ كل ملف بنفس اسم المكوّن
