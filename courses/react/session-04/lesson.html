هدف الجلسة

نتحكم بما يظهر حسب الشرط، نعرض القوائم مع Keys صحيحة، ونربط أزرار المستخدم بـ Event Handlers.

04

الشرح النظري

1) Conditional Rendering

الواجهة تتغير حسب البيانات: رسالة ترحيب إن وُجد اسم، أو تنبيه إن كانت القائمة فارغة.

  • && — أظهر شيئاً إذا الشرط صحيح.
  • العامل الثلاثي ? : — اختيار بين عنصرين.
  • if قبل الـ return لإرجاع JSX مختلف.

2) Lists

نمرّ على مصفوفة بـ map ونرجع عنصراً لكل عنصر بيانات. لا تستخدم حلقة for داخل JSX مباشرة.

3) Keys

key معرّف ثابت يساعد React على معرفة أي عنصر تغيّر. فضّل معرّفاً حقيقياً (id) لا رقم الفهرس إلا للقوائم الثابتة.

تجنّب: key={index} إذا كانت القائمة تُضاف أو تُحذف أو تُرتَّب.

4) Events و Event Handlers

في React نكتب onClick و onChange بـ camelCase. القيمة دالة — لا تستدعِها بأقواس إلا إذا أردت تغليفها.

صحيح

onClick={handleClick} أو onClick={() => greet("Osama")}

خطأ شائع

onClick={handleClick()} يشتغل فوراً عند الرسم لا عند النقر.

أمثلة عملية

مثال 1: شرط &&

function Banner({ isOpen }) {
  return (
    <div>
      {isOpen && <p>Registration is open</p>}
    </div>
  );
}

مثال 2: ثلاثي للترحيب

function Hello({ name }) {
  return (
    <h1>{name ? `Welcome ${name}` : "Welcome guest"}</h1>
  );
}

<Hello name="Osama Bittar" />

مثال 3: قائمة كورسات مع key

const courses = [
  { id: 1, title: "HTML" },
  { id: 2, title: "CSS" },
  { id: 3, title: "JavaScript" }
];

function CourseList() {
  return (
    <ul>
      {courses.map((course) => (
        <li key={course.id}>{course.title}</li>
      ))}
    </ul>
  );
}

مثال 4: زر حدث

function EnrollButton() {
  function handleClick() {
    console.log("Osama enrolled in React");
  }

  return (
    <button type="button" onClick={handleClick}>
      Enroll
    </button>
  );
}

تمارين عملية

1 قائمة فارغة

إذا كانت المصفوفة فارغة اعرض «No courses yet»، وإلا اعرض القائمة.

{courses.length === 0 ? (
  <p>No courses yet</p>
) : (
  <ul>{courses.map((c) => <li key={c.id}>{c.title}</li>)}</ul>
)}

2 map لمدربين

مصفوفة فيها Osama وBittar كعنصرين (id + name) واعرضها.

const people = [
  { id: 1, name: "Osama" },
  { id: 2, name: "Bittar" }
];

{people.map((person) => (
  <li key={person.id}>{person.name}</li>
))}

3 زر مع معامل

عند النقر اطبع «Hello Osama» باستخدام دالة سهمية في onClick.

<button onClick={() => console.log("Hello Osama")}>
  Greet
</button>

ملخص الجلسة

  • && والثلاثي يتحكمان بما يظهر
  • القوائم تُرسم بـ map مع key ثابت
  • الأحداث camelCase: onClick, onChange
  • مرّر الدالة نفسها لا نتيجة استدعائها

واجب الجلسة

  • اعرض قائمة 5 جلسات React مع id و title
  • أضف رسالة إذا كانت القائمة فارغة
  • زر لكل عنصر يطبع عنوان الجلسة في Console
