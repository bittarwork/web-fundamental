هدف الجلسة

نحوّل التطبيق إلى صفحات متعددة عبر React Router: Routes وRoute وLink وNavLink وتخطيط مشترك والتنقّل دون إعادة تحميل.

10

الشرح النظري

1) React Router

في SPA الرابط يتغيّر والمحتوى يتبدّل داخل الصفحة نفسها. React Router يربط عنوان URL بمكوّن صفحة: الرئيسية، الكورسات، عن المدرب. 

npm install react-router-dom

2) Routes و Route

BrowserRouter يغلّف التطبيق. Routes مجموعة مسارات. كل Route يحدد path وelement.

صفحة 404: مسار path="*" يعرض «الصفحة غير موجودة» لأي رابط غير معروف.

3) Link

استخدم <Link to="/courses"> لا <a href> للتنقّل الداخلي. a يعيد تحميل التطبيق ويفقد الـ state.

4) NavLink

مثل Link مع حالة «نشط» للرابط الحالي. مفيد للقائمة: نضيف صنفاً عندما يكون المسار مطابقاً.

5) Layouts

الهيدر والتذييل يتكرران. نضع تخطيطاً فيه القائمة و <Outlet /> مكان الصفحة الحالية. المسارات المتداخلة ترسم الصفحة داخل التخطيط.

تشبيه: التخطيط = إطار الموقع الثابت. Outlet = اللوحة التي تتبدل: الرئيسية ثم الكورسات ثم التواصل.

6) Navigation

التنقّل من القائمة بـ Link/NavLink. في الجلسة التالية نتنقّل برمجياً بـ useNavigate بعد حفظ نموذج مثلاً.

أمثلة عملية

مثال 1: تغليف التطبيق

import { BrowserRouter } from "react-router-dom";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);

مثال 2: مسارات أساسية

import { Routes, Route } from "react-router-dom";

function App() {
  return (
    <Routes>
      <Route path="/" element={<HomePage />} />
      <Route path="/courses" element={<CoursesPage />} />
      <Route path="/about" element={<AboutPage />} />
      <Route path="*" element={<NotFoundPage />} />
    </Routes>
  );
}

مثال 3: Link و NavLink

import { Link, NavLink } from "react-router-dom";

function MainNav() {
  return (
    <nav>
      <Link to="/">Home</Link>
      <NavLink
        to="/courses"
        className={({ isActive }) => (isActive ? "active" : "")}
      >
        Courses
      </NavLink>
      <Link to="/about">Osama Bittar</Link>
    </nav>
  );
}

مثال 4: تخطيط مع Outlet

import { Outlet } from "react-router-dom";

function SiteLayout() {
  return (
    <div>
      <header>Academy — Osama Bittar</header>
      <MainNav />
      <main>
        <Outlet />
      </main>
      <footer>Prices in EUR (€)</footer>
    </div>
  );
}

function App() {
  return (
    <Routes>
      <Route path="/" element={<SiteLayout />}>
        <Route index element={<HomePage />} />
        <Route path="courses" element={<CoursesPage />} />
        <Route path="about" element={<AboutPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Route>
    </Routes>
  );
}

تمارين عملية

1 ثلاث صفحات

Home و Courses و About. About تعرض اسم المدرب Osama Bittar.

<Route path="about" element={<AboutPage />} />

function AboutPage() {
  return <h1>Trainer: Osama Bittar</h1>;
}

2 قائمة نشطة

NavLink لصنف active على الرابط الحالي.

<NavLink
  to="/courses"
  className={({ isActive }) => (isActive ? "active" : "")}
>
  Courses
</NavLink>

3 404

مسار * يعرض «Page not found» مع Link للرئيسية.

<Route path="*" element={<NotFoundPage />} />

function NotFoundPage() {
  return (
    <p>
      Page not found. <Link to="/">Home</Link>
    </p>
  );
}
