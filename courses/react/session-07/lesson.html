هدف الجلسة

عندما يحتاج أخوة مكوّنات لنفس البيانات، نرفع الـ State إلى الأب المشترك ونمرّر القيم ودوال التحديث للأسفل.

07

الشرح النظري

1) مشاركة State

مثال: حقل بحث ومكوّن قائمة نتائج. الاثنان يحتاجان نص البحث. لا نضع نسختين من النص — نضعها في الأب.

2) Lifting State Up

ارفع الحالة إلى أقرب أب مشترك. الأب يحتفظ بـ state ويمرّر:

  • القيمة للعرض: query={query}
  • دالة التغيير: onQueryChange={setQuery}
تشبيه: الأب = لوحة التحكم · الأبناء = شاشات تعرض الأزرار لكنها لا تخزّن القرار وحدها.

3) Parent / Child Communication

  • أب ← ابن: Props (بيانات أو دوال).
  • ابن ← أب: الابن يستدعي دالة مرّرها الأب، مثل onSelect(id).

4) تصميم أفضل للمكوّنات

اسأل: من يحتاج هذه القيمة؟ إذا كان أكثر من مكوّن — المكان الصحيح للأب. إذا كان مكوّن واحد فقط — أبقِ الحالة محلية (حقل مؤقت داخل النموذج مثلاً).

لا ترفع كل شيء. الرفع الزائد يجعل App مثقلاً ويصعّب القراءة.

أمثلة عملية

مثال 1: بحث مشترك

function SearchInput({ value, onChange }) {
  return (
    <input
      value={value}
      onChange={(e) => onChange(e.target.value)}
      placeholder="Search courses"
    />
  );
}

function Results({ query }) {
  return <p>Looking for: {query}</p>;
}

function CourseSearch() {
  const [query, setQuery] = useState("");
  return (
    <section>
      <SearchInput value={query} onChange={setQuery} />
      <Results query={query} />
    </section>
  );
}

مثال 2: الابن يخبر الأب بالاختيار

function SessionItem({ title, onPick }) {
  return (
    <button type="button" onClick={() => onPick(title)}>
      {title}
    </button>
  );
}

function SessionBoard() {
  const [picked, setPicked] = useState("JSX");

  return (
    <div>
      <p>Osama selected: {picked}</p>
      <SessionItem title="Components" onPick={setPicked} />
      <SessionItem title="Hooks" onPick={setPicked} />
    </div>
  );
}

مثال 3: عداد في الأب، أزرار في الأبناء

function Controls({ onInc, onDec }) {
  return (
    <>
      <button onClick={onDec}>-</button>
      <button onClick={onInc}>+</button>
    </>
  );
}

function SeatCounter() {
  const [seats, setSeats] = useState(12);
  return (
    <div>
      <p>Seats left: {seats}</p>
      <Controls
        onInc={() => setSeats((n) => n + 1)}
        onDec={() => setSeats((n) => n - 1)}
      />
    </div>
  );
}

تمارين عملية

1 درجة حرارة

Input في الابن، وعرض «X °C» في ابن آخر. الحالة في الأب.

const [celsius, setCelsius] = useState(20);
<TempInput value={celsius} onChange={setCelsius} />
<TempLabel value={celsius} />

2 اختيار جلسة

قائمة أزرار جلسات، والأب يعرض الجلسة المختارة باسم Osama.

<p>Osama is in: {session}</p>
<SessionButton label="useState" onPick={setSession} />

3 متى لا نرفع؟

اكتب جملة: حالة «القائمة مفتوحة» لأيقونة همبرغر تخص الهيدر فقط تبقى في Header.

لأن لا مكوّن آخر يحتاج معرفة فتح القائمة — الحالة محلية في Header.

ملخص الجلسة

  • ارفع الحالة لأقرب أب مشترك فقط
  • الأب يمرّر القيمة ودالة التحديث
  • الابن يبلغ الأب باستدعاء onSomething
  • الحالة الخاصة تبقى محلية

واجب الجلسة

  • ابنِ فلتر كورسات: حقل بحث + قائمة نتائج يشاركان query
  • زر في عنصر القائمة يحدّث «الكورس المختار» في الأب
