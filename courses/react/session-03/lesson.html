هدف الجلسة

نتعلّم تمرير البيانات من الأب إلى الابن عبر Props، واستخدام children، وتركيب الواجهة من مكوّنات قابلة لإعادة الاستخدام.

03

الشرح النظري

1) ما هي Props؟

Props اختصار Properties: بيانات يرسلها المكوّن الأب إلى الابن. الابن يقرأها ولا يعدّلها — كأنها مدخلات للدالة.

تشبيه: المكوّن = قالب بطاقة · Props = الاسم والسعر اللذان يتغيران في كل بطاقة.

2) تمرير البيانات

تمرَّر كخصائص JSX، وتُستقبل ككائن في معامل الدالة:

<Welcome name="Osama" />

function Welcome(props) {
  return <h1>Hello {props.name}</h1>;
}

الأوضح تفكيك الكائن:

function Welcome({ name }) {
  return <h1>Hello {name}</h1>;
}

3) Children

كل ما يُكتب بين وسم الفتح والإغلاق يصل عبر props.children. مفيد للصناديق والأزرار والتخطيطات.

4) Component Composition

التركيب يعني بناء واجهة أكبر من مكوّنات أصغر: Page تحتوي Header و Card، والـ Card تحتوي Title و Price.

5) Reusable UI

إذا تكرر نفس الشكل مع بيانات مختلفة — اصنع مكوّناً واحداً ومرّر Props. لا تنسخ نفس الـ JSX ثلاث مرات.

يمكن إعطاء قيمة افتراضية عند التفكيك حتى لا ينكسر العرض إن نُسي الـ prop: function Price({ amount = 0 }).

لا تغيّر props داخل الابن. إذا احتجت قيمة تتبدل مع الوقت فهذه مهمة State في الجلسة 5.

أمثلة عملية

مثال 1: بطاقة كورس

CourseCard.jsx
function CourseCard({ title, hours, level }) {
  return (
    <article className="card">
      <h3>{title}</h3>
      <p>{hours} hours · {level}</p>
    </article>
  );
}

export default CourseCard;
App.jsx
<CourseCard title="Web Fundamentals" hours={40} level="Beginner" />
<CourseCard title="React" hours={32} level="Intermediate" />

مثال 2: تمرير اسم المدرب

function Instructor({ fullName, city }) {
  return (
    <p>{fullName} — {city}</p>
  );
}

<Instructor fullName="Osama Bittar" city="Damascus" />

مثال 3: children — صندوق محتوى

function Panel({ title, children }) {
  return (
    <section className="panel">
      <h2>{title}</h2>
      {children}
    </section>
  );
}

<Panel title="About the trainer">
  <p>Osama Bittar teaches modern web development.</p>
</Panel>

مثال 4: سعر باليورو

function Price({ amount }) {
  return <strong>{amount} €</strong>;
}

<Price amount={29} />

تمارين عملية

1 مكوّن Welcome

يستقبل name ويعرض «Welcome [name]». استدعه باسم Osama.

function Welcome({ name }) {
  return <h1>Welcome {name}</h1>;
}

<Welcome name="Osama" />

2 ثلاث بطاقات كورس

مرّر title و hours لثلاث دورات مختلفة باستخدام نفس المكوّن.

<CourseCard title="HTML" hours={12} />
<CourseCard title="CSS" hours={12} />
<CourseCard title="JavaScript" hours={12} />

3 Button مع children

مكوّن زر يعرض النص الموجود بين الوسمين.

function Button({ children }) {
  return <button type="button">{children}</button>;
}

<Button>Enroll now</Button>

ملخص الجلسة

  • Props = بيانات من الأب إلى الابن للقراءة فقط
  • فكك القيم: { title, hours }
  • children تمرّر المحتوى الداخلي للصندوق أو الزر
  • التركيب = صفحات كبيرة من مكوّنات صغيرة

واجب الجلسة

  • حوّل بطاقة المدرب إلى مكوّن يستقبل name و title و city
  • أنشئ قائمة 3 كورسات من نفس CourseCard
  • اصنع Panel يستخدم children لنص طويل
