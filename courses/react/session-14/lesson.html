الشرح النظري

1) useRef

useRef يحتفظ بقيمة عبر الرسوم دون إعادة رسم عند تغييرها. الاستخدام الأشهر: الإشارة إلى عنصر DOM — تركيز حقل بعد الخطأ، أو قراءة ملف. 

const inputRef = useRef(null);

function focusName() {
  inputRef.current.focus();
}

<input ref={inputRef} />
ليس بديلاً عن state للواجهة. إن كان المستخدم يجب أن يرى التغيّر فوراً استخدم useState.

2) Custom Hooks

خطاف مخصّص = دالة يبدأ اسمها بـ use وتستدعي Hooks أخرى. ننقل منطق الجلب أو النموذج خارج المكوّن لإعادة الاستخدام.

تشبيه: المكوّن يعرض البطاقة · الخطاف يجلب القائمة ويُعيد loading و error و data.

3) تنظيم Project Structure

افصل المسؤوليات حتى يبقى المشروع قابلاً للنمو في الجلستين 15 و 16:

src/
  components/     // reusable UI pieces
  pages/          // route screens
  context/        // providers
  hooks/          // custom hooks
  services/       // fetch helpers
  App.jsx
  main.jsx

4) Components · Pages · Services

  • Components: زر، بطاقة، حقل — بلا معرفة بالمسار.
  • Pages: تجمع المكوّنات وتربطها بالـ Router.
  • Services: دوال fetch فقط، تُستدعى من أثر أو خطاف.

5) Reusable Logic

لا تنسخ نفس كتلة fetch في ثلاث صفحات. انقلها إلى useCourses() أو coursesService.js.

6) Environment Variables

في Vite المتغيرات العامة تبدأ بـ VITE_ وتُقرأ عبر import.meta.env.VITE_API_URL. لا تضع أسراراً حقيقية في الواجهة — أي مفتاح في الفرونت يظهر للمستخدم. 

VITE_API_URL=https://jsonplaceholder.typicode.com

7) أساسيات تحسين الأداء

  • لا تجلب البيانات في كل رسم — قيّد useEffect بالاعتماد الصحيح.
  • Keys ثابتة في القوائم.
  • قسّم المكوّنات حتى لا يعيد رسم صفحة كاملة من أجل شارة صغيرة.
  • لاحقاً: React.memo عند الحاجة فقط، لا في كل ملف.

8) Debugging و React Developer Tools

ثبّت إضافة React Developer Tools في المتصفح. تبويب Components يعرض الشجرة والـ props والـ state. تبويب Profiler يساعد لاحقاً على فهم إعادة الرسم.

أثناء التطوير: console.log بحذر، ونقاط التوقف في DevTools، وقراءة رسالة الخطأ كاملة قبل تعديل عشوائي.

9) التحضير للمشاريع النهائية

قبل الجلسة 15 جهّز مستودع Vite نظيفاً، والمجلدات أعلاه، وملف .env لعنوان الـ API، وتخطيط Router فارغ. المشروع الأول كتالوج كورسات، والثاني سلة بحالة متقدمة.

أمثلة عملية

مثال 1: تركيز الحقل بعد خطأ

function EnrollForm() {
  const nameRef = useRef(null);
  const [error, setError] = useState("");

  function handleSubmit(event) {
    event.preventDefault();
    const name = nameRef.current.value.trim();
    if (!name) {
      setError("Name is required");
      nameRef.current.focus();
      return;
    }
    setError("");
  }

  return (
    <form onSubmit={handleSubmit}>
      <input ref={nameRef} defaultValue="Osama" />
      {error && <p>{error}</p>}
      <button type="submit">Save</button>
    </form>
  );
}

مثال 2: Custom Hook للجلب

export function useCourses() {
  const [courses, setCourses] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function load() {
      try {
        const base = import.meta.env.VITE_API_URL;
        const response = await fetch(base + "/posts?_limit=8");
        if (!response.ok) throw new Error("Failed to load");
        setCourses(await response.json());
      } catch (err) {
        setError(err.message);
      } finally {
        setLoading(false);
      }
    }
    load();
  }, []);

  return { courses, loading, error };
}

مثال 3: طبقة services

const baseUrl = import.meta.env.VITE_API_URL;

export async function getCourses() {
  const response = await fetch(baseUrl + "/posts?_limit=8");
  if (!response.ok) throw new Error("Could not load courses");
  return response.json();
}

export async function getCourseById(id) {
  const response = await fetch(baseUrl + "/posts/" + id);
  if (!response.ok) throw new Error("Course not found");
  return response.json();
}

مثال 4: صفحة تستخدم الخطاف فقط

function CoursesPage() {
  const { courses, loading, error } = useCourses();
  if (loading) return <p>Loading...</p>;
  if (error) return <p>{error}</p>;
  return <CourseList items={courses} trainer="Osama Bittar" />;
}

تمارين عملية

1 useRef للتركيز

زر «Focus search» يركّز حقل البحث.

const searchRef = useRef(null);
<button type="button" onClick={() => searchRef.current.focus()}>
  Focus search
</button>
<input ref={searchRef} />

2 خطاف useToggle

يعيد value و دالة تعكس القيمة. استخدمه لقائمة الجوال.

function useToggle(initial = false) {
  const [value, setValue] = useState(initial);
  function toggle() {
    setValue((current) => !current);
  }
  return [value, toggle];
}

3 نقل fetch

انقل طلب القائمة من الصفحة إلى services/courses.js ثم استدعه من الخطاف.

import { getCourses } from "../services/courses";
const data = await getCourses();
setCourses(data);
