الشرح النظري

1) Authorization و Roles و Ownership

أكمل وسطاء الأدمن والملكية على التعديل والحذف.

2) Relationships

populate للمالك في التفاصيل. لا تُظهر password.

3) Validation و Error Handling

معالج مركزي و404 ورسائل تحقق عربية أو إنجليزية موحّدة (الإنجليزية في JSON كما في أمثلة الدورة).

4) Search و Filtering و Pagination و File Uploads

قائمة قوية ورفع صورة الغلاف.

5) Security Fundamentals

CORS مقيّد، أسرار في env، حد لمسار login، ترويسات أساسية.

6) API Testing و Debugging و Code Organization و المراجعة

مجموعة طلبات تغطي السعادة والفشل (401/403/400/404). لا أخطاء غير ملتقطة في الطرفية عند المسار السعيد.

معيار الاكتمال: واجهة React لاحقة تستطيع عرض الكورسات وتسجيل الدخول دون تعديل العقد.
