هدف الجلسة

ننتقل من Callbacks إلى Promises وasync/await، نعالج الأخطاء، ونقرأ متغيرات البيئة مع تنظيم المجلدات.

02

الشرح النظري

1) Callbacks كمفهوم

دالة تُستدعى لاحقاً عند انتهاء عمل بطيء. تتداخل بسرعة (callback hell) لذا نفضّل Promises.

2) Promises و async / await

Promise تمثّل قيمة مستقبلية. async/await يجعل القراءة كأنها متسلسلة مع بقائها غير حاجبة للخادم.

3) Error Handling

غلّف await بـ try/catch. لا تترك وعداً بلا catch في المسارات.

4) Environment Variables

المنفذ وسلسلة Mongo وسر JWT لا تُكتب في الكود. ملف .env محلياً و.gitignore يمنعه من Git.

PORT=3000
MONGO_URI=mongodb://127.0.0.1:27017/academy
JWT_SECRET=change-me-in-real-life

5) تنظيم مشروع Node.js

src/
  config/
  routes/
  controllers/
  models/
  middleware/
  utils/
index.js
.env
.gitignore

أمثلة عملية

مثال 1: await مع خطأ

async function loadTrainer() {
  try {
    const name = await Promise.resolve("Osama Bittar");
    return name;
  } catch (error) {
    console.error(error.message);
  }
}

مثال 2: dotenv

import "dotenv/config";
const port = process.env.PORT || 3000;
