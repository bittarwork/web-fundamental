هدف الجلسة

نفهم دور الخادم مقابل الواجهة، بروتوكول HTTP وفكرة REST، ثم نشغّل Node.js مع npm ووحدات.

01

الشرح النظري

ملاحظة: أمثلة الدورة تستخدم Osama Bittar والأسعار باليورو (€).

1) Backend Development

الواجهة تعرض الصفحات. الخادم يخزّن البيانات، يتحقق من الصلاحيات، ويرجع JSON. المتصفح أو تطبيق React يستهلك هذا الـ API.

2) Client / Server

تشبيه: العميل يطلب قائمة كورسات · الخادم يبحث في القاعدة ويردّ بالمستندات.

3) HTTP

طلب فيه طريقة (GET/POST...) ومسار وترويسات وجسم أحياناً. الرد فيه رمز حالة وجسم غالباً JSON.

4) REST

نصمّم عناوين حول موارد: /api/courses للكورسات. الحالة لا تُحفظ في الخادم بين الطلبات (stateless) — التوكن يأتي مع كل طلب لاحقاً.

5) Node.js و npm و package.json

Node يشغّل JavaScript خارج المتصفح. npm يثبت الحزم. package.json يسجّل الاسم والإصدار والسكربتات.

node -v
npm -v
mkdir academy-api && cd academy-api
npm init -y

6) Modules

في الدورة نفضّل ES Modules: "type": "module" في package.json ثم import/export.

💻

أمثلة عملية

مثال 1: أول ملف

// index.js
const trainer = "Osama Bittar";
console.log("Academy API — " + trainer);

تشغيل: node index.js

مثال 2: تصدير وحدة

// prices.js
export const euro = (amount) => amount + " €";

// index.js
import { euro } from "./prices.js";
console.log(euro(49));

مثال 3: سكربت في package.json

{
  "type": "module",
  "scripts": { "start": "node index.js" }
}
