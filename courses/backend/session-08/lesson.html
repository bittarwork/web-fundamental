هدف الجلسة

نضيف تصفية وترتيباً وبحثاً وترقيماً، ونربط المستندات بـ populate.

08

الشرح النظري

1) Filtering و Sorting و Search

query: minPrice وsort=price وq للعنوان بـ regex آمن محدود.

2) Pagination

page وlimit. skip = (page-1)*limit. أرجع total للواجهة.

3) References و populate و Relationships

owner: { type: ObjectId, ref: "User" }. populate("owner", "name email") يجلب الحقول المختارة لا كلمة المرور.

💻

أمثلة عملية

مثال 1: قائمة

const page = Number(req.query.page) || 1;
const limit = Number(req.query.limit) || 10;
const filter = {};
if (req.query.q) filter.title = { $regex: req.query.q, $options: "i" };
if (req.query.minPrice) filter.price = { $gte: Number(req.query.minPrice) };

const [items, total] = await Promise.all([
  Course.find(filter).sort(req.query.sort || "-createdAt").skip((page - 1) * limit).limit(limit),
  Course.countDocuments(filter)
]);
res.json({ success: true, total, page, data: items });

مثال 2: populate

Course.findById(id).populate("owner", "name email");

ملخص الجلسة

  • الاستعلام من query string
  • لا تُرجع كلمات المرور في populate
  • total ضروري للواجهة

واجب الجلسة

  • قائمة كورسات مع q وminPrice وpage
  • populate للمالك
  • جرّب ?page=1&limit=5
