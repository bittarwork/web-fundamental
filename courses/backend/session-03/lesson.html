هدف الجلسة

ننشئ خادم Express، نفهم الطلب والرد، ونعرّف مسارات بطرق HTTP ورموز حالة صحيحة.

03

الشرح النظري

1) Express Setup و Web Server

npm install express
# index.js
import express from "express";
const app = express();
app.use(express.json());
app.listen(3000, () => console.log("API on 3000"));

2) Requests و Responses

req يحمل المعاملات والجسم والترويسات. res يرسل الرمز والجسم. JSON عبر res.json.

3) Routes و HTTP Methods

app.get وapp.post على مسارات ثابتة أولاً. لا تخلط مسؤولية المسار الواحد.

4) Status Codes

  • 200 نجاح قراءة · 201 إنشاء
  • 400 طلب سيئ · 401 غير مصادق · 403 ممنوع · 404 غير موجود
  • 500 خطأ خادم
💻

أمثلة عملية

مثال 1: ترحيب

app.get("/api/health", (req, res) => {
  res.status(200).json({ ok: true, trainer: "Osama Bittar" });
});

مثال 2: POST بسيط

app.post("/api/echo", (req, res) => {
  res.status(201).json({ received: req.body });
});

مثال 3: 404 مبدئي

app.use((req, res) => {
  res.status(404).json({ message: "Route not found" });
});
