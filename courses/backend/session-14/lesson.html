الشرح النظري

1) تحليل المتطلبات

منصة كورسات: الزائر يرى القائمة، المستخدم يسجّل، الأدمن ينشئ كورسات بسعر € واسم مدرّب Osama Bittar.

2) Resources

Auth، Users (محدود)، Courses. لاحقاً يمكن Enrollment.

3) تصميم MongoDB و Schemas و Models

نفّذ User وCourse كما خططت في 13 مع owner وtimestamps.

4) Routes و Controllers و CRUD

GET عام للقائمة والتفاصيل. POST/PATCH/DELETE محمية.

5) Authentication و Users و JWT

register، login، me. لا ترجع password.

6) تنظيم البنية

لا تضع كل شيء في index.js. هذا معيار التسليم.

لا تبدأ بالزينة. تدفق: اتصال → نماذج → auth → CRUD كورسات.

أمثلة عملية

مثال 1: مسارات المرحلة 1

POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me
GET  /api/courses
GET  /api/courses/:id
POST /api/courses          // admin
PATCH /api/courses/:id     // admin or owner
DELETE /api/courses/:id    // admin or owner
