الشرح النظري

1) Authentication vs Authorization

المصادقة: من أنت؟ التفويض: هل يُسمح لك بهذا الفعل؟

2) Roles و Admin / User و Permissions

role: user | admin. وسيط requireRole("admin") لمسارات الإدارة مثل إنشاء كورس عام.

3) Ownership Validation

تعديل كورس: إما أدمن أو owner يساوي req.user.id. وإلا 403.

4) Protected Resources

GET العام للقائمة يمكن أن يبقى مفتوحاً. DELETE للمالك أو الأدمن فقط.

أمثلة عملية

مثال 1: دور

export function requireRole(...roles) {
  return (req, res, next) => {
    if (!roles.includes(req.user.role)) {
      return res.status(403).json({ success: false, message: "Forbidden" });
    }
    next();
  };
}
