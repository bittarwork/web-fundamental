الشرح النظري

1) User Model

email فريد، password يُجزَّأ قبل الحفظ، role افتراضي user.

2) Registration و Login

التسجيل ينشئ المستخدم ويرجع توكن. الدخول يقارن bcrypt ثم يصدر توكن.

3) Password Hashing

bcrypt (أو bcryptjs). لا تخزّن النص الأصلي أبداً.

4) JWT

payload: user id وrole. السر من JWT_SECRET. مدة صلاحية قصيرة للتدريب (مثلاً 7d) مع فهم أنها إعداد.

5) Authentication Middleware و Protected Routes

اقرأ Authorization: Bearer. تحقق التوكن وضع req.user. بدون توكن 401.

لا تضع السر في الكود. ولا تسجّل التوكن في لوج عام.
💻

أمثلة عملية

مثال 1: تجزئة

import bcrypt from "bcryptjs";
user.password = await bcrypt.hash(plain, 10);

مثال 2: توكن

import jwt from "jsonwebtoken";
const token = jwt.sign({ id: user._id, role: user.role }, process.env.JWT_SECRET, { expiresIn: "7d" });

مثال 3: وسيط

export async function protect(req, res, next) {
  const header = req.headers.authorization || "";
  const token = header.startsWith("Bearer ") ? header.slice(7) : "";
  if (!token) return res.status(401).json({ success: false, message: "Unauthorized" });
  const payload = jwt.verify(token, process.env.JWT_SECRET);
  req.user = payload;
  next();
}
