نفرّق الراوتر عن التطبيق، نقرأ المعاملات والجسم، ونكتب Middleware وControllers.

04

الشرح النظري

1) Express Router

ملف routes/courses.js يصدّر راوتراً يُركَّب على /api/courses.

2) Route Parameters و Query و Body

  • params: /courses/:id → req.params.id
  • query: ?q=react → req.query.q
  • body: JSON بعد express.json → req.body

3) Middleware

دالة (req, res, next). إن لم تستدع next ولم ترسل رداً يبقى الطلب معلّقاً.

4) Custom Middleware

سجّل الطريقة والمسار، أو أرفق req.requestTime.

5) Controllers

المسار يسمي الدالة فقط. المنطق في controllers/courseController.js حتى يبقى الراوتر قصيراً.

💻

أمثلة عملية

مثال 1: راوتر

import { Router } from "express";
const router = Router();
router.get("/", listCourses);
router.get("/:id", getCourse);
export default router;

مثال 2: وسيط سجل

export function logger(req, res, next) {
  console.log(req.method, req.originalUrl);
  next();
}

مثال 3: Controller

export function listCourses(req, res) {
  const q = req.query.q || "";
  res.json({ trainer: "Osama Bittar", q, items: [] });
}
