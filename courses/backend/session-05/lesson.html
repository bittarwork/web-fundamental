الشرح النظري

1) REST Principles و Resource-Based APIs

اسم جمع للمورد: /api/courses. لا أفعال في المسار مثل /getCourses. الفعل في طريقة HTTP.

2) CRUD مقابل الطرق

  • GET قائمة وGET واحد
  • POST إنشاء
  • PUT استبدال كامل · PATCH تحديث جزئي
  • DELETE حذف

3) API Response Structure

{ "success": true, "data": { } }
{ "success": false, "message": "Course not found" }

السعر داخل المورد باليورو: price: 49 مع حقل currency: "EUR".

💻

أمثلة عملية

مثال 1: قائمة في الذاكرة

let courses = [
  { id: "1", title: "React", price: 49, trainer: "Osama Bittar" }
];

مثال 2: POST

export function createCourse(req, res) {
  const course = { id: String(Date.now()), ...req.body };
  courses.push(course);
  res.status(201).json({ success: true, data: course });
}

مثال 3: DELETE

courses = courses.filter((item) => item.id !== req.params.id);
res.status(200).json({ success: true, data: null });
