الشرح النظري

1) File / Image Uploads

multipart/form-data عبر multer. اسمح بامتدادات صور فقط وحدّ الحجم (مثلاً 2 MB). خزّن المسار في المستند لا الملف داخل Mongo.

2) Search و Filtering و Sorting و Pagination

اجمع ما تعلمته في الجلسة 08 في قائمة الكورسات النهائية: q وminPrice وsort وpage وlimit.

3) Query Parameters

وثّق المعاملات في تعليق أو مسار GET /api/courses حتى مطوّر الواجهة يعرف العقد.

لا تنفّذ الملفات المرفوعة. احفظها خارج المسارات التنفيذية وتحقق من النوع.
💻

أمثلة عملية

مثال 1: multer

import multer from "multer";
const upload = multer({
  dest: "uploads/",
  limits: { fileSize: 2 * 1024 * 1024 },
  fileFilter(req, file, cb) {
    const ok = /jpeg|jpg|png|webp/.test(file.mimetype);
    cb(ok ? null : new Error("Images only"), ok);
  }
});

مثال 2: مسار

router.post("/:id/image", protect, upload.single("image"), setCourseImage);

مثال 3: حفظ المسار

course.imageUrl = "/uploads/" + req.file.filename;
await course.save();
