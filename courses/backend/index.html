عن هذه الدورة

دورة عملية متخصصة في Backend Development باستخدام Node.js وExpress وMongoDB، يتعلم الطالب خلالها كيفية بناء REST APIs احترافية، والتعامل مع قواعد البيانات، Authentication وAuthorization، Validation، Error Handling، ورفع الملفات، وصولاً إلى بناء Backend متكامل وجاهز للربط مع تطبيقات Front-End الحديثة.

المحتوى العلمي باسم المنصة. الأمثلة تستخدم Osama Bittar والأسعار في النماذج باليورو (€). الكود بالإنجليزية.
