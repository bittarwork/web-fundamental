الشرح النظري

1) الاتصال

import mongoose from "mongoose";
await mongoose.connect(process.env.MONGO_URI);

2) Schemas و Models و Types

الـ Schema يصف الحقول. الـ Model هو الباب للاستعلامات. String وNumber وBoolean وDate وObjectId شائعة.

3) Validation

required وmin وmax وmatch للبريد. timestamps: true يضيف createdAt وupdatedAt.

4) CRUD

create / find / findById / findByIdAndUpdate / findByIdAndDelete. new: true في التحديث لإرجاع النسخة الجديدة.

💻

أمثلة عملية

مثال 1: Course schema

const courseSchema = new mongoose.Schema({
  title: { type: String, required: true, trim: true },
  price: { type: Number, required: true, min: 0 },
  trainer: { type: String, default: "Osama Bittar" }
}, { timestamps: true });

export const Course = mongoose.model("Course", courseSchema);

مثال 2: إنشاء

const course = await Course.create(req.body);
res.status(201).json({ success: true, data: course });

مثال 3: اتصال عند الإقلاع

await mongoose.connect(process.env.MONGO_URI);
app.listen(port);
