هدف الجلسة

نحوّل السيرفر الجديد إلى بيئة جاهزة: وقت، تحديثات، جدار ناري، مستخدم نشر، وNginx على المنفذ 80.

07

الشرح النظري

1) المنطقة الزمنية

timedatectl
timedatectl set-timezone Europe/Berlin

اختر مدينة تناسب عملك. السجلات تصبح مفهومة.

2) مستخدم للنشر

adduser osama
usermod -aG sudo osama

انسخ مفتاحك إلى هذا المستخدم لاحقاً وادخل به بدل root اليومي.

3) جدار ناري ufw

ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw enable
ufw status
اسمح بـ SSH قبل التفعيل وإلا قد تُغلق على نفسك. Hostinger Browser Terminal يبقى منفذاً إن أخطأت، ويمكن ضبط جدار hPanel أيضاً.

4) Nginx كواجهة أولية

apt install -y nginx
systemctl enable --now nginx

افتح http://YOUR_IP من المتصفح. يجب أن تظهر صفحة الترحيب. انسخ ملفاتك إلى /var/www/html أو اضبط موقعاً لاحقاً.

5) صفحة الأكاديمية يدوياً

echo "<h1>Osama Bittar Academy</h1>" > /var/www/html/index.html
systemctl reload nginx

6) جدار Hostinger في hPanel

بالإضافة إلى ufw: VPS → Firewall. أبقِ 22 و80 و443. لا تفتح كل المنافذ «للراحة».

7) ماذا بعد؟

لا تعطّل دخول كلمة المرور حتى تتأكد أن المفتاح يعمل مرتين. ثم يمكن تشديد sshd لاحقاً بحذر.

أمثلة عملية

مثال 1: ترتيب اليوم الأول

apt update && apt upgrade -y
timedatectl set-timezone Europe/Berlin
adduser osama
usermod -aG sudo osama
ufw allow OpenSSH && ufw allow 80 && ufw allow 443 && ufw enable
apt install -y nginx && systemctl enable --now nginx

مثال 2: اختبار من الخارج

من هاتفك على شبكة أخرى افتح http://IP حتى لا تختبر من السيرفر فقط.

ملخص الجلسة

  • يوم أول: تحديث + وقت + جدار + Nginx
  • مستخدم sudo للعمل اليومي
  • لا تغلق 22 قبل نجاح المفتاح

واجب الجلسة

  • أكمل التهيئة حتى تظهر صفحة على IP
  • أنشئ مستخدم osama أو اسمك
  • سجّل المنافذ المفتوحة
