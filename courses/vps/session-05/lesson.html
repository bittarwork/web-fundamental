هدف الجلسة

نتنقّل في نظام ملفات Ubuntu، ننشئ ملفات المشروع، ونعدّل الصلاحيات دون حذف النظام.

05

الشرح النظري

1) الطرفية تفكّر بالمجلد الحالي

كل أمر يجري «من هنا». pwd يطبع المسار. ls يعرض المحتوى. ls -la يظهر المخفي والصلاحيات.

pwd
ls -la
cd /
ls
cd ~
cd /var/www

~ بيت المستخدم. .. المجلد الأب. Tab يكمل الأسماء.

2) إنشاء وقراءة

mkdir -p /root/academy
cd /root/academy
touch notes.txt
echo "Trainer: Osama Bittar" > notes.txt
cat notes.txt
nano notes.txt

في nano: اكتب النص، Ctrl+O حفظ، Ctrl+X خروج. less للقراءة الطويلة (q للخروج).

3) نسخ نقل حذف

cp notes.txt notes.bak
mv notes.bak /tmp/
rm notes.txt
لا تستخدم rm -rf / أبداً. احذف فقط مسارات مشروعك التي تعرفها. لا تجربة أوامر تدمير «للتجربة».

4) الصلاحيات باختصار

ثلاث خانات: مالك، مجموعة، آخرون — قراءة كتابة تنفيذ. chmod u+x script.sh يجعل الملف قابلاً للتشغيل للمالك.

ls -l
chmod 644 notes.txt
chmod 755 /root/academy

5) sudo

root لا يحتاج sudo. المستخدم العادي يكتب sudo apt update لصلاحية مؤقتة. ستنشئ هذا المستخدم في الجلسة 07.

6) المساعدة

man ls
ls --help
history

أمثلة عملية

مثال 1: شجرة مشروع

mkdir -p /root/academy/public
echo "<h1>Osama Bittar</h1>" > /root/academy/public/index.html
ls -R /root/academy

مثال 2: رؤية المساحة

df -h
du -sh /root/academy

مثال 3: مسارات مهمة

  • /etc إعدادات النظام — لا تحذف.
  • /var/log السجلات.
  • /home بيوت المستخدمين.
  • /root بيت المدير.

ملخص الجلسة

  • اعرف أين أنت قبل أن تحذف
  • nano للكتابة السريعة
  • لا تلمس /etc إلا بتعليمات واضحة

واجب الجلسة

  • تمرّن 20 دقيقة: ls cd mkdir cat nano
  • اكتب 8 أوامر استخدمتها في الواجب
  • لا ترفع مخرجات فيها أسرار
