هدف الجلسة

نحدّث Ubuntu، ندير الخدمات والعمليات، نقرأ السجلات، وننقل المشروع من جهازنا إلى السيرفر.

06

الشرح النظري

1) الحزم: apt

Ubuntu يستخدم apt. حدّث فهرس الحزم ثم النظام:

apt update
apt upgrade -y
apt install -y curl git ufw nginx

apt search nginx للبحث. apt remove لإزالة حزمة.

2) الخدمات: systemd

systemctl status nginx
systemctl start nginx
systemctl enable nginx
systemctl restart nginx

enable تعني التشغيل بعد إعادة الإقلاع. status يخبرك active أم failed.

3) السجلات

journalctl -u nginx -n 50 --no-pager
tail -f /var/log/nginx/access.log

Ctrl+C يوقف المتابعة. اقرأ الخطأ من الأسفل غالباً.

4) العمليات والموارد

htop
# or: top
ps aux | grep nginx
free -h
df -h

ثبّت htop إن لم يوجد: apt install -y htop.

5) الأنابيب والتصفية

ls /var/log | grep nginx
dmesg | tail

6) النقل من جهازك (على اللابتوب لا على السيرفر)

scp -r ./public root@YOUR_IP:/root/academy/
rsync -avz ./public/ root@YOUR_IP:/root/academy/public/

rsync ألطف للتحديثات المتكررة. scp كافٍ لأول مرة.

7) المستخدمون (تمهيد)

adduser deploy
id deploy

التفاصيل والصلاحيات في الجلسة التالية. لا تحذف root.

أمثلة عملية

مثال 1: تحديث آمن أول يوم

apt update && apt upgrade -y

مثال 2: هل Nginx يستمع؟

ss -tulpn | grep :80

مثال 3: جلب Git على السيرفر

cd /root/academy
git clone https://github.com/USERNAME/academy-notes.git

مستودعك العام فقط. لا تضع أسراراً في المستودع.

تمارين عملية

1 حدّث

apt update وupgrade.

انتظر حتى ينتهي بلا أخطاء حمراء حرجة.

2 git وcurl

ثبّتهما عبر apt.

apt install -y git curl

3 انقل

من جهازك انسخ مجلد public إلى السيرفر.

scp -r ./public root@YOUR_IP:/root/academy/
