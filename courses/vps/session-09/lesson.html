هدف الجلسة

نفهم الصورة والحاوية، نثبت Docker على Ubuntu، ونشغّل Nginx في حاوية مع Dockerfile بسيط.

09

الشرح النظري

1) لماذا Docker؟

الحاوية تغلف التطبيق ومتطلباته. ما يعمل على سيرفر Osama يعمل بنفس الملف على سيرفر العمل. أقل جملة «عندي يشتغل».

Image

القالب للقراءة فقط (وصفة).

Container

نسخة شغّالة من الصورة (طبق على الطاولة).

2) التثبيت على Ubuntu (رسمي مبسّط للدورة)

apt install -y docker.io docker-compose-v2
systemctl enable --now docker
docker version
docker compose version

إن فضّلت مستودع Docker الرسمي لاحقاً يمكن الترقية. للدورة حزم Ubuntu كافية للبداية.

usermod -aG docker osama

بعد إضافة المستخدم لمجموعة docker أعد الدخول حتى يعمل دون sudo.

3) أوامر يومية

docker pull nginx:alpine
docker run -d --name academy-web -p 8080:80 nginx:alpine
docker ps
docker logs academy-web
docker stop academy-web
docker rm academy-web

افتح http://IP:8080. إن منع الجدار المنفذ 8080 اسمح به للتجربة أو استخدم 80 بعد إيقاف nginx النظام.

4) Dockerfile

FROM nginx:alpine
COPY public/ /usr/share/nginx/html/
docker build -t academy-site .
docker run -d --name academy-web -p 8080:80 academy-site

5) المجلدات والمنافذ

-p 8080:80 يربط منفذ المضيف بالحاوية. Volume يشارك ملفات من السيرفر داخل الحاوية للتطوير.

Hostinger قد يعرض مدير Docker في اللوحة. تعلّم الأوامر أولاً ثم استخدم الواجهة إن شئت.

ملخص الجلسة

  • صورة ≠ حاوية
  • المنفذ جسر للزائر
  • Dockerfile يوثّق البناء

واجب الجلسة

  • حاوية تعرض اسم المدرب
  • افهم stop/rm
  • لا تفتح منفذ Docker للعالم بلا جدار
