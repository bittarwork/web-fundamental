الشرح النظري

لماذا Flexbox؟

قبل Flexbox، كان ترتيب العناصر بجانب بعض أو في المنتصف صعباً. Flexbox (Flexible Box Layout) نظام CSS حديث يسهّل ترتيب العناصر أفقياً أو عمودياً بمرونة عالية.

متى تستخدم Flexbox؟ شريط التنقل (navbar)، صف أزرار، بطاقات في صف واحد، توسيط عنصر في منتصف الشاشة — Flexbox مثالي لهذه الحالات.

المفاهيم الأساسية

  • Flex Container: العنصر الأب الذي نضيف له display: flex;
  • Flex Items: العناصر الأبناء داخل الـ container
  • Main Axis: المحور الرئيسي (أفقي افتراضياً في RTL أيضاً)
  • Cross Axis: المحور العمودي المتعامد

خصائص الـ Container (الأب)

  • display: flex; — يفعّل Flexbox
  • flex-direction — row (أفقي) أو column (عمودي)
  • justify-content — توزيع على المحور الرئيسي (flex-start, center, space-between, space-around)
  • align-items — محاذاة على المحور العمودي (center, stretch, flex-start)
  • gap — مسافة بين العناصر (بديل أنظف من margin)
  • flex-wrap — wrap للانتقال لسطر جديد عند ضيق المساحة

خصائص الـ Items (الأبناء)

  • flex: 1; — يأخذ المساحة المتبقية بالتساوي
  • flex-grow — كم ينمو العنصر
  • flex-shrink — كم يتقلص عند ضيق المساحة
  • align-self — محاذاة عنصر واحد بشكل مختلف

بناء Navbar بـ Flexbox

شريط التنقل (Navbar) هو أشهر استخدام لـ Flexbox: الشعار على اليمين، الروابط في الوسط أو اليسار، وزر تسجيل الدخول في الطرف الآخر — كل ذلك بسطر CSS واحد display: flex; justify-content: space-between;.

مقدمة Media Queries — التصميم المتجاوب

@media تسمح بتطبيق CSS مختلف حسب حجم الشاشة. مثلاً: على الموبايل نخفي القائمة ونكبر الخط.

  • @media (max-width: 768px) { ... } — للشاشات الصغيرة
  • @media (min-width: 1024px) { ... } — للشاشات الكبيرة
Mobile First: الأفضل كتابة CSS للموبايل أولاً، ثم إضافة media queries للشاشات الأكبر — أسهل للصيانة.

Viewport Meta Tag

لا تنسَ إضافة <meta name="viewport" content="width=device-width, initial-scale=1.0"> في head — بدونه لن يعمل التصميم المتجاوب بشكل صحيح على الموبايل.

مثال 1: Flexbox أساسي

CSS — Flexbox Basics
.flex-container {
  display: flex;
  justify-content: center;   /* Center items on main axis */
  align-items: center;     /* Center items on cross axis */
  gap: 16px;                 /* Space between items */
  padding: 20px;
  background: #f3f4f6;
}

.flex-item {
  padding: 16px 24px;
  background: #2563eb;
  color: white;
  border-radius: 8px;
}

مثال 4: Media Query بسيط

CSS — Responsive Media Query
/* Default styles — mobile first */
.navbar {
  flex-direction: column;
  gap: 12px;
  padding: 12px;
}

.nav-links {
  flex-direction: column;
  text-align: center;
  gap: 8px;
}

/* Tablet and up — horizontal navbar */
@media (min-width: 768px) {
  .navbar {
    flex-direction: row;
    padding: 16px 32px;
  }

  .nav-links {
    flex-direction: row;
    gap: 24px;
  }
}

/* Desktop — wider spacing */
@media (min-width: 1024px) {
  .navbar {
    padding: 16px 48px;
  }

  .logo {
    font-size: 1.6rem;
  }
}

3 Media Query للموبايل

اجعل navbar عمودياً على الشاشات أقل من 768px، وأفقياً على الشاشات الأكبر. اختبر بتصغير نافذة المتصفح.

Solution
/* Mobile: stack vertically */
.navbar {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 12px;
  padding: 16px;
}

/* Desktop: horizontal layout */
@media (min-width: 768px) {
  .navbar {
    flex-direction: row;
    justify-content: space-between;
    padding: 16px 40px;
  }
}

ملخص الجلسة

  • Flexbox يرتّب العناصر أفقياً أو عمودياً بمرونة — display: flex على الأب
  • justify-content للمحور الرئيسي، align-items للمحور العمودي
  • gap مسافة أنظف بين العناصر، flex-wrap للانتقال لسطر جديد
  • Navbar = أشهر تطبيق: space-between + align-items: center
  • @media (max-width/min-width) لتطبيق CSS حسب حجم الشاشة
  • Mobile First: اكتب للموبايل أولاً ثم أضف media queries للأكبر

واجب اختياري

قبل الجلسة القادمة (مشروع Portfolio):

  • ابنِ navbar كامل لموقعك الشخصي بـ Flexbox
  • أضف media query يخفي بعض الروابط على الموبايل
