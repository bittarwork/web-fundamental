الشرح النظري

ما هو DOM؟

DOM اختصار لـ Document Object Model — تمثيل شجري لصفحة HTML يبنيها المتصفح عند التحميل. JavaScript تصل إلى كل عنصر في الصفحة عبر DOM وتغيّر محتواه أو مظهره أو هيكله.

تخيّلها هكذا: HTML هو المخطط، DOM هو النموذج الحيّ القابل للتعديل، و JavaScript هي أدوات البناء التي تُحرّك العناصر.

اختيار العناصر (Selecting Elements)

  • document.getElementById("id") — عنصر واحد بـ id فريد
  • document.querySelector(".class") — أول عنصر يطابق المحدّد CSS
  • document.querySelectorAll("p") — كل العناصر المطابقة (NodeList)
الأفضلية: querySelector أكثر مرونة لأنه يستخدم نفس صيغة CSS selectors التي تعرفها.

تعديل المحتوى

  • textContent — نص العنصر فقط (آمن، لا يفسّر HTML)
  • innerHTML — HTML داخل العنصر (يُفسّر الوسوم — احذر XSS)
  • value — قيمة حقول الإدخال input

إنشاء عناصر جديدة

لإضافة محتوى ديناميكي:

  1. document.createElement("tag") — إنشاء عنصر
  2. تعيين المحتوى أو الخصائص (class, textContent...)
  3. parent.appendChild(child) — إضافته للصفحة

تعديل الأنماط والخصائص

  • element.classList.add("active") — إضافة class
  • element.style.color = "red" — تعديل مباشر (للحالات البسيطة)
  • element.setAttribute("href", url) — تعديل سمة

أمثلة الكود

مثال 1: HTML الأساسي للتجربة

HTML — DOM Target Elements
<!-- index.html -->
<h1 id="page-title">مرحباً</h1>
<p class="intro">فقرة تعريفية</p>
<ul id="product-list"></ul>
<div id="price-box"></div>

مثال 2: getElementById و querySelector

JavaScript — Selecting Elements
// By ID
const title = document.getElementById("page-title");
title.textContent = "متجر الإلكترونيات";

// By CSS selector
const intro = document.querySelector(".intro");
intro.textContent = "أفضل الأسعار بالليرة السورية";

// All matching elements
const paragraphs = document.querySelectorAll("p");
paragraphs.forEach((p) => {
  console.log(p.textContent);
});

مثال 3: textContent مقابل innerHTML

JavaScript — Content Methods
const box = document.getElementById("price-box");

// textContent — نص فقط
box.textContent = "السعر: 75,000 ل.س";

// innerHTML — يُفسّر HTML
box.innerHTML = `
  <strong>عرض خاص!</strong>
  <span style="color:green">55,000 ل.س</span>
`;

مثال 4: createElement — بناء قائمة منتجات

JavaScript — createElement
const products = [
  { name: "لابتوب", price: 3200000 },
  { name: "سماعات", price: 85000 },
  { name: "فأرة", price: 28000 }
];

const list = document.getElementById("product-list");

products.forEach((product) => {
  const li = document.createElement("li");
  li.textContent = `${product.name} — ${product.price.toLocaleString("ar-SY")} ل.س`;
  list.appendChild(li);
});

مثال 5: بناء بطاقة منتج كاملة

JavaScript — Dynamic Card
const container = document.querySelector("#price-box");

const card = document.createElement("div");
card.classList.add("product-card");

const nameEl = document.createElement("h3");
nameEl.textContent = "هاتف ذكي";

const priceEl = document.createElement("p");
priceEl.textContent = "1,850,000 ل.س";

card.appendChild(nameEl);
card.appendChild(priceEl);
container.appendChild(card);

تمارين عملية

1 تغيير عنوان الصفحة

أنشئ صفحة فيها h1#welcome وغيّر نصه عبر JavaScript إلى اسمك.

Solution
<h1 id="welcome">أهلاً</h1>
<script>
  const heading = document.getElementById("welcome");
  heading.textContent = "أهلاً محمد!";
</script>

2 عدّاد المهام

عرض عدد المهام في span#task-count بناءً على طول مصفوفة مهام.

Solution
<p>عدد المهام: <span id="task-count">0</span></p>
<script>
  const tasks = ["قراءة", "برمجة", "رياضة"];
  const counter = document.querySelector("#task-count");
  counter.textContent = tasks.length;
</script>

3 قائمة أسعار ديناميكية

ابنِ قائمة ul فارغة واملأها بـ 3 منتجات وأسعارها بالليرة السورية باستخدام createElement.

Solution
<ul id="menu"></ul>
<script>
  const menu = document.getElementById("menu");
  const items = [
    { name: "شاي", price: 5000 },
    { name: "قهوة", price: 8000 },
    { name: "عصير", price: 12000 }
  ];

  items.forEach((item) => {
    const li = document.createElement("li");
    li.textContent = `${item.name}: ${item.price} ل.س`;
    menu.appendChild(li);
  });
</script>

ملخص الجلسة

  • DOM تمثيل شجري لـ HTML يتيح لـ JavaScript التحكم بالصفحة
  • getElementById للـ id · querySelector لأي محدّد CSS
  • textContent آمن للنص · innerHTML يُفسّر وسوم HTML
  • createElement + appendChild لبناء محتوى ديناميكي
  • الخطوة التالية: ربط هذه التقنيات بأحداث المستخدم (الجلسة 13)

  • ابنِ صفحة «معرض منتجات» تعرض 4 بطاقات من مصفوفة كائنات
  • استخدم createElement لكل بطاقة (اسم + سعر بالليرة السورية)
  • أضف class لكل بطاقة لتنسيقها لاحقاً بـ CSS
