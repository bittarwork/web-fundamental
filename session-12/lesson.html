هدف الجلسة

اليوم نتعلم كيف نخزّن أكثر من قيمة في مكان واحد. مثل قائمة ألعاب مفضلة، أو ملف شخصي فيه الاسم والعمر والمدينة — هذا لا يُحفظ في متغير واحد. لذلك نستخدم المصفوفات والأغراض.

الشرح النظري — من الصفر

1) ليش نحتاج هياكل بيانات؟

المتغير العادي (const name = "George") بيحفظ قيمة واحدة. بس بالحياة الحقيقية عندك قوائم: ألعاب، منتجات، أصدقاء... JavaScript بتعطينا طريقتين أساسيتين لتجميع البيانات:

Array — مصفوفة

قائمة مرتبة: لعبة 1، لعبة 2، لعبة 3. كل عنصر له رقم (index) يبدأ من 0.

Object — غرض

بطاقة شخصية: اسم، عمر، مدينة. كل معلومة لها اسم (property).

تشبيه بسيط: المصفوفة = رف ألعاب مرتب بالترتيب (الأول، الثاني، الثالث...) · الغرض = بطاقة هوية فيها حقول: الاسم، العمر، المدينة

2) المصفوفات (Arrays) — القائمة المرتبة

إنشاء مصفوفة

بنكتب العناصر بين أقواس مربعة [] ومفصولة بفاصلة:

  • const games = ["FIFA", "Minecraft", "GTA"];
  • مصفوفة فاضية: const empty = [];

الوصول بالـ index — الرقم يبدأ من 0!

أول عنصر = index 0، ثاني عنصر = index 1، وهكذا. games[0] يعطينا "FIFA".

قاعدة مهمة: آخر عنصر = index length - 1. إذا عندك 3 ألعاب، آخر index هو 2 مو 3!

length — كم عنصر في المصفوفة؟

games.length بيرجع عدد العناصر (مثلاً 3).

push و pop — إضافة وحذف من الآخر

  • push() — يضيف عنصر آخر المصفوفة
  • pop() — يحذف آخر عنصر ويرجعه

التكرار على المصفوفة — for loop

لما بدنا نمر على كل عنصر ونطبعه، منستخدم حلقة for مع length:

  • let i = 0 — نبدأ من أول index
  • i < arr.length — نوقف قبل ما نتجاوز الحد
  • arr[i] — نقرأ العنصر الحالي

3) الأغراض (Objects) — البطاقة الشخصية

إنشاء غرض

بنكتب الخصائص (properties) بين أقواس معقوفة {}: اسم الخاصية، ثم نقطتين، ثم القيمة.

الوصول للخصائص — طريقتين

Dot notation — النقطة

student.name — لما تعرف اسم الخاصية مسبقاً

Bracket notation — الأقواس

student["name"] — مفيد لما الاسم بمتغير

أغراض متداخلة (Nested Objects)

الغرض ممكن يحتوي غرض أو مصفوفة جواته! مثلاً: منتج فيه name وprice وdetails (غرض داخل غرض).

فرق سريع: المصفوفة = ترتيب + أرقام (0, 1, 2...) · الغرض = أسماء حقول (name, age, city...)

أمثلة عملية

مثال 1: مصفوفة ألعاب مفضلة

JavaScript — Array Basics
const favoriteGames = ["FIFA", "Minecraft", "GTA"];

console.log(favoriteGames);      // print whole array
console.log(favoriteGames[0]);   // first game
console.log(favoriteGames[2]);   // third game
console.log(favoriteGames.length); // how many games

مثال 2: push و pop — إضافة وحذف

JavaScript — push & pop
const games = ["FIFA", "Minecraft"];

games.push("Valorant");          // add new game at the end
console.log(games);              // 3 games now

const removed = games.pop();     // remove last game
console.log(removed);            // which game was removed
console.log(games);              // array after pop

مثال 3: حلقة for — طباعة كل لعبة

JavaScript — Loop Through Array
const games = ["FIFA", "Minecraft", "GTA"];

for (let i = 0; i < games.length; i++) {
  console.log("Game " + (i + 1) + ": " + games[i]);
}

مثال 4: غرض — ملف شخصي

JavaScript — Student Profile Object
const student = {
  name: "George Ziad Shahin",
  age: 17,
  city: "Damascus",
  hobbies: ["coding", "gaming", "tech"]
};

console.log(student.name);           // dot notation

console.log(student.hobbies[0]);     // first hobby from array inside object
console.log(student.city);

مثال 5: أغراض منتجات — أسعار بالليرة السورية

JavaScript — Product Objects
const laptop = {
  name: "Gaming Laptop",
  price: 3200000,                  // 3,200,000 ل.س
  inStock: true
};

const headphones = {
  name: "Wireless Headphones",
  price: 85000,                    // 85,000 ل.س
  inStock: false
};

console.log(laptop.name + " — " + laptop.price + " ل.س");
console.log(headphones.name + " — " + headphones.price + " ل.س");

// nested object — product with details inside
const phone = {
  name: "Smartphone",
  price: 1850000,
  details: {
    brand: "Samsung",
    storage: "256GB"
  }
};

console.log(phone.details.brand);    // nested access with dot
console.log(phone["details"]["storage"]); // nested with brackets

تجربة تفاعلية — شو رح يطلع؟

سؤال 1: شو رح يطبع هالكود؟

const games = ["FIFA", "GTA", "Minecraft"];
console.log(games[1]);

سؤال 2: بعد push، شو رح يكون length؟

const arr = ["A", "B"];
arr.push("C");
console.log(arr.length);

سؤال 3: شو رح يطبع هالكود؟

const student = { name: "George", age: 17 };
console.log(student["name"]);

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: بدون تشغيل — توقع النتيجة!

اقرأ الكود بعناية واكتب النتيجة على ورقة:

const games = ["FIFA", "Minecraft"];
games.push("GTA");
games.pop();
console.log(games.length);
console.log(games[1]);

الحل خطوة بخطوة:

  1. البداية: ["FIFA", "Minecraft"] — length = 2
  2. بعد push("GTA"): 3 عناصر
  3. بعد pop(): يرجع "GTA" ويحذفها — length = 2
  4. games[1] = العنصر الثاني = Minecraft

🧩 تحدي 2: وصل النقاط!

عندك غرض متداخل. شو لازم تكتب بدل ??? ليطبع "Damascus"؟

const profile = {
  name: "George",
  address: {
    city: "Damascus",
    country: "Syria"
  }
};

console.log(profile.???.city);

الجواب: address

"Damascus" موجودة داخل غرض address، فلازم نمر عبر profile.address أولاً، بعدين .city. 

console.log(profile.address.city);        // dot notation
console.log(profile["address"]["city"]);  // bracket notation
// Damascus

ملخص الجلسة

  • المصفوفة = قائمة مرتبة، الـ index يبدأ من 0
  • length يعطي عدد العناصر · push يضيف · pop يحذف من الآخر
  • حلقة for لمرور على كل عناصر المصفوفة
  • الغرض = خصائص بأسماء: name, age...
  • Dot notation (obj.name) و Bracket notation (obj["name"])
  • مصفوفة فيها أغراض = أقوى تركيبة للمتاجر والقوائم الحقيقية
  • الجلسة الجاية: توابع سهمية + filter و map لتصفية وتحويل البيانات!
