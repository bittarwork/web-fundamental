01

الشرح النظري

ما هو الويب؟

الويب (World Wide Web) هو نظام يربط بين ملايين الصفحات عبر الإنترنت. عندما تكتب عنوان موقع في المتصفح، يقوم المتصفح بجلب الصفحة وعرضها لك.

كيف يعمل المتصفح؟

المتصفح (مثل Chrome أو Firefox) يقوم بثلاث خطوات بسيطة:

  1. الطلب: يرسل طلباً للسيرفر لجلب الملفات
  2. الاستلام: يستلم ملفات HTML و CSS و JavaScript
  3. العرض: يقرأ الملفات ويعرض الصفحة كما تراها

ما هو HTML؟

HTML اختصار لـ HyperText Markup Language — أي لغة ترميز النصوص التشعبية. هي لغة الهيكل التي نبني بها صفحات الويب. تخيلها كهيكل عظمي: تحدد أين العنوان، أين الفقرة، أين الصورة.

ملاحظة مهمة: HTML ليست لغة برمجة — هي لغة ترميز. نستخدمها لوصف محتوى الصفحة، وليس لكتابة منطق معقد.

أدوات العمل

  • VS Code: محرر نصوص مجاني لكتابة الكود
  • المتصفح: لمعاينة الصفحات التي نبنيها
  • DevTools: أدوات المطور (F12) لفحص الصفحة

هيكل صفحة HTML الأساسي

كل صفحة HTML تحتوي على هيكل ثابت:

  • <!DOCTYPE html> — يخبر المتصفح أن هذا ملف HTML5
  • <html> — العنصر الجذر الذي يحتوي كل شيء
  • <head> — معلومات الصفحة (العنوان، الترميز) لا تظهر للمستخدم
  • <body> — المحتوى الذي يراه المستخدم فعلياً

عناصر النص الأساسية

  • h1 إلى h6 — العناوين (h1 الأكبر)
  • p — فقرة نصية
  • br — سطر جديد
  • hr — خط فاصل أفقي
💻

أمثلة الكود

مثال 1: الهيكل الأساسي لأي صفحة

HTML — Basic Structure
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحباً بالعالم!</h1>
  <p>هذه أول صفحة ويب أبنيها.</p>
</body>
</html>

تمارين عملية

1 أول صفحة HTML

أنشئ ملف index.html يحتوي على الهيكل الأساسي مع عنوان "صفحتي الأولى" وعبارة ترحيب.

Solution
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>أهلاً وسهلاً!</h1>
  <p>هذه أول صفحة HTML أكتبها بنفسي.</p>
</body>
</html>

2 صفحة "نبذة عني"

ابنِ صفحة تحتوي على: عنوان رئيسي باسم المدرب محمد أسامة بيطار، عنوان فرعي "نبذة عني"، وفقرتين تعريفيتين.

Solution
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>نبذة عني</title>
</head>
<body>
  <h1>محمد أسامة بيطار</h1>
  <h2>نبذة عني</h2>
  <p>مهندس معلوماتية ومدرب علوم ويب.</p>
  <p>أعمل في دمشق على بناء مواقع ومشاريع رقمية.</p>
</body>
</html>

3 استخدام DevTools

افتح صفحتك في Chrome، اضغط F12، واعثر على عنصر h1 في تبويب Elements.

الخطوات:

  1. افتح الملف في المتصفح (اسحبه أو انقر عليه مرتين)
  2. اضغط F12 أو كليك يمين → Inspect
  3. في تبويب Elements ستجد شجرة HTML
  4. ابحث عن <h1> وانقر عليه لرؤية تفاصيله
📌

ملخص الجلسة

  • الويب عبارة عن صفحات مرتبطة عبر الإنترنت يعرضها المتصفح
  • HTML هي لغة هيكل الصفحة — ليست لغة برمجة
  • كل صفحة تحتاج: DOCTYPE, html, head, body
  • h1-h6 للعناوين، p للفقرات، br لسطر جديد، hr لخط فاصل
  • VS Code + المتصفح + DevTools = أدواتك الأساسية

واجب اختياري

قبل الجلسة القادمة:

  • ثبّت VS Code على جهازك إن لم يكن مثبتاً
  • أنشئ صفحة "مذكراتي" فيها 3 عناوين و3 فقرات عن يومك
  • جرّب تغيير نص العنوان في DevTools وشاهد التغيير مباشرة
