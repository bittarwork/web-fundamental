الشرح النظري

ما هو API؟

API (واجهة برمجة التطبيقات) هي طريقة للتواصل بين البرامج. موقعك يرسل طلباً لخادم خارجي، والخادم يرد بـ بيانات جاهزة — مثل الطقس، أسعار العملات، أو قائمة مستخدمين.

ما هو JSON؟

JSON هو صيغة شائعة لتبادل البيانات على الإنترنت. يشبه كائن JavaScript لكنه نص يمكن إرساله عبر الشبكة:

  • المفاتيح بين علامتي اقتباس مزدوجتين
  • القيم يمكن أن تكون نصوصاً، أرقاماً، مصفوفات، أو كائنات متداخلة
  • نحوّله لكائن JS باستخدام response.json()
مثال JSON: 
{ "city": "Damascus", "temp": 28, "unit": "°C" }

Fetch API — جلب البيانات

الدالة fetch(url) ترسل طلب HTTP وترجع Promise. الخطوات الأساسية:

  1. استدعِ fetch مع رابط API
  2. تحقق أن الاستجابة ناجحة (response.ok)
  3. حوّل الرد إلى JSON بـ response.json()
  4. استخدم البيانات لتحديث الصفحة

async / await — تبسيط الكود

بدلاً من سلسلة .then() الطويلة، نكتب الكود بشكل متتابع داخل دالة async:

  • async — تعلن أن الدالة تعمل بشكل غير متزامن
  • await — تنتظر انتهاء Promise قبل المتابعة
  • نلف الكود بـ try / catch لمعالجة الأخطاء
تذكير: جلب البيانات من الإنترنت يحتاج اتصالاً فعّالاً. بعض APIs مجانية ولا تحتاج مفتاحاً — مثل Open-Meteo للطقس.

عرض البيانات في الصفحة

بعد جلب JSON، نستخدم DOM لعرض النتائج:

  • textContent — لعرض نص آمن
  • innerHTML — لبناء عناصر HTML (بحذر)
  • إظهار/إخفاء حالة التحميل والخطأ للمستخدم

أمثلة الكود

مثال 1: جلب بيانات بـ fetch و .then()

JavaScript — fetch with .then()
// Fetch weather data for Damascus from Open-Meteo (free, no API key)
const apiUrl =
  'https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true';

fetch(apiUrl)
  .then(function (response) {
    if (!response.ok) {
      throw new Error('Network response was not ok');
    }
    return response.json();
  })
  .then(function (data) {
    const weather = data.current_weather;
    console.log('Temperature:', weather.temperature, '°C');
    console.log('Wind speed:', weather.windspeed, 'km/h');
  })
  .catch(function (error) {
    console.error('Fetch failed:', error.message);
  });

مثال 2: نفس الطلب بـ async/await

JavaScript — async/await
async function getWeather() {
  const apiUrl =
    'https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true';

  try {
    const response = await fetch(apiUrl);

    if (!response.ok) {
      throw new Error('Failed to load weather data');
    }

    const data = await response.json();
    const weather = data.current_weather;

    return {
      temp: weather.temperature,
      wind: weather.windspeed,
      code: weather.weathercode
    };
  } catch (error) {
    console.error(error.message);
    return null;
  }
}

// Call the function
getWeather().then(function (result) {
  if (result) {
    console.log(result.temp + '°C');
  }
});

مثال 3: عرض البيانات في HTML

HTML + JavaScript — Display on page
<!-- HTML structure -->
<div id="weather-card">
  <p id="city-name">دمشق</p>
  <p id="temperature">--°C</p>
  <p id="wind-speed">-- km/h</p>
  <p id="status-msg" class="hidden"></p>
</div>

<script>
  async function displayWeather() {
    const tempEl = document.getElementById('temperature');
    const windEl = document.getElementById('wind-speed');
    const statusEl = document.getElementById('status-msg');

    statusEl.textContent = 'جاري التحميل...';
    statusEl.classList.remove('hidden');

    try {
      const url =
        'https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true';
      const response = await fetch(url);
      const data = await response.json();
      const w = data.current_weather;

      tempEl.textContent = w.temperature + '°C';
      windEl.textContent = 'سرعة الرياح: ' + w.windspeed + ' km/h';
      statusEl.classList.add('hidden');
    } catch (err) {
      statusEl.textContent = 'تعذّر جلب البيانات';
    }
  }

  displayWeather();
</script>
Open-Meteo API: مجاني بالكامل ولا يحتاج تسجيلاً. مثال دمشق: latitude=33.51&longitude=36.29

تمارين عملية

1 جلب وطباعة JSON

استخدم fetch لجلب بيانات الطقس لدمشق واطبع كائن current_weather في Console.

Solution
fetch('https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true')
  .then(res => res.json())
  .then(data => console.log(data.current_weather));

2 تحويل لـ async/await

أعد كتابة التمرين الأول باستخدام دالة async و try/catch.

Solution
async function loadWeather() {
  try {
    const res = await fetch(
      'https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true'
    );
    const data = await res.json();
    console.log(data.current_weather);
  } catch (e) {
    console.error(e);
  }
}

loadWeather();

3 عرض درجة الحرارة في الصفحة

أنشئ عنصر #temp واعرض درجة الحرارة الحالية بعد الجلب.

Solution
async function showTemp() {
  const tempEl = document.getElementById('temp');
  const res = await fetch(
    'https://api.open-meteo.com/v1/forecast?latitude=33.51&longitude=36.29¤t_weather=true'
  );
  const data = await res.json();
  tempEl.textContent = data.current_weather.temperature + '°C';
}

ملخص الجلسة

  • API يسمح لموقعك بجلب بيانات من خوادم خارجية
  • JSON صيغة البيانات الأكثر شيوعاً على الويب
  • fetch() ترسل طلب HTTP وترجع Promise
  • async/await تجعل كود الجلب أوضح وأسهل للقراءة
  • استخدم try/catch و response.ok لمعالجة الأخطاء
  • في الجلسة القادمة: مشروع تطبيق الطقس الكامل

  • أضف رسالة "جاري التحميل..." قبل ظهور النتيجة
  • اقرأ عن Geocoding API لتحويل اسم المدينة لإحداثيات
