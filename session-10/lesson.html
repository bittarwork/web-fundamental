هدف الجلسة

اليوم نتعلم كيف البرنامج «يفكر» ويأخذ قرارات — مثل لما تلعب لعبة وإذا نقاطك أكثر من 60 تنجح، وإذا بطارية التلفون أقل من 20% يظهر تحذير. هذه الجلسة أساسية لأي تطبيق أو لعبة ستبنيها.

الشرح النظري — من الصفر

1) شو يعني «شرط» في البرمجة؟

البرنامج عادةً ينفّذ أوامر بالترتيب، سطر بعد سطر. لكن أحياناً بدنا نقول: «إذا صار هالشي، اعمل كذا — وإلا اعمل شي تاني». هون بيجي دور if و else.

تشبيه بسيط: الشرط مثل حارس الباب — إذا عمرك 18+ بيدخّلك، وإلا بيرجعك.

2) if — إذا تحقق الشرط

  1. نكتب if وبعدها الشرط بين أقواس ()
  2. نفتح أقواس معقوفة { } ونكتب الكود اللي بدنا ينفّذ
  3. إذا الشرط true (صح) — الكود بين الأقواس ينفّذ
  4. إذا الشرط false (غلط) — الكود بين الأقواس ما بينفّذ

3) else — وإلا

لما بدنا خيار بديل إذا الشرط ما تحقق، نستخدم else: 

if (age >= 18) {
  console.log("مسموح");
} else {
  console.log("ممنوع");
}

4) else if — أكتر من خيار

لما عندنا أكتر من حالة (مثل مستويات بطارية أو خصومات)، نستخدم else if بين if و else.

5) عوامل المقارنة — كيف نقارن القيم؟

== و ===

== يساوي (قد يحوّل النوع)
=== يساوي تماماً (نوع + قيمة)
استخدم === دائماً!

!= و !==

!= لا يساوي
!== لا يساوي تماماً
استخدم !== دائماً!

> < >= <=

أكبر · أصغر · أكبر أو يساوي · أصغر أو يساوي
مثل: score >= 60

قاعدة ذهبية: استخدم === و !== بدل == و != — أدق وأقل أخطاء! مثلاً: "5" === 5 يرجع false لأن واحد نص والتاني رقم.

6) && و || — ربط أكتر من شرط

  • && (و) — لازم كل الشروط تكون صح
  • || (أو) — يكفي شرط واحد يكون صح

مثال: age >= 18 && hasID === true — لازم العمر 18+ و معك هوية.

7) switch — اختيار من قائمة (مبسّط)

لما عندك قيمة محددة وبدك تختار حسبها (مثل مستوى خصم)، switch أوضح من كتير if: 

switch (tier) {
  case "gold":
    console.log("خصم 30%");
    break;
  case "silver":
    console.log("خصم 15%");
    break;
  default:
    console.log("بدون خصم");
}

لا تنسى break — بدونها الكود يكمل للحالة اللي بعدها!

تحديات تفكير — حسّن منطقك البرمجي

🧩 تحدي 1: صلّح الشروط المكسورة!

هالكود المفروض يطبع «نجحت» إذا score أكبر أو يساوي 60، بس فيه أخطاء:

let score = 75;
if score >= 60 {
  console.log("نجحت");
} else
  console.log("رسبت");
}

الأخطاء:

  1. ناقص أقواس حول الشرط: if (score >= 60)
  2. قوس إضافي } في آخر الكود
  3. الأفضل نضع أقواس { } حول كل كتلة else
let score = 75;
if (score >= 60) {
  console.log("نجحت");
} else {
  console.log("رسبت");
}
// نجحت

🧩 تحدي 2: بدون تشغيل — توقع النتيجة!

اقرأ الكود بعناية واكتب النتيجة على ورقة:

const price = 80000;
let message = "";

if (price >= 100000) {
  message = "غالي";
} else if (price >= 50000) {
  message = "متوسط";
} else {
  message = "رخيص";
}

console.log(message);

الحل خطوة بخطوة:

  1. price = 80000 — مو >= 100000، إذن نروح للـ else if
  2. 80000 >= 50000 = true
  3. إذن message = "متوسط"
متوسط

ملخص الجلسة

  • if ينفّذ كود إذا الشرط true، else للخيار البديل
  • else if لأكتر من حالة (بطارية، خصومات، مستويات)
  • استخدم === و !== للمقارنة الدقيقة (نوع + قيمة)
  • && (و) — كل الشروط لازم تكون صح · || (أو) — شرط واحد يكفي
  • switch لاختيار من قائمة قيم — لا تنسى break
  • الشروط أساس أي تطبيق: ألعاب، متاجر، تحذيرات، صلاحيات

واجب اختياري

  • اكتب برنامج يفحص بطارية تلفونك (رقم من 0 لـ 100) ويطبع 3 مستويات
  • برنامج خصم: إذا السعر >= 200,000 ل.س خصم 40,000 ل.س
  • جرب الفرق بين == و === مع نص ورقم
