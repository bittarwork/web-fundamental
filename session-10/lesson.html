الشرح النظري

التحكم في تدفق البرنامج

حتى الآن نفّذنا أوامراً متتابعة. لكن البرامج الحقيقية تحتاج قرارات (إذا كان الشرط صحيحاً افعل كذا) وتكرار (نفّذ هذا العمل 10 مرات). هذا ما نسميه «تدفق التحكم» (Control Flow).

if / else — اتخاذ القرار

تنفّذ كتلة كود عند تحقق شرط معيّن، وإلا تنفّذ بديلاً:

  • if — الشرط الأساسي
  • else if — شروط إضافية
  • else — الحالة الافتراضية عند فشل كل الشروط

switch — اختيار من حالات محددة

عندما تريد مقارنة قيمة واحدة بعدة خيارات ثابتة (مثل أيام الأسبوع أو حالة الطلب)، switch أوضح من سلسلة طويلة من else if. لا تنسَ break لمنع تنفيذ الحالات التالية.

حلقة for — تكرار بعدد معروف

تتكوّن من ثلاثة أجزاء: تهيئة العداد · شرط الاستمرار · تحديث العداد. مثالية عندما تعرف عدد التكرارات مسبقاً (مثل طباعة أرقام 1 إلى 10).

حلقة while — تكرار بشرط

تستمر طالما الشرط true. مناسبة عندما لا تعرف عدد التكرارات مسبقاً (مثل انتظار إدخال صحيح من المستخدم). احذر من الحلقة اللانهائية إذا لم يتغيّر الشرط!

الدوال (Functions)

الدالة هي كتلة كود قابلة لإعادة الاستخدام تُنفَّذ عند استدعائها. بدلاً من تكرار نفس المنطق، نكتبه مرة ونستدعيه من أي مكان.

  • function name() { } — التعريف التقليدي
  • return — إرجاع نتيجة من الدالة
  • المعاملات (Parameters): قيم تمرّر للدالة عند الاستدعاء
مبدأ DRY: Don't Repeat Yourself — اكتب المنطق مرة واحدة في دالة واستخدمها في كل مكان تحتاجه.

أمثلة الكود

مثال 1: if / else if / else

JavaScript — Conditionals
const score = 75;

if (score >= 90) {
  console.log("ممتاز!");
} else if (score >= 70) {
  console.log("جيد جداً");
} else if (score >= 50) {
  console.log("ناجح");
} else {
  console.log("راسب — حاول مرة أخرى");
}

مثال 2: switch لحالة الطلب

JavaScript — Switch
const orderStatus = "shipped";

switch (orderStatus) {
  case "pending":
    console.log("طلبك قيد المعالجة");
    break;
  case "shipped":
    console.log("طلبك في الطريق إليك");
    break;
  case "delivered":
    console.log("تم التسليم بنجاح");
    break;
  default:
    console.log("حالة غير معروفة");
}

مثال 3: حلقة for

JavaScript — For Loop
for (let i = 1; i <= 5; i++) {
  console.log("المنتج رقم", i);
}

// جمع أرقام 1 إلى 10
let sum = 0;
for (let n = 1; n <= 10; n++) {
  sum += n;
}
console.log("المجموع:", sum);

مثال 4: حلقة while

JavaScript — While Loop
let attempts = 0;
const maxAttempts = 3;

while (attempts < maxAttempts) {
  console.log("محاولة رقم", attempts + 1);
  attempts++;
}
console.log("انتهت المحاولات");

مثال 5: دوال مع return

JavaScript — Functions
function calculateTotal(price, quantity) {
  const total = price * quantity;
  return total;
}

function formatPrice(amount) {
  return amount.toLocaleString("ar-SY") + " ل.س";
}

const bill = calculateTotal(35000, 4);
console.log("الفاتورة:", formatPrice(bill));

// Arrow function — صيغة مختصرة
const applyDiscount = (price, percent) => {
  return price - (price * percent / 100);
};

console.log("بعد خصم 10%:", formatPrice(applyDiscount(bill, 10)));

تمارين عملية

1 تصنيف العمر

اكتب برنامجاً يصنّف العمر إلى: طفل (أقل من 13)، مراهق (13-17)، بالغ (18+).

Solution
const age = 16;

if (age < 13) {
  console.log("طفل");
} else if (age <= 17) {
  console.log("مراهق");
} else {
  console.log("بالغ");
}

2 جدول الضرب

استخدم حلقة for لطباعة جدول ضرب الرقم 7 (من 1 إلى 10).

Solution
for (let i = 1; i <= 10; i++) {
  console.log(`7 × ${i} = ${7 * i}`);
}

3 دالة حساب الضريبة

اكتب دالة addTax(price, rate) تُرجع السعر بعد إضافة نسبة ضريبة، وجرّبها على 100,000 ل.س بنسبة 5%.

Solution
function addTax(price, rate) {
  return price + (price * rate / 100);
}

const finalPrice = addTax(100000, 5);
console.log(`السعر النهائي: ${finalPrice} ل.س`);

ملخص الجلسة

  • if/else لاتخاذ قرارات بناءً على شروط منطقية
  • switch مناسب لقيم محددة ومتعددة — لا تنسَ break
  • for للتكرار بعدد معروف · while للتكرار بشرط
  • الدوال تجمع المنطق المتكرر وتُرجع نتائج عبر return
  • Arrow functions صيغة حديثة مختصرة: (a, b) => a + b
